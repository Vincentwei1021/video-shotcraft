---
name: gradient-transition
一句话: 背景在 linear、radial、conic 三类 CSS 渐变间平滑过渡——角度、色标、中心、半径逐参数插值，段间交叉淡化换类型
适用: 氛围底/章节底色的连续变奏；给静态排版段落提供"活着"的背景层
时长: 约 6.7s（200f@30fps；linear 0–2.3s · radial 1.9–4.4s · conic 3.9–6.7s）
能量: 低（纯背景运动，为前景内容让路）
---

## 意图
渐变不是静态贴图而是可动画的参数集：同类型渐变内部任何参数都能插值出丝滑变化，跨类型则用短交叉淡化衔接。作背景层用，给"没有主体运动"的段落一层持续的低速能量。

## 动效核心
- 三层各持一种渐变类型，同一时刻只有一层主导，交叉淡化窗口很窄（12–14f）且两层在窗内都在动
- linear 段（0–68f）：角度 18°→198°（swift in-out），三档明度色标（64→40→7）在 HSL 空间三通道插值
  （`mixH` 对 h/s/l 分别 lerp，比 RGB 不发灰）——明度拉开，亮带走向才看得出"角度在扫"
- radial 段（56–132f）：圆心 (24%,72%)→(68%,38%) 对角迁移 + 半径 48%→80% 扩张，外圈近黑，
  光斑像在画面里游走并聚焦
- conic 段（118–200f）：A→B→C→A 三色环（紫 / 品红 / 冰蓝，首尾同色）`from` 0→250° 旋转，
  慢起长尾 ease 越转越慢落定；圆心放在主体右后方 (64%,54%)，外圈与文字侧再压暗
- **小画布作画**：三层渐变画在 480×270 上再 `transform: scale(4)` 铺满——合成期放大天然柔化，
  conic 的 blur(9px) 在小画布上做（≈全分辨率 36px），每帧代价是全屏实时模糊的 1/16；上面叠颗粒防色带
- demo 前景：每段一句大字（180px），动词描述该段的参数运动（Bend light. / Focus it. / video-shotcraft 字标 + 品牌短句），
  换句与换类型同拍；底部 mono 注记实时读出正在插值的渐变参数

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 段窗口重叠 | 相邻段起点比前段终点早 12f | 重叠保证淡化时两层都在动；无重叠会看到"接管瞬间静止" |
| 交叉淡化 | 56–68f / 118–132f（smooth in-out） | 拉宽会同屏看到两种渐变结构打架；窄淡化 + 参数同动是"换类型不换气"的关键 |
| HSL 插值 | h/s/l 三通道独立 lerp | 色相差 >180° 时会绕远路（如 340→160），需要短路径时给起点 +360 |
| 色标明度差 | linear 亮 64 / 中 40 / 暗 7 | 明度差 <20 时角度扫过读不出来，只剩一块在变色的平底 |
| radial 迁移 | 中心对角走位 + 半径 48%→80% | 中心不动只扩半径会读作"呼吸"不是"游走" |
| conic 旋转 | from 0→250°（不满一圈，ease-out 长尾） | 转满 360° 收尾与开头同帧，接循环时用；单次播放留缺口避免"回到原点"感 |
| 色标组 | 三段同一组紫 / 品红 / 冰蓝 | 换项目色时保持"亮色+暗色"配对结构，radial 外圈必须暗（光斑成立的前提） |

## 已知坑
- 这是背景卡：前景放排版/UI 时在文字一侧叠暗色 scrim（demo 左侧线性压暗 + 外圈暗角），否则 conic 段的亮色会吃掉前景对比度
- `radial-gradient(circle R …)` 的 R 只接受长度：写成 `circle 45%` 整条渐变失效、该段渲成纯黑——百分比半径要么换算成 px（demo 以小画布宽 480px 为 100%），要么改用 `ellipse X% Y%`
- CSS 渐变字符串每帧重写触发 repaint 而非 composite——大画幅 + 低端设备需实测；Remotion 服务端渲染无此顾虑
- conic 段用三色循环（A→B→C→A）；七段彩虹色环是"演出"性质，品牌化场景别用
- 三段各自独立可拆用：只要 linear 段（0–68f 重归一化）就是一张"角度扫过"的极简底
