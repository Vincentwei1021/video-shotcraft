## 意图
transition-travel 是镜头钻进画面里的既有元素换景；本卡反过来——从
动作里**放出一个语义信使**，让镜头跟着它飞去下一个场景。"发送"这个
抽象动作被实体化成折纸飞机，A/B 两窗的空间关系被飞行轨迹真实丈量
过，观众对"消息去了哪"有了身体感。命门是 2.5D 相机管线：所有元素
挂在同一世界坐标系上，镜头中心 A→跟飞机→B、变焦拉远再推近，视差
道具按 depth 乘相机位移——重 3D 原片降级成一台"假三维"，成本掉一个
量级而纵深感保留。飞机俯仰角跟随弧线切线是"它在飞"而非"它在平移"
的全部区别。

## 动效核心
- 世界坐标系相机：`screen = 960 + (world − camCenter) × zoom × depth`；
  镜头中心 A(600,560) → 跟飞机 → B(3500,600)，变焦 1.5（贴脸 A）
  → 0.5（拉远伴飞）→ 0.56（伴飞缓推）→ 2.0（=1920/窗宽 960，B 满幅接管）；变焦在对数空间插值，推拉体感匀速
- 飞机三次贝塞尔：A 发送按钮 → 高抛控制点（y=−170）→ 下压控制点 →
  B 新行头像左侧；朝向 = bez(t) 与 bez(t+0.012) 的 atan2 切线角
- 飞行整体缓动 bezier(0.45,0.05,0.25,1)（起飞加速、落定
  减速）76f；途中 scale 放大 1.8 倍保可读，落定收回 1.1
- 夜空三层视差（demo 用 midnight 暗场）：远层 170 颗闪烁星点 depth 0.28（世界里铺 ~8000px 高，拉远时才铺得满画面）/
  中层薄云 depth 0.62 / 近层焦外云絮 depth 1.5（画在世界层之上，从镜头前掠过）；云全用径向渐变，不挂实时 blur；
  飞机身后一条光迹：取 bez 最近 42% 段切 46 小段，宽辉光 + 细亮芯，透明度与线宽按 k² 从尾到头递增
- 飞机 = SVG 三块折面（渐变示受光）+ 折痕线，外层不旋转的柔光晕（夜里唯一的亮物）；
  入场过冲弹出，转弯时轻微倾侧；新行提前 8f（96f）高度 0→96 顶开列表"让出空槽"，飞机 102f 起滑进新行头像位
  缩小淡出 + 一圈强调色涟漪（落进真实槽位，不留残影）
- 点击：光标滑到发送键，按下 3f 压到 0.93 → 松开过冲回弹 + 扩散圈（CLICK 12f），按钮文案上滑换成「Sent ✓」；
  B 的「All caught up」徽标随新行到达换成强调色「1 new」
- 窗口为镜头放大排版：A 贴脸时正文有效 ≈39px，B 接管后姓名 52px / 摘要 44px（Q11）

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 变焦三段 | 1.5 → 0.5 → 2.0 | 不先拉远直接跟飞，观众不知道 B 在哪个方位；拉远 <0.6 才装得下旅程感 |
| 飞行时长 | 76f，ease-in-out | <45f 读作弹射；匀速读作拖拽平移 |
| 切线采样 | dt = 0.012 | 太大角度滞后、太小抖动；俯仰角是"飞"的命门，删掉立即变贴图滑动 |
| 途中放大 | ×1.8（0.22–0.78 区间），落定 ×1.1 | 拉远后飞机只剩几十像素，不放大就丢主角 |
| 视差层 | depth 0.28/0.62/1.5，远层星点闪烁、近层云絮低透明度 | 全同 depth 就没有穿越感；近景太实会抢飞机视线；远层铺得不够大，拉远时星点挤成一条带 |
| B 接管 | 110–142f，变焦推到 2.0（窗满幅、圆角同步收到 0），视差层/光迹同步淡出 | 道具不淡出会在推近时变成巨大糊块扫过全屏 |
| 新行让位 | 飞机到达前 8f 开始顶开 | 同时开会让飞机扎进旧行，读作撞上 |

## 已知坑
- demo 在手搓的深色玻璃窗 + 夜空上调校——参数是调校起点非实战定稿，
  首次实战须以真实素材回验
- 与 transition-travel 分工：那卡钻进**画面里既有的**元素/容器完成
  换景（空间早已在构图里）；本卡**放出一个新实体**连接画外的第二场景
  ——A/B 无既有空间关系时才轮到本卡
- 与 glow-flyline-moves B（flyline-arc）分工：飞线是暗场数据流向的
  抽象示意（线是主角），本卡是叙事旅程（信使是主角、镜头伴飞）
  ——讲数据用飞线，讲人与人用信使
- 信使实体必须来自动作语义（发送→纸飞机、上传→气球、部署→火箭），
  随便找个吉祥物飞一趟读不出因果
- 相机三段（拉远/伴飞/接管）的切换帧上中心与变焦都要连续——demo 里
  接管段以 TAKEOVER[0] 处的伴飞变焦为起点做对数插值才不跳帧，改时间轴先查这点
- 2.5D 的极限：道具只能是剪影级形状，写实道具会暴露"没有真透视"；
  要重 3D 质感请回原片路线（成本高一档）
