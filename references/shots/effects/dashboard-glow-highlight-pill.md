一句话: 金字悬于黑场，数据仪表盘自底带透视升入并持续 3D 漂移；金色光斑从功能按钮被拾起、巡游到底部拉成胶囊，再由它一分为二、双向描出弹窗的辉光轮廓
适用: 金融/数据类产品的重功能揭示；"注意这里"的高级指引；黑金调品牌片的核心一拍
时长: 约4.5s（136f@30fps）
能量: 高（升入 + 巡游 + 描边 + 弹窗四段，交棒必须密不透风）
---

## 意图
用一束光把观众的注意力从"整个仪表盘"收到"这一个弹窗"上。光斑先在
面板间巡游（宣布有东西要来），拉成胶囊（蓄力），再从胶囊落点起笔
描出弹窗轮廓（交棒）——三段是同一束光的连续变形，任何一处断开就
变成三个不相干的动画。每段都靠上一段的落点做起点。

## 动效核心
- 黑金 = 近单色暗场 + 香槟金唯一强调色：仪表盘 K 线做象牙白实体 / 灰色空心
  的单色蜡烛，涨跌不用红绿抢色，画面里只有光和弹窗是金的
- 开场金字（150px 衬线，`background-clip:text` 金色渐变）逐字由虚到实、字距
  收拢、轻微上浮（0.8f 错峰），泛光走 `glowFilter` 呼吸；20→34f exit 上浮淡出
- 仪表盘按原生像素布局（1600×900），27f 起 `rotateX 40°→4°`、`y 560→0`、
  `scale 1.12→1`（snappy 26f）透视升入，之后 yaw −9°→+4° 持续漂移；
  58→92f 后拉到 0.93 让位给弹窗
- 背景虚化压暗：58→80f `blur 0→7px` + 压暗 0.5，104f 起退掉 35%
- 光斑起点 = 顶栏 Focus 按钮（46f 按钮先被点亮 = "光被拾起"），52→78f 沿二次
  贝塞尔弧（smooth in-out）巡游到弹窗底边中点；形状沿切线方向按速度拉成彗星，
  70→78f 压平成 230×18 水平胶囊；实心亮核 + 外扩辉光 + 更大一圈金色晕
- 78→100f 胶囊一分为二：两条半周路径（底边中点 → 左/右下角 → 侧边 → 上角 →
  顶边中点）同时 draw-on（snappy 22f），两枚光头跟着描边头跑，100f 顶边汇合小闪
- 100→116f 描边收敛：笔宽 4→1.5px、暖白→香槟金、辉光撤到常驻细框
- 弹窗底板 82f 先到，标题 / 正文 / 双选项 / 按钮 86–101f 逐层升起；弹窗与描边
  共用同一个盒子，随相机半幅漂移

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 金字退场 | 20→34f exit，上浮 140px | 要和仪表盘升入叠着走；先清场再升入就断了 |
| 仪表盘升入 | rotateX 40°→4°、y 560→0、scale 1.12→1，snappy 26f | 快起慢落读作"镜头压下去"；匀速读作"面板飘上来" |
| 常驻 3D 漂移 | yaw −9°→+4°（smooth 88f），后拉 0.93 | 漂移不能停：一静止就露出这是张贴图 |
| 光斑巡游 | 贝塞尔弧 26f smooth，宽 34+速度×1.1 → 230，末 8f 压平 | 单调向左下 + 只拉长不回摆；回摆一次就读作"光在找东西" |
| 背景虚化 | blur 峰值 7px，104f 起退 35%，压暗 0.5 | 只起不退 = 结尾整幅糊；退到 0 又失去弹窗的层次 |
| 描边 draw-on | 双向半周，snappy 22f，从底边中点起 | 双向包抄比单向绕圈快一倍且对称；快起步才接得住胶囊"甩出去"的势 |
| 描边收敛 | 100→116f：4→1.5px、#fff4da→#e6c785 | 收敛是"光变成 UI"的语义；不收敛就一直是特效 |
| 弹窗内容 | 底板 82f、内容 86–101f 逐层（3–4f 错峰） | 底板先于文字，才有"框先在、内容后填"的顺序 |

## 已知坑
- **描边 SVG 与弹窗必须共用同一个盒子和 1:1 px 的 viewBox**。曾用
  `300×220` + `preserveAspectRatio="none"`，被非等比压成 x0.39/y0.49：
  笔宽横竖不一、圆角拉成椭圆、整条描边浮在轮廓外——这是"画光位置和
  弹窗不一致"的根因
- 光斑不要用径向渐变一路淡到透明再叠 box-shadow：两者之间会夹出一圈暗边，
  读作"黑描边的棍子"。用实心亮核（纯色 + 1.5px blur）+ box-shadow 外扩辉光，
  再垫一层更大的金色径向晕
- 光斑终点必须 = 描边起笔点（弹窗底边中点），起点必须对准触发它的按钮；
  写死坐标后一改仪表盘姿态或弹窗位置，"拾起光 → 拉成胶囊 → 描边"的交棒就断了
- 金字用 `background-clip:text`，辉光只能走 `filter: drop-shadow`——
  `text-shadow` 对透明字无效
- 仪表盘整块 3D 漂移 + 实时 blur 每帧重算，单镜头渲染仍在 10s 级；
  再加大面积元素时注意别叠第二层整屏 blur
- 仪表盘的行情 / 持仓 / 弹窗文案全是虚构占位（确定性随机游走生成），
  落地要换成项目真实界面
