## 意图
黑场里观众只能看见光给看的东西——聚光既是照明也是运镜和剪辑：
光到哪里哪里登场，光走即谢幕。三式共用"贴边辉光光线"这个
身份元素（光线贴着 UI 边框/logo/顶边走，辉光要亮要糊，是光在
"抚摸"界面而不是描边动画）；光色跟镜头 look 走（demo：A 紫粉、
B 冰蓝白、C 日出杏金），层次结构不变。命门是**匀速**：聚光的移动/扩张
严格 linear——缓动会让光有"意图"，匀速才读作探照灯的机械扫掠
（C 式判例：linear 但半径终值过大＝前 1/4 就饱和，观感照样不匀速）。

## 动效核心
**A 醒睡扫过**（glow-wake-sleep-panel，aurora）：斜置的音频工作站混音页
（rotateX18/Y−12/Z−10，后层一块重影面板给厚度）；光池跟随光头 sx 从左外
到右外 linear 扫过（6–128f），平台亮区 + S 形衰减，范围外沉黑；光池中心也压一层
~30% 紫调（亮面板被照成可读的淡紫，不是过曝白盘），泛光只给被照到的波形柱
（模糊副本垫底）与贴边光线，光头眩光收到 300×120。**光心兼作
播放头**：光照到的波形柱点亮成紫粉渐变、播放头细线与时间码跟光走、走过的
波形留一层暗紫"已播放"，分轨电平随光经过跳一下（光到即醒）。贴顶边四层
辉光（blur28 宽糊 + blur9 中层 + 粉偏移 + 亮芯）同行，经过 logo 描一圈光；
光身后一团紫雾 + 浮尘。100–134f 包络沉回黑暗，右缘竖直残光转蓝紫，
播放键自发光留到尾帧（暗场海报）。
**B 贴边泛光横摇**（slide-spotlight-pan，midnight）：超宽暗色路线图面板；
光头先沿左缘竖直爬升、14f 转过左上角（转角 ±2f 做红/蓝错位副本的 RGB
色散）后沿顶边横走；光头与面板左滑共用一条 linear 时间轴，最后 16f
**同速刹停**（速度从匀速值线性降到 0，速度连续），光头停在 Q4 发布卡上方，
卡片描边亮起进 hold。暗色 UI 靠光池才读得出来；光头下方一团青蓝光从顶边
渗进界面，顶边发丝线本身被点亮一段。
**C 角落匀速显影**（corner-spotlight-reveal，sand）：光心在画外左上（太阳刚
露头），显影平台半径严格 linear 190→2120（0–104f，恰在 104f 盖满最远角），
羽化带 = 110 + 0.3r；光前沿挂两圈 screen 叠加的杏粉辉边（宽 + 窄亮带），
角落几道极淡丁达尔光柱随光长、全亮后淡出；被照亮处先叠一层 multiply
晨光暖调、随时间褪成日光（色温从黎明走到白天）；每块内容在光前沿扫过时
上浮 18px 落座（按到光心距离自动错峰）。相机 1.12→1.0 缓出 112f 后静止；
全亮 hold 46f 里日出弧上的太阳点升到 6:42 位置。

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 聚光移动/扩张 | 全程 linear、零缓动（B 只在末 16f 同速刹停） | **匀速是命门**——加 ease 读作光有主观意图；需要停在终点时用"速度线性降到 0"的刹停，别用 ease-out 整段 |
| C 式半径终值 | 平台半径恰好在扩张末帧盖住最远角（190→2120@1080p/104f） | 终值过大＝提前饱和假匀速：亮度采样须全程平滑爬升 |
| C 式羽化带 | 110 + 0.3r | 太宽（≥0.55r）光前沿糊成一片灰雾，读不出"照到/照不到"的界线 |
| 贴边光线辉光 | 4 层（blur28 宽糊 + blur9 中层 + 偏移色层 + 亮芯），screen 叠加 | 层少读作细线描边；辉光要够亮够糊才是"光" |
| 光线锚定 | 严格贴 UI 边缘/顶边/logo | 光线脱离边缘漂浮＝失去"抚摸界面"语义（A 式返工判例：定位丢失紫光跑到底边） |
| 显影罩 | 平台亮区 ~22% + S 形多停靠点衰减，暗部带 look 的色相；亮面板上平台中心也留 ~30% 光色压暗 | 边太硬像圆形遮罩；太糊没有界线；单段线性衰减会把整圈照成灰雾；平台中心全透明 = 亮面板过曝成白盘（A 式返工判例），白场面积别超过 ~200px |
| B 转角色散 | 光头过角 ±2.4f，红/蓝两份 0.5 倍长副本各错 ±12px | 超过 4f 读作故障特效；只在转角那一下 |
| 相机漂移（C） | 0–112f 缓出收住后静止，插值必须钳位 | 不钳位会在扩张结束后继续外推缩放，底边露黑 |

## 已知坑
- demo 在灰阶/占位素材上调校通过——参数是调校起点非实战定稿，
  首次实战须以真实素材回验
- 与 light-play-moves 分工：那张是元素/文字上的
  光泽戏（sheen/辉光呼吸）；本卡光是**运镜和剪辑**（显影/谢幕/转场），
  光决定观众看什么
- 三式重做判例：聚光扫过必须带贴边光线同行（v1 只有显影罩被裁
  "改改再看"——裸聚光没有身份，贴边紫光才是这个手法的签名）
- 原片（clickup-30）光线转角有一瞬彩虹色散——B 式已做（红/蓝错位副本
  ±2.4f）；A 式没有转角，不加
- 暗色 UI（B 式）在黑场里对比天然弱：靠光池压暗 + 顶边渗光让"照到的才读得出"，
  别把面板本身提亮去凑对比
