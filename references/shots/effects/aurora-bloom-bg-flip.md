---
name: aurora-bloom-bg-flip
一句话: 雾白底从底部升起青绿紫柔焦极光团，随后整个底色在约 0.37s 内压暗到极夜、光团压成余晖并显出极光帘幕；文案同步 blur-out 换句 blur-in，换句间留空档不 cross-fade
适用: 叙事转折点（"多年以来…→一切都变了"）；品牌片从铺垫拉到重音的那一拍；深浅色系之间的段落切换
时长: 约5.7s（172f@30fps）
能量: 由低到高（前 2/3 是酝酿，压暗那一瞬是全片重音）
---

## 意图
把"底色反转"当成重音符号用：前 56% 让极光慢慢升起、观众适应浅底，
然后用不到 0.4s 把整个画面压到极夜——这一下比任何缩放/闪白都更像
"翻页"。文案的换句必须卡在反转之后，且中间留空档，让观众先接住画面
变化再读新句。

## 动效核心
- 光色是真实极光的一组：主层青绿 `rgb(46,214,160)`、过渡冷青 `rgb(56,180,230)`、紫核 `rgb(132,92,255)`、
  白色融边（只在亮场）；四层都用径向渐变自带的软边（色心 → 34% 半透 → 70% 透明），不用整屏 `filter: blur`
- 升起 `ramp(6→96f, outCubic)`：容器 `translateY 34%→−6%` + `scale 1→1.25`；
  冷青层 / 紫核各自不同频横向漂移（±6% / ±8%），光团内部有相对流动
- 反转 `flip = ramp(96→107f, inOutQuad)`（11f ≈ 0.37s）：
  底色 `mix([233,237,240] → [5,8,14])`，光团组 opacity 1→0.4 压成余晖并轻收 6%（overshoot），
  白色融边层 `1−flip` 收掉；亮场顶部天光与暗场深蓝天顶交叉换位
- 底色压到位后（f104 起 30f）显影极夜：18 条竖向极光帘幕（紫顶 → 青绿身 → 透明脚的渐变 + 横向软遮罩，
  沿正弦带排布、各自 skewX 摆动与明灭，每条带一根更窄更亮的"褶"芯，screen 叠加）+ 80 颗明灭星点
- A 句「For years, forecasts were guesses.」92px：开场逐词 blur-in（2.5f 间隔），静置期 1→1.035 极缓推近，
  f62 起逐词 blur→14px + 上浮淡出（stagger 4f、各 14f、inQuad），f92 收完
- B 句「See it coming.」140px：f118 起逐词 `outQuint` blur-in + 24px 上浮（stagger 6f、各 16f），
  每词落定后 10f 内由极光青收色到白；f140 起品牌落款字距收拢浮现，f156 后 16f 静止

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 光团软边 | 径向渐变 0%→34%→70% 三停，主层 104%×104%，容器 inset −10% | 渐变停点太硬就看得出是圆，成了"色球"不是"光" |
| 升起 | translateY 34%→−6% + scale 1→1.25，f6→96 outCubic | 占掉一半以上时长是故意的：酝酿越长，反转越有分量 |
| 反转时长 | f96→107 inOutQuad ≈ 0.37s | **命门**：拉到 1s 就不是重音而是渐变过场 |
| 底色 | #e9edf0 → #05080e（带蓝相，不是纯黑） | 纯黑会让余晖边缘出现色阶断层 |
| 光团压暗 | opacity 1→0.4、轻收 6%，白色融边层同步归零 | 不压暗光团，暗场里会过曝糊成一团 |
| 帘幕显影 | 反转落定后才起（f104→134），整体 0.9 | 和反转同时出现会在中灰过渡段 screen 出一片脏雾 |
| A 句 blur-out | 逐词 stagger 4f、各 14f、inQuad、blur→14px | inQuad 让消失是加速的，读作"被光吞掉" |
| B 句 blur-in | 逐词 stagger 6f、各 16f outQuint + 10f 内青→白 | 收色比入场晚一点，落定瞬间才转白，是"定稿"的信号 |
| 换句空档 | A 收完 f92 → B 起 f118（≈0.9s 无字，其中反转占 11f） | cross-fade 会把两句糊在一起，空档才读出"翻篇" |

## 已知坑
- 白色融边层只在浅底成立，反转时必须 `1−flip` 收掉，
  否则暗场里留一团灰雾
- 青绿 / 冷青 / 紫是这个效果的**本体光色**，不是品牌色槽位；要换成项目色
  必须光团三层 + 极光帘幕 + B 句收色前的 AURORA 字色整组一起换，只换文字色会和背景脱节
- 文案是虚构品牌 Boreal 的示例句，逐词 stagger 的节奏依赖词数与字长，
  换句要回调 4f / 6f 两个间隔，并确认 A 句在反转前收完
- 底色用 JS 逐帧写 `background`（`mix()` 出实色），不要用 CSS transition，
  否则 seek 到任意帧时颜色不确定
