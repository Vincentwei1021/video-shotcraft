## 意图
库内入场词汇的力度上限一直是 deck-deal-flyin 的"发牌"——快但不重。
本卡补"砸"这一档，三种口味：A 是方向感——卡片带鱼眼级夸张透视贴着
镜头甩进来，"啪"地弹平，动漫金田流的潇洒；B 是重量感——KPI 卡从
镜头前 2.6 倍大小砸落，圆环+尘点+震屏三件套同帧起爆，体育比分弹窗
的分量；C 是传导感——B 的三件套之上，冲击波前沿扫过左右邻卡时把
它们可见地推开再弹回，"这一下震到了邻居"，一件事说清力量大小。
选型按叙事需要：告诉观众"它来了"用 A，"它很重"用 B，"它震动了
全场"用 C。

## 三式选型
| 式 | 做法 | 适用 |
|----|------|------|
| A kanada-perspective-snap | perspective 260→1800px + rotate3d 62°→0 + scale 1.8→1 甩入 18f（姿态比位移晚收），末 5f 过冲 +6° 弹簧弹平 + 集中线，长斜影收正 | 单卡潇洒亮相；调性偏动漫/轻快 |
| B score-slam | 卡从镜头前 scale 2.6/rotate 5° 六帧 ease-in(quad) 砸落，落点帧冲击环+碎片火花+震屏+白闪同帧，比分数字晚 3/6f 二次落地 | KPI/比分类重磅数字登场 |
| C impact-burst-kit | 主卡从镜头前砸进页面空槽 + B 三件套 + 冲击波前沿按半径-距离精算扫过邻卡帧，邻卡外推 34px + rotate ±3.5° 阻尼弹回 | 页面上已有邻居时的"全场震动" |

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| A 甩入 | 18f：translateX −1350→0 走 EASE.snappy（急停），透视/扭转/缩放走晚收曲线 bezier(.62,0,.3,1) 16f——卡片"扭着"冲到位、最后几帧才拍平；按 x 速度给水平 SpeedBlur（0.2×速度、≤26px）+ 身后 7 条速度线 | 快于 12f 读不到鱼眼畸变，慢于 24f 泄劲；姿态与位移同曲线同时收，到位前几帧就已经平了，鱼眼感只剩第一帧 |
| A 落定 | rotateY 15–20f 冲到 +6°，20f 起 spring(damping 16) 回 0 + 8px 震屏 2f + 48 道集中线 9f 向外退散 + 斜长影收正；卡内文字晚 3f 落定（片名 −10° skew 收正） | "啪"在过冲回弹那一下，不在位移结束；集中线超过 10f 读作特效贴纸 |
| B 砸落 | 0–9f 悬在镜头前（2.75→2.6、虚化 10px、半透看得见背景）→ 9–15f ease-in(quad) 砸到 0.965 → spring(damping 14) 回 1 | ease-out 落地是"放下"，ease-in 才是"砸" |
| B 三件套 | 冲击环直径 120→1500px/16f（白芯 9→1.5px + 金色柔辉）+ 14 片多边形玻璃/金箔碎片飞 280–580px（+16 道火花）+ 震屏 18px 指数衰减 5f（偏竖向）+ 2f 白闪 | 原案(720px/10px 尘/8px 震)全档不可感，实渲已 ×1.5–2；实黑粗环/黑方块尘读作"贴纸" |
| B 解耦命门 | 环/尘的"扩散"用 out-cubic、"消散"用线性帧时间 | 同用 out-cubic 前段跑太快，刚扩开就淡没 |
| C 波及帧 | 前沿过邻卡中心距反解（环半径 100→1100/16f，514px 距 ≈ 落点后 3f）；包络 cos(t/2)·e^(−t/8)，40f 硬钳 0；推开瞬间按速度给水平拖影 | 邻卡与主卡同帧动读作整版抖动，晚 3f 才是"被波及" |
| C 悬停蓄力 | 0–16f 主卡悬在空槽上方：上提 20px、scale 1.55→1.6（smooth）、槽内接触影随高度变实，再 16–22f ease-in(cubic) 砸进槽 | 悬停段死停读作"卡住了"；蓄力幅度大于 30px 就成了另一个动作 |
| 景深 | B/C 离镜头近（scale 大）时按高度给虚化（B ≤10px、C ≤7px），落地清晰 | 近镜头元素锐利反而读不出"从镜头前砸下来" |
| 收尾 | 全部余波归零后真静止 ≥45f | 重拳 hold 按平常两倍给（同 beat-cut A 判例） |

## 已知坑
- demo 用 video-shotcraft 的宣传内容调校（A 发布片首映卡 / B「Shotcraft vs Keyframes」终场比分 / C 成片规格页 Launch film 卡）——参数是调校起点非实战定稿，
  首次实战须以真实素材回验
- 亮场（C）上冲击环要配一层白色压力盘打底、环本身用饱和强调色，暗场（A/B）用白芯 + 色辉；
  亮底上的白环 / 暗底上的黑环都几乎不可见
- 三式都带震屏，震屏族（impact-feedback）同一镜头
  只能有一个震源；三式互相之间同镜头也只能选一
- 声音强依赖：A 的"啪"、B/C 的音爆必须同帧钉（sound-design §4.5），
  无声版 B/C 的三件套读作"卡在抽搐"
- C 式邻卡必须先驻场稳定 ≥15f 再被波及——邻卡自己还在入场时被推开，
  因果链读不出来
- 全片砸入 ≤2 次；三次以上每次都响等于都不响（P4）
