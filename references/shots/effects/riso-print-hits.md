## 意图
RGB 色散故障闪（impact-feedback C 式的一部分）是荧光屏语言，与纸墨
调性相克。这两式给出印刷版平替：元素裂成两份单色 riso 印版（demo：A 荧光粉 × 蓝、
B 荧光橙 × 青绿；multiply 油墨感而非 screen 荧光感，两版套准时叠成深色墨），
像 risograph 没对准版，抖几下
"啪"地套准——同样的冲击力，介质想象完全换成纸上油墨。A 是单发：
撞停瞬间裂版、震荡衰减、硬切套准，给一次命中盖章；B 是它的节奏化：
每个鼓点整画面跳大 8% + 标题裂版，错位逐拍加码，越打越狠——
卡点段的视觉低音鼓。同技术根（衰减震荡的双版错位），单发/连打二选一。

## 两式选型
| 式 | 做法 | 适用 |
|----|------|------|
| A misregistration-hit 单发 | 标题 8f 撞入撞停，裂两版反向错 ~40px，44f 衰减震荡后硬切套准 + scale 脉冲 + 「ON REGISTER」圆章盖下 | 全片 1–2 次的命中盖章；标题/大字的到位一瞬 |
| B beat-pump 节拍泵 | 每 24f 一拍：整画面瞬跳 1.08 指数回落 + 标题逐拍盖上一个词、错版逐拍 10/18/28/40px 加码套准 | 音乐卡点段；"越打越狠"的蓄力连打 |

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 双版 | 两色 riso 油墨：A 荧光粉 #ff4fa3 + 蓝 #1f5fc4（套准叠成深紫）；B 荧光橙 #ff6a2b + 青绿 #00808a（套准叠成墨绿）。`mix-blend-mode: multiply` 叠在再生纸（#f3eee2 / #f4efe4 + 静态纸纤维/油墨颗粒）上，位移反向；套准即两版归零重合 | multiply 叠出的重影就是"油墨没对准"；screen 叠加立刻变荧光故障；两版选互补色相、套准后叠成近黑最好，别用纯灰（读作阴影） |
| A 错位包络 | `offset = A·cos(2πt/18)·exp(-t/60)`，A=(20,8)px 两版反向（300px 标题）；帧 72 硬切归零 | 命门：套准是**硬切跳变**不是渐收——衰减到 ~11px 残余时啪地归零才有"啪"；纯渐收读不出套准一拍 |
| A 撞入 | 8f Easing.in(cubic) 从画外撞停，命中帧即裂版 | 裂版必须与撞停同帧——晚 2f 就读作两件事 |
| A 套准脉冲 | 归零帧 4f scale 1.03→1；同帧圆章 scale 1.5→1 盖下；命中帧整页 1.2% 顿挫 10f 回落 | 盖章的一拍；省略则套准无重量 |
| B 泵 | `scale = 1 + 0.08·exp(-t/3)`（t=0 即满值、一帧到位无渐入），14f 窗口外精确归 1 | 瞬跳是"顿推"本体——加渐入就成了普通 zoom 呼吸 |
| B 错版加码 | AMP 逐拍 5/9/14/20px（单版，双版反向即总分离 10/18/28/40px，196px 标题），`AMP·cos(2πt/6)·exp(-t/3)` 12f 窗口 | 逐次加码是命门（同 hit-counter 判例）：四拍一样大读不出"越打越狠" |
| B 逐拍盖词 | 标题 ONE / MORE / TIME, / LOUDER. 每拍命中帧盖上一个词（无渐入），右侧巨型半调拍号同帧换数 | 每一拍既是冲击也推进一句话；词提前出现就只剩抖动 |
| B 作用域 | scale 作用整画面容器，错版只作用标题 | 整画面全裂读作故障而非印刷 |
| B 节拍参照物 | 底部四格步进音序器：命中格被橙版填满常驻；播放头拍前 6f ease-in 加速扑向下一格、正落在鼓点上 | 静音预览环境的节拍可读性；播放头的拍前蓄力让节拍"可预期" |
| 收尾 | A 套准后 ≥40f / B 末拍归零后 ≥20f 真静止 | R1 |

## 已知坑
- demo 在灰阶/占位素材上调校通过——参数是调校起点非实战定稿，
  首次实战须以真实素材回验
- **错位幅度可感性判例（本批实渲）**：词汇表原案 ±5px 在 1920 宽画面
  正常速度下肉眼几乎不可见——单版 16px/总分离 32px 起步才可感（200–300px 大标题按 20px/40px）；
  幅度存疑时做极端版给用户看（可感性优先）
- 两式与 impact-feedback C（负片冲击帧）语义重叠——纸墨调性片子用本卡、
  游戏/动漫调性用 C 式，同片不并用（P4）
- B 式是声音强依赖：命中帧必须钉鼓点（sound-design §4.5）；无音轨
  段落读作画面抽搐
- A 式错位方向一横一纵混合（x 为主 y 少量）更像没对准版；纯横向读作
  左右晃动
- 半调网点大字用 `background-clip: text` 填网点，别叠 `-webkit-text-stroke` 描边：系统可变字体的
  字形有重叠轮廓，描边会把内部接缝描出来（"2" 的弯折处出现一颗星形线头）
- B 式四拍后必须接足量 hold（≥24f）——连打完不还呼吸，观众的耳朵还
  在等第五拍
