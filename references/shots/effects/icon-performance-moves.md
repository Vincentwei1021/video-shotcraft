时长: A 120f（4s）/ B 156f（5.2s）
能量: A 高潮点缀 / B 蓄势引入
标签: interaction

## 意图
库内图标动画品类首批入库：icon 是镜头怼着拍的表演者，不是 UI 角落的
微交互。A 是确认时刻的三连爆——部署进度环加速冲到 100%，状态盘先缩 0.62x
蓄力 3f、弹 1.3x 过冲落回，同帧射出 12 根随阻力减速的短线粒子 + 一圈描边环
从边缘扩到 2.5 倍直径淡出，盘面同帧"通电"成翡翠绿，"部署成功"不是画出来的
是炸出来的；B 是 macOS Dock 语汇——Dock 里的 app 图标原地连跳 4 次一次比
一次高（0.35→1.2 倍 icon 高），每次落地压扁（末跳宽 1.2x 高 0.8x）+涟漪溅点，
邻居图标逐渐失焦、跳最高那下镜头向它轻推 8%（被吸引），落定后弹开功能
面板——把"用户注意力"剪进叙事。

## 两式选型
| 式 | 做法 | 适用 |
|----|------|------|
| A pop-burst-confirm | 进度环 ease-in 冲到 100% → scale 蓄力-过冲-弹簧落回 + 12 条阻力减速径向线（线长随速度收短）+ 圆环 scale/opacity + 一次泛光，全程 ~20f，随后主体让位、标题逐词升起 | 任务完成/部署成功/打勾时刻，卡点音效 |
| B attention-bounce | 抛体弹跳（时长 ∝ √高度）递增 + 空中速度拉伸 + 落地 2f 挤压 + 涟漪溅点，邻居 rack focus 失焦，峰值跳镜头 scale 1.08 推近，落定触发角标 + 面板弹簧展开 | 新功能引出："看我"→镜头看它→它开面板 |

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| icon 尺寸 | 360–400px 高（半屏特写；A 盘直径 380、B 图标 360） | 角落小图标做表演没人看见——表演者必须占 C 位 |
| A 蓄力 | 缩 0.62x（3f exit）停 3f，停顿时盘内泛绿光 | anticipation：无蓄力的弹出没有"爆"感 |
| A 弹出 | 5f snappy 到 1.3x → 弹簧落回（damping 13，一次可见回弹）+ 镜头同帧 +2% 冲击推 | 回弹超过一次读作果冻 |
| A 粒子/环 | 12 根短线 pos = D(1−e^{−t/4.5})、D 170–290px，线长 = 速度×2.1 + 10 颗细火花 + 环扩 2.5 倍 22f | 三件套同帧齐发是"爆花"成立条件；匀速外推读作烟花贴图 |
| B 递增弹跳 | 4 跳 0.35→0.6→0.85→1.2 倍 icon 高，空中 14/18/22/26f（∝ √高度） | 等高连跳读作 loading；递增才是"越喊越大声"；时长不随高度变读作失重 |
| B 落地挤压 | 接触 2f，压扁量 0.1→0.2 递增（末跳宽 1.2x 高 0.8x），末跳阻尼余弦回稳 | squash 缺席=没有重量 |
| B 镜头推近 | 末跳 72–90f smooth 推 8%；邻居 30–96f 失焦到 7px、降饱和 30% | 镜头动作把"被吸引"的观众视角演出来 |

## 已知坑
- demo 在灰阶/占位素材上调校通过——参数是调校起点非实战定稿，
  首次实战须以真实素材回验
- 同批 bell-swing-alert（铃铛甩摆）淘汰无附言——挂点摆动型 icon
  表演相性存疑，做新 icon 表演优先弹跳/爆发型
- A 与 particle-celebrate-hits 同属爆发点缀，同一段落二选一
- B 首版曾出画框（末跳最高点顶出），弹跳高度与画面上留白先算像素
  （demo：地面 960、图标 360、末跳顶点 168px，推近 8% 后约 119px）
- 声音：A 蓄力静默→爆发帧"pop"+粒子细响；B 每次落地一声"duk"
  音调递升，面板弹出一声轻"叮"
