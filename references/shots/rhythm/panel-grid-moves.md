name: panel-grid-moves
一句话: 分格节奏三式——grid-flash-mosaic 九宫格闪切填墙、中心格吞屏成海报，flip-grid-reflow 一拍内横排集体重排成网格，comic-panel-split 漫画斜格劈出同一主体的三个机位
适用: 把"格子"当节奏器：逐格踩拍亮相（A）、节拍点集体换位（B）、同主体多机位定格并列（C）；三式都吃拍点
时长: A 140f / B 150f / C 156f
能量: A 高 / B 中 / C 中高
标签: ui-entrance

## 意图
与 wall-reveal-moves 的区别是本卡的定位锚：那是"整墙怎么入场"
（一次性揭示），这是"格子怎么当节奏器"——分格、重排、并列都发生
在节拍上，格变即鼓点。A 是填：3×3 格按十六分音符乱序逐格硬切亮相，
中心格晚一拍最后砸下，填满停一拍，中心格放大吞掉全屏成为品牌海报——
功能矩阵一秒全亮相；B 是移：按下 Grid 切换器的同一拍，6 张卡集体换位
（横排→3×2 网格），卡片边飞边形变、落定后才长出更多信息——布局重排本身
当一个鼓点；C 是并：画面被三刀斜缝咔咔劈开，同一产品三种机位同时定格，
停一拍后末格斜边扫过吃掉全屏——Scott Pilgrim 的分屏语言。
按需选：多功能亮相用 A，布局叙事用 B，单品多视角用 C。

## 三式选型
| 式 | 做法 | 适用 |
|----|------|------|
| A grid-flash-mosaic | 16:9 格 3×3（576×324，缝 16px），外围 8 格每 2f 一格乱序条件挂载硬入（4f scale 1.12→1 + 一次白闪），中心格晚 2f 砸下；满墙停 22f（1.006 呼吸 + 格内小图形各动一下）；中心格 3f 预备缩 0.97 → 16f 强加速尾段急刹放大到 3.4，外围格同时外推、缩小、压暗 | 功能矩阵一秒全亮相；高潮前铺排 |
| B flip-grid-reflow | 光标点 Row/Grid 切换器 → 同拍起飞：两套坐标表（竖卡 262×380 横排 / 横卡 520×300 网格），卡片尺寸与卡内版式一起形变（不是等比放大）；4f 集体下沉预备、每卡错峰 2f、22f 不对称 in-out 飞行（上排上弧 / 下排下弧）+ 弹簧落座；落定后卡内样张句再浮现 | 布局叙事：并列→分组的语义换挡 |
| C comic-panel-split | 全屏 3/4 侧拍 20f → 三刀 12° 斜缝每 4f 一刀从上往下劈出，对应格硬切弹入（5f scale 1.07→1 + 白闪）；三格 = 同一主体的全身 / 局部特写 / 微距；定格 29f 靠主体自身动作保活；末格 2f 反向回拉 + 14f 扫屏吃掉全屏成海报 | 同一主体多视角并列；漫画感段落 |

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| A 硬入 | 未到拍点直接不渲染（条件挂载），零淡化；未亮格是暗槽而不是空白 | 逐格硬入无淡化——命门；淡入就不是"啪" |
| A 中心格 | 中心格晚一拍（+2f）最后砸下，白闪更强；格内塞 1920×1080 原生海报 ×0.3 | 中心 = 重拍；海报在格里就读得出字标，吞屏是"走进去" |
| A 吞屏 | 3.4（>3.333 铺满）让描边滑出画外，圆角同步收成直角；完成后摘罩、海报原生尺寸直出 | 纯 ease-in 会带着全速硬停在满屏帧，尾段必须急刹 |
| B 形变 | 宽高分别插值（262×380 → 520×300），卡内字形 / 名称位置一起插值，字号按布局重排不走 scale | 等比放大只是"变大"，形变才读作"换了一种视图" |
| B 起飞 | 光标先按下切换器（30f）→ 2f 后集体下沉 10px → 36f 起每卡 +2f 起飞 | 先有"因"再有重排；预备让起飞有重量 |
| B 轨迹 | 偶数索引去上排、奇数去下排，上排走上弧、下排走下弧（峰值 70px） | 乱排轨迹会恶性穿帮 |
| C 斜缝 | SVG 双线：墨边 + 奶油纸芯（总宽 18px），12° 斜角，每刀 3f 从上往下画出 | 斜缝纸芯是漫画感命门；直缝读作分屏工具 |
| C 保活 | 定格期主体自己在动：对焦环转 26°、光圈叶片收拢、全身格极缓推近 | 三格全静读作截图拼贴；"镜头在工作"比缓推更有内容 |
| C 旁白框 | 奶油底 + 4px 墨描边 + 7px 硬投影，-2° 歪斜盖章弹入，活在格子里随格被盖掉 | 漫画语言的第二个锚点；浮在格子上方会穿帮 |
| 收尾 | 最后一行字揭示完后 A ~36f / B ~59f / C ~50f 海报 hold（只留 1.5% 极缓推近） | R1；摘罩帧与吞屏终值逐像素对齐防跳变 |

## 已知坑
- demo 在虚构内容（矢量镜头 / 字体样张 / 工具墙）上调校通过——参数是调校起点非实战定稿，
  首次实战须以真实素材回验
- C 三格必须是**同一主体的不同机位**——三格塞不同内容读作 bento
  排版不是漫画分格，语义就散了
- 三式都吃拍点、声音强依赖：A 逐格一声啪、B 点击与落座各一声、
  C 逐格咔咔三声（sound-design §4.5）；不踩拍的分格只是布局动画
- C 的主体用 SVG 矢量画（或高分辨率素材）：三格机位最高放大 2.45x，
  位图截图放大会糊（Q2）
- 同片分格系 ≤1 段——格子语言辨识度太强，两段就撞
- A 与 wall-reveal-moves 别同片连用（都是"墙"，观众分不出
  入场还是节奏器）
