适用: 用"打断连续性"本身当节奏器：顿挫推近（B）、窒息逼近（C）；与 beat-cut-moves（切点排布）、montage-rhythm（段落呼吸）互补
时长: B 150f（5s）/ C 150f（5s）
能量: B 中 / C 高
---

## 意图
库内节奏卡管的都是"怎么切、切多密"；这两式管**怎么断**——观众预期
连续，你偏打断，打断方式即表达：B 是空间断——同构图三次无补间跳大
（1x→1.6x→2.6x），戈达尔跳切的顿挫，比连续推近更有"看这里、再近点、
就是它"的指令感；C 是存在断——画面与纯黑交替频闪且间隔收紧，
高潮前的窒息倒数。选型：强制聚焦指标用 B，高潮前蓄压用 C。

## 两式选型
| 式 | 做法 | 适用 |
|----|------|------|
| B jump-cut-punch-in | origin 钉目标中心，三档 CSS zoom 阶梯跳变（零补间），每跳 2f 压暗脉冲 + 镜头外倍率读数跳格当 tick；每挡多给一层信息（语义缩放） | 逐级逼近核心指标；纪录片式盯住 |
| C strobe-black-frames | 全屏黑帧按写死帧号表闪现（每次 2f，间隔 8f→3f 收敛），每闪倒数跳一格；末闪掀开即硬切放大 + 状态翻转落定 | 全片最高潮前的倒数蓄压 |

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| B 跳挡 | 1.0→1.6→2.6（跳点 40f / 80f），各挡 40f，挡内 1.2% in-out 漂移 | 挡差 <1.5× 读作画面抖了一下 |
| B origin | 按末挡构图反推：screen = O + (base − O)·s，令主角在 2.6× 下落在想要的屏幕位置 | 直接取目标中心常让末挡主角贴边、注释出画 |
| B tick | 跳变帧起 2f brightness 0.8 + 右上倍率读数 1.0×/1.6×/2.6× pop | 无 tick 的跳切读作丢帧 |
| B 语义缩放 | 1.0× 红点 ping / 1.6× 异常色带+标签 / 2.6× 采样点+读数卡 | 三挡同一信息量，第三跳就只是"更大" |
| C 帧号表 | [44,52,59,65,70,74,77,80,83] 各 2f 近黑 | 间隔必须收敛；等距频闪只是闪没有"逼近" |
| C 压强 | 暗角 0.5→0.92、变形光条随闪次拉长、倒数 T–10→T–01 | 只有黑帧没有加码，读作信号故障 |
| C 落锤 | 末闪掀开一帧到位 1.35× + 遮幅撤掉 + 空心字转实心 + 2f 压暗 | 掀开后还在原构图，频闪就白憋了 |
| 收尾 | B 末挡 70f（含 46f hold）/ C 落锤后 65f；hold 段只留 1.5–2% 极缓推进 | 打断系事后 hold 从重给 |

## 已知坑
- demo 用手搓画面调校（B：暖黑 ember 监控折线图事故回放；C：黑 + 信号红
  预告片字标海报）——参数是调校起点非实战定稿，首次实战须以真实素材回验
- B 式放大走 CSS zoom（布局级缩放）而非 transform scale，2.6× 下字和线才锐（Q2）；
  镜头外 HUD（取景角、时间码、倍率读数）放在 zoom 层外，不随跳切放大
- C 式空心字别直接用 -webkit-text-stroke：系统粗体字形轮廓互相重叠，会把内部重叠线
  也描出来；用 SVG 遮罩（描边字 − 实心字）只留外轮廓
- 两式与 speed-ramp-freeze 都动"时间轴"，同一镜头只能有一个时间
  操纵者
- C 式**光敏警示**：频闪画面需注意光敏性癫痫观众提示；且必须配乐
  渐强同步（无声频闪读作信号故障），全片 ≤1 次
- B 式三挡构图必须同 origin（钉死目标中心）——每挡重新构图就是
  三个镜头，不是跳切
- 声音强依赖：B 每跳一声 tick、C 每闪一声打点（sound-design §4.5）
