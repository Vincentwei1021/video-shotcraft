---
name: tension-camera-moves
一句话: 情绪运镜四式——bullet-time 冻结环绕、dutch-roll 斜角滚正、slow-push 慢推压迫、pull-back 拉远孤立，相机替观众"感受"而非"看"
适用: 情绪节点（震撼/纠偏/积压/收束）的运镜语言；与 space-camera-moves 的"炫技大动作"互补——这四式动作小、情绪重
时长: 单式 5–6s（150–170f）；全片合计 ≤2 式（各 ≤1 次）
能量: A 高 / B 中 / C 低压升 / D 低收
---

## 意图
space-camera-moves 三式是"把页面当 3D 实体拍"的高光炫技；这四式相反——
动作本身克制，全部劲道在情绪语义上：A 说"这一刻值得停下时间看"
（运动中的元素被冻住、相机绕行审视）；B 说"问题解决了，世界被扶正"
（斜角悬着的难受感在节拍上滚回水平）；C 说"有什么要发生了"（慢到
不自觉的推近积压张力，顶点硬切释放）；D 说"最后只剩这一件事"
（后拉中周围逐层熄灭，孤悬一点收束全片）。四式各占一个情绪格，
是分镜阶段"这一段观众该感到什么"的直接词汇。

## 四式选型
| 式 | 做法 | 适用 |
|----|------|------|
| A bullet-time-freeze-orbit 冻结环绕 | 图表生长到一半连同柱顶喷出的火花一起冻住（火花悬在半空、拖尾保留），相机在真 3D 场景里绕面板 rotateY 扫 52° 再回，时间恢复接着长完 | 核心数据/图表的加冕时刻；"值得停表看"的一格 |
| B dutch-roll-to-level 斜角滚正 | 痛点段整帧（含坐标纸网格）-10° 斜角悬着（叠微漂移），解决方案一拍带单次过冲滚回水平，内容随后跟随"愈合" | 痛点→方案的翻转节拍；纠偏语义 |
| C slow-push-in 慢推压迫 | 4s 匀加速三层视差推近（主体 1.00→1.14）+ 暗角渐深，张力顶点无过渡硬切亮场 | 大数字/宣言前的蓄力；暗→亮的章节爆点 |
| D pull-back-isolation 拉远孤立 | 从主卡特写后拉，周围一整面屏幕墙按距离由近到远加速熄灭、环境光随之沉黑，孤卡在一束顶光下悬在暗场中央 | 结尾收束；"全片只为这一个数字"的谢幕 |

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| A 双时钟 | 内容动画吃 `eff`（速度坡道积分：8f smooth 刹停 → 冻结 52f → 8f 恢复），相机吃真实 f | 命门：冻结期内容必须肉眼可见地完全静止，相机却在动——两个时钟各管各的；硬停硬起没有子弹时间的变速感 |
| A 环绕 | perspective 1800 的 preserve-3d 场景（面板 / 带 z 深度的火花 / 网格地面 / 远处点阵墙）：rotateY 0→-52°（26f smooth）→ 顶点慢漂 12f → 回 0（22f swift），同步 rotateX 抬 6°、推近 160px | 50–55° 是"绕到侧面看"的下限；>70° 面板变纸片穿帮；没有深度参照物（单面板 + 纯色底）读不出是相机在绕 |
| A 冻住的运动 | 火花拖尾长度、计数器滚动模糊都按内容时钟的速度算 | 冻结时它们保持"运动中"的形态——冻住的是瞬间，不是静物 |
| B 斜置 | rotate -10° + ±0.8° 长周期正弦漂移 + 2px 纵漂；整帧铺一张比画面大一圈的网格（旋转不露边），scale 1.08 | 漂移是"悬着难受"的活感，纯静止斜角读作构图错误；网格与画框的错位让斜角一眼可见 |
| B 滚正 | 滚正前 6f 再压 0.6° 蓄力 → 13f snappy 冲过 0 到 +1.2° → 11f smooth 收回 0（单次过冲不振荡）；scale 同步 1.08→1.00 | 过冲即"扶正的手劲"；振荡两次以上读作弹簧玩具 |
| B 跟随 | 整帧先转，内容晚 4f：数字回落、曲线从左到右逐点愈合、指标跌破阈值那一帧状态才换 | 状态先于数字变就自相矛盾（"Operational" 配着 900ms） |
| C 推近 | `scale [0,120f]→[1.00,1.14] Easing.in(quad)`（主体），中景 1.10、远景 1.03 同曲线 + 暗角 opacity 0→0.6 | 加速曲线是本体——匀速推读作普通 zoom；幅度 >1.2 变成普通推镜头；分层才有深度 |
| C 硬切 | 顶点帧零过渡直切下一景；暗景 A→亮景 B 反差要大；同一元素（demo 为进度条 97%→100%）跨切点同位 | 切的一拍才是释放；加任何过渡等于把弓拉满又慢慢松掉；切后只允许余波（副句升起、1.035→1 呼气） |
| D 后拉 | scale 2.4→0.62 / 118f bezier(0.33,0,0.15,1)，origin 锁主卡中心，按 2.4× CSS zoom 布局 | 前 20f 主卡仍占满画面，开场即特写不需要另加 hold；transform 放大的特写字会糊（Q2） |
| D 熄灭 | 44 块小屏按到主卡距离排序，28f 起按 EASE.out 错峰（62f 跨度，越往外越密）；每块先内容断电 6f，再 14f opacity→0 + 下沉 0.96 + brightness→0.35；环境光 ∝ 亮屏占比 | 由近到远熄灭 = "世界向外塌暗"；乱序熄灭读作故障；环境光不跟着暗，画面就是"卡没了"而不是"灯灭了" |
| D 光晕 | 70–112f 主卡白色轮廓光 + 两层冷白 box-shadow + 一束收窄的顶光 | 光晕是"只剩它"的视觉证词，与沉黑同步才成立 |
| 收尾 | 四式动作完毕 hold ≥30f（只留光的极缓呼吸 / ≤1.5% 推近） | R1；D 式是全片句号，静止给足 40f+，可在屏幕空间加一句结语 |

## 已知坑
- demo 在灰阶/占位素材上调校通过——参数是调校起点非实战定稿，
  首次实战须以真实素材回验
- C 式"前 2 秒不可察"是设计意图不是缺陷——裁决/验收看完整播放，抽帧
  diff 前段变化极小属正常（已确认成立）
- A 式与 speed-ramp-freeze/impact-feedback 同为时间操纵，同一镜头别叠用
  （帧 remap 互相打架）；A 的冻结是"停给你看"+相机动，speed-ramp 的
  定格是"停下来标注"——选语义不选形似
- B 式斜角只压"痛点"段——全片常态斜角是 MV 语言，产品片里读作镜头没扶稳
- C 式硬切后的亮景必须信息完整可读（它承接全部积压的注意力）；
  切进另一个铺垫段等于白蓄力
- D 式放结尾时后接 outro-group-photo-launch 会打架（一收一放），二选一
