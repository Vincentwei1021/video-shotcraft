---
name: chip-lift-to-user-pill
一句话: 网格里的目标 chip 先 3 档台阶硬切反色（暗场里是深灰→近白实体），其余 chip 按到它的曼哈顿距离交错淡出缩小；反色 chip 左缘锚定向右生长成药丸，内部逐字打出人名并点亮绿点，再拉一条发光细线接到圆形徽标
适用: "从一堆候选里选中并展开这一个"的交互链路；协作/通讯录/收件人类产品的功能演示；选中→详情的转场
时长: 约5.5s（165f@30fps）
能量: 中（选中那一下是硬爆点，之后全是从容的生长与打字）
---

## 意图
让"选中"这件事有**两段完全不同的质感**：选中瞬间是硬的（3 帧台阶化反色，
像真实 UI 的 `:active`），选中之后是软的（药丸生长、逐字打字、绿点点亮）。
其余 chip 按距离交错淡出，是在告诉观众"注意力从这里开始收拢"——
距离排序比时间排序重要，因为它给出了空间上的因果。

## 动效核心
- 4×3 网格（1080p 原生：chip 168×100、圆角 50、间距 24、40px 缩写），目标位于第 2 列第 2 行；
  入场按到目标的距离由中心向外错峰升起（2 + dist×3.5f）
- **反色硬切**：38–39f 原色 → 40–41f 半灰 → 42f 起近白（只有 3 个取值、不缓动）；
  背景 / 描边 / 文字同步跳变，阴影随选中抬起
- **距离交错淡出**：其余 chip 按曼哈顿距离 `|Δcol|+|Δrow|`，`d0 = 44 + dist×3.3f`，各 11f（outQuad），
  opacity 1→0 + `scale 1→0.9`；眉题同时 ease-in 退场
- **左缘锚定生长**：`g = ramp(58f, 30f, outCubic)` 驱动 width 168→640px，`left` 不变
- 人名逐字：以 `g` 为自变量，字符 `0.16 + i×0.058` 起、各 0.06，`translateY 12→0`；原缩写在 `g×5` 内先撤；
  职能副标签在 g 0.78→0.95 淡入
- 在线点 18px `#7fd000` + 光环 + 泛光，在 g 的 0.85→1 段 overshoot 弹出，`left = w − 56` 始终吸在药丸右端；
  同时药丸底下亮一抹荧光绿落地光
- 连接线 96→110f outQuad 从 0 拉到 170px（3px 荧光绿渐变 + 泛光，线头带领跑光点）→ 徽标 108f spring 弹入
  （scale 0.8→1）→ 字幕 112f 显形、逐词加深（末词人名染强调色）→ 副句 122f 从线下升起（字幕与药丸左缘对齐）
- 机位：选择与生长段静止；90→126f smooth 横移 + 上移把结果组送到画面中心并推近 5%，hold 段再缓推 1.5%

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 反色时长 | 38→42f，台阶化成 3 档（每档 2f） | **不要给它缓动**：连续插值读作"渐变高亮"，台阶才读作按下 |
| 距离间隔 | 3.3f / 曼哈顿距离 | 按 index 排序也能错峰，但按距离才有"从选中点扩散"的空间因果 |
| 余项退场 | 各 11f、opacity→0 + scale→0.9 | 只淡出不缩小会显得"被擦掉"；缩到 0.9 才像退到后面 |
| 药丸生长 | width 168→640px，58→88f outCubic，左缘锚定 | 双向生长（居中扩张）会把它读成弹窗，不是同一个 chip 长大 |
| 逐字打字 | 以 g 为自变量，间隔 0.058、各 0.06 | 挂在 g 上而不是帧上：改生长时长时打字节奏自动跟随 |
| 在线点 | 18px + 光环 + 泛光，g 的 0.85→1 段 overshoot | 必须在生长收尾才亮：早了就成了"已在线"，不是"刚接上" |
| 连接线 | 0→170px，96→110f outQuad | 线要在药丸完全定型后才起笔，否则读作药丸在被拽 |
| 徽标 | 104px，108f spring(damping 14)，scale 0.8→1 | 与连接线抵达重叠 2f，才有"线到即物到"的交棒 |

## 已知坑
- 目标 chip 必须画在其余 chip 之后（最上层），否则生长时被右侧 chip 盖住
- 药丸内的人名容器 `left:40px` 是按 100px 高的 chip 配的内边距；改 chip 高度要同改，否则文字贴边
- 在线点的 `left = w − 56` 每帧重算——写死坐标后一改 PW1 就飞出药丸
- 连接线、徽标与机位终点的坐标全部基于 `TX + PW1`（药丸终态右缘），改生长终值必须同改
- 占位内容：12 个双字母缩写 + 人名 "Noor Haddad" + 字幕 "Starting a thread with Noor"，落地全部替换；
  人名字符数变化会改变打字总时长（0.16 + 0.058 × 字符数必须留在 g 的 1.0 以内）
