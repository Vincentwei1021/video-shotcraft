## 意图
库内光标一直是"操作工具"（input-trigger-moves 的 cursor-performance
是单光标点击表演）。本卡把带身份名牌的协作光标升格成**演员**：
A 式两枚具名光标在纯暗场用位移编排讲"设计-开发交接"——没有一个 UI
元素，观众照样看懂了剧情，光标位置关系就是台词；B 式五枚光标错峰
入场后持续漂移当氛围粒子，"团队在场"感全靠它，其中一枚还能停下来
打字（cameo 戏份）。SVG 光标+名牌 chip 成本极低、叙事密度极高，
是"协作"主题最便宜的视觉论证。

## 两式选型
| 式 | 做法 | 适用 |
|----|------|------|
| A dialogue-duet | 冷蓝/琥珀两枚具名光标在黑匣子剧场里：贝塞尔入场→名牌展开成 cursor chat 气泡打出台词→上下扁弧绕位交换（追光钉在说话位，谁走进光谁亮）→琥珀光标预备后缩再对数缩放冲镜成巨箭头整屏遮挡→遮挡面升起标题成海报 | 双角色交接叙事（设计→开发、你→AI）；需要一段无 UI 的纯叙事呼吸拍 |
| B cast-ensemble | 5 枚具名彩色光标错峰 spring 飞入白板画布（头像组同帧弹出、便签带作者色）→双频正弦漂移驻场→一枚挂在插入点上打出简报卡标题→结尾全员 smooth 聚拢围观 | 画布/白板类产品全片氛围层；主内容之外需要"别人也在"的背景活性 |

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| A 位移 | 全部曲线：入场三次贝塞尔路径 + snappy 28f / 探身 swift 14f / 绕位 smooth 36f / 站定时双频微漂 ±5px，无 linear | 直线+linear 立即读作"程序在挪图标"；曲线+缓动才是"人在动" |
| A 绕位 | 各以自己起止点的中点为圆心同向转 π（左侧起步走上弧、右侧起步走下弧），纵向压扁 45%、半径中段外扩 10% | 同弧同向会相撞感；上下分弧是"礼让"的身体语言；不压扁的话两人间距 700px 时弧顶会出画 |
| A 灯光交接 | 一盏追光钉在台口左侧说话位（体积光锥 + 地面光池），lit = 光标身体到光心距离 120px 内全亮、340px 外全暗；暗处光标往石墨灰去饱和 62%、名牌 opacity 0.42 | 一亮一暗是"话语权移交"；两个都亮读不出主从。光跟着人滑会在绕位中段打在两人中间的空地上——钉住光、让人走进走出才是交接 |
| A 转场放大 | 136–144f 预备后缩 12% → 142–162f 冲镜：倍率在对数空间走 t^2.4（5.6→380 px/单位），箭头体内锚点 (4,8.5) snappy 移到画面中心，~160f 整屏遮挡；遮挡面上升起标题 | 对数空间 ease-in 才是匀加速的"冲过来"，线性倍率前半段几乎不动、最后一帧才爆；锚点必须离各边 ≥3.4 单位才盖得满；巨箭头即前景遮挡物，接 transition-hidden-cut 语法 |
| B 入场 | 5 枚 delay 2/7/11/16/22f 错峰，spring(damping 15, stiffness 80)；名牌晚 10f 淡入+上浮 12px；右上头像组同帧弹出（槽宽随弹出长） | 名牌跟光标同帧出现读作贴纸；随减速淡入才是"人到了自报家门" |
| B 漂移 | 双频正弦叠加（0.055/0.021 rad/f，每枚相位不同），幅度 ±40/26px | 单频正弦读作钟摆；双频不同相才是"人手的随机" |
| B 打字 cameo | 48–104f 打 28 字（1.6–2.4f/字确定性抖动，空格后多停 0.9f）；光标箭头挂在行内插入点锚点上，换行也跟着走；打字时手稳（漂移压到 0） | 箭头和插入点分开算位置必错位；行内零宽锚点让浏览器排版替你算 |
| B 聚拢 | 98f 起 28f smooth 到卡片四周围观位（不压标题和眉题），漂移幅度衰减到 25% 保留 | 聚拢后漂移不能归零——完全静止的光标群读作死机 |

## 已知坑
- demo 在手搓画面上调校通过（A：石墨剧场 + 追光；B：瓷白白板 + 便签 + 简报卡）——参数是调校起点非实战定稿，
  首次实战须以真实素材回验
- 名牌颜色=身份编码，全片必须一致（蓝=Designer 就一直蓝）；中途换色观众会以为换了人
- A 式是全片一段的"戏"，≤1 次（P4）；B 式是可全片驻场的氛围层，两式同片可共存但 A 的两枚主角要从 B 的群演里出（同名同色），否则读作两拨人
- B 式漂移光标永远不许盖住正在阅读的主内容——氛围层要让戏，漂移范围避开主体安全区
- 与 input-trigger-moves 分工：那是光标"操作 UI"（点击有 payload），本卡光标"表演给你看"（位移即剧情）；光标要点东西时回那张卡
- 声音：A 绕位配轻 whoosh、交接一声柔和 chime、放大甩出一声重 whoosh；B 入场每枚一声极轻 pop，漂移段静，打字段 keyboard 轻声
