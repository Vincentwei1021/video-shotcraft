## 意图
Raycast/Linear 发布片的标志性仪式：一声轻响，整个 UI 世界压暗
让路，⌘K 面板从中心上方弹落，候选列表错峰浮现；敲两个字母，
列表实时收窄——"你要的一切都在这个输入框里"。模拟交互按真人
操作速度走（R3），收窄的"挤压感"来自行高塌缩而非淡出。

## 动作阶段
| 阶段 | 帧段参考 | 内容 |
|------|------|------|
| 1 静置 + 动机 | f0–14 | 产品界面清晰静置；画面下方 ⌘ K 大键帽浮现，f10 按下（下沉 + 强调色底光一闪） |
| 2 让路 | f12–26 | 世界后退 4% + 亮度压到 ~42% + blur 12px + 降饱和 35%（smooth） |
| 3 降临 | f16–34 | 面板 -56px 落入，spring damping 14 一次可见过冲（与压暗跨骑）；落地时背后一次强调色泛光 |
| 4 候选浮现 | f22–49 | 6 行每 3f 错峰上浮（与弹落跨骑） |
| 5 输入收窄 | f62/74/86 | 三次按键，每键 +3f 起行高塌缩 10f，6→4→3→2（塌缩完条件卸载），匹配片段强调色加粗、计数同步 |
| 6 选中定格 | f100 起 ≥50f | 首条高亮从左扫满（浅底 + 左缘亮条 + 图标块转实色 + ↵ 键帽弹出），光标转常亮，只剩 1→1.03 极缓推镜 |

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 压暗 | 亮度 ~42% + blur 12px + 后退 4%，14f smooth | 压不够面板不突出；全黑失去上下文 |
| 弹落 | 起点上方 56px，spring damping 14 / stiffness 160 | 无过冲读作淡入，仪式感没了；damping <12 回弹两次读作果冻 |
| 候选错峰 | 3f/行，与弹落跨骑 | 同帧出读作贴图；等面板落定再出会留一个空盒子死帧 |
| 收窄 | height→0 + overflow hidden 塌缩 | 淡出收窄没有"挤压"感；塌缩完必须卸载 |
| 光标 | 闪烁周期 16f；f112 后强制常亮 | 闪到结尾就永不真静止（demo 判例） |

## 已知坑
- demo 在手搓暗色部署控制台（midnight 深蓝 + 电光蓝）上调校通过——参数是调校起点非实战定稿，
  首次实战须以真实素材回验（背景世界应换成产品真实截图，Q1）
- 输入节奏按真人打字速度（R3 判例），两键间隔 ≥12f；查询词要设计成每一键都有行塌缩（demo：dep → 6/4/3/2），某一键不收窄会读作卡顿
- 组合款见 theme-switch-moves B 式（面板收缩成点引发主题涟漪）
- 实战候选行放真实功能名——这是功能清单的天然展位（P4 映射）
- 声音：唤出一声轻响（非游戏音），按键 2 声键帽拟音，
  高亮一声轻 pop（S1/S4 同源）
