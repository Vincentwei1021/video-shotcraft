---
name: counter-confetti
一句话: 大数字机械滚轮冲刺计数、最后一次进位弹簧落定，到位前一拍彩纸从两侧礼炮抛物线炸入，泛光一闪、副标题升起收尾
适用: 里程碑/成绩数字的庆祝拍：用户数、营收、下载量等"值得开香槟"的指标揭示
时长: 约 5.7s（172f@30fps；计数 0.27–2.1s · 进位 + 纸屑 2.2s 起 · 落定 2.4s · 纸屑 5.3s 前清场）
能量: 高（计数蓄力 + 爆点释放，标准的情绪峰值镜头）
---

## 意图
数字不是"显示"出来的，是"冲线"的：计数曲线前快后慢像百米冲刺进入慢镜，纸屑在数字到位**之前**抢拍爆开——庆祝比结果先到半拍，情绪压过信息，观众先兴奋再看清数字。

## 动效核心
- 计数器做成七位机械滚轮（每位一条竖向数字带，tabular-nums）：个位连续转，高位按真实进位规则只在下一位 9→0 时被带着翻一格；转速快的位按速度加竖向运动模糊并变虚；未到的高位是暗色"幽灵零"，开场第 1 帧就有 0,000,000 的空槽
- 计数两段（8–64f）：expo-out 冲到 0,999,999——前 1/4 时间跑完九成，低位越转越慢，观众在等；停 2f 后 66f 六位同时 9→0、最高位 0→1，一记物理弹簧进位（damping 18，~8% 一次过冲）——"咔哒"就是到位
- **抢拍**：纸屑在进位弹簧起跳的同一帧（66f）射出，数字 ~6f 后才落定——庆祝先于结果，这半拍是这张卡的灵魂
- 120 片纸屑真物理：左右下角两门礼炮（画外）斜向上射入，初速 vx 420–1920 向中 / vy −1900~−3000，重力 g 1000–1320，线性空气阻力 k=2.1（顶点在画面上 1/4、下落趋于终速），自转 + 绕自身轴翻转（高度随 cos 压扁、背面变暗）、下落飘摆，远/中/近三层景深（近景大而虚、从数字前掠过）
- 配色：香槟金箔（高光随翻转相位掠过）/ 强调橙 / 奶白三色，与 look 同源，不用彩虹 8 色
- 落定：数字整体 1→1.05→1 弹一下，背后金色泛光提亮后缓落 + 一道横向光带（只一次）；副标题 80f 起逐词从线下升起，品牌名用强调色

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 计数曲线 | expo-out，8–64f 冲到 999,999 + 2f 停顿 + 弹簧进位 | 直接 ease 到 1,000,000 的话最后一次进位挤在末 2 帧、读不出来；拆成"冲刺 + 进位"两拍 |
| 抢拍量 | 礼炮 = 进位起跳帧，落定晚 ~6f | 同拍读作"结果出来了再庆祝"；>10f 纸屑像"别人的庆祝" |
| 纸屑数量 | 120 片（3 色） | <60 稀疏不成雨；>160 遮数字 |
| 重力/阻力 | g≈1000–1320、k=2.1 → 终速 ~480–630px/s | 决定落完的时间：172f 全长下 ~160f 前清空，尾段留干净海报 |
| 进位过冲 | 弹簧 damping 18 / stiffness 220（~8%） | <14 过冲 >15%，逗号和数字会明显错位；>24 没有"咔哒" |
| 滚轮窗口 | 1.3em 高，上 12% 全透明、上下渐隐 | 上沿不透明会露出上一格数字的底部（一排"笑脸"） |
| 字宽 | 每位步进 0.64em，clip-path 只裁上下 | overflow:hidden 会把粗体 0 的左右弧切平 |
| 终值 | 1,000,000（演示值） | 换真实数字：位数与逗号位置跟着改，保持"从 0 滚到终值" |

## 已知坑
- 纸屑物理按真实秒（(f−LOCK)/30）算，改总时长不影响手感；但改 g / DRAG 会改变清场时间，尾帧前要确认画面干净
- 抢拍帧 = 进位帧 LOCK，是同一个常量——改计数窗口时 COUNT1 与 LOCK 一起平移，保持 2f 停顿
- 低位转速远超 1 位/帧时数字带位置会混叠，必须靠竖向模糊 + 降不透明度藏住，别去掉模糊
- 配 SFX：计数段 tick 渐密（滚轮咔嗒）+ LOCK 拍 pop/confetti + 落定拍 impact——三层缺一情绪都塌（对照 sound-design.md counter 类）
