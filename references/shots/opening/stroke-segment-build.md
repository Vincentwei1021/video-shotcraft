时长: 165f（5.5s；揭晓 f105 后 hold 2s）
能量: 低起中收（悬念型，落位帧是能量点）
标签: typography

## 意图
《异形》片头判例：标题不是被画出来的，是"显影"出来的——拆成离散
笔画段乱序点亮，观众前 70% 时间只看到神秘碎段，最后几段落位的瞬间
突然读出是什么字。"认出的那一刻"就是钩子，钩子的强度取决于
不可读期撑多久、钥匙段压多晚。

## 动作阶段
| 阶段 | 帧段参考 | 内容 |
|------|------|------|
| 1 暗场 | f0–12 | 深紫墙 + 极淡墙面光静置（不是死黑） |
| 2 乱序点亮 | f12–72 | 前 13 段起点按 ease-out 分布（间隔 9f 越来越密到 3f）；每段是 7f 霓虹起辉抖闪（亮—灭—亮—半亮—亮），之后以 0.58 亮度稳住 |
| 3 屏息 | f72–86 | 14f 不新增任何段，只有灯管电流的微弱嗡动——悬念最紧的一拍 |
| 4 钥匙段 | f86 / f93 / f99 | S 下脊 → H 中横 → P 碗底，三拍落下 |
| 5 揭晓 | f105 | 全部灯管 0.58→1、电流涌起冲到 1.25 再回落（灯牌自身宽泛光涌一次）、整字 scale 1→1.02、墙与地面被照亮 |
| 6 定格 | f113–165 | 副题升起后 hold，镜头全程 1→1.035 极缓推近 |

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 拆段粒度 | 4 字母 16 段（单线几何字 260×400/字，灯管线宽 30，圆端帽，两端各留 4% 电极缝） | 段太少悬念期短；太碎读作噪点。S 拆成两段反向弧各 3 段 |
| 乱序表 | 手工排：跨字母乱跳，"可读性钥匙段"（S 下脊 / H 中横 / P 碗底）压到最后 3 段 | 顺序点亮 = 没有悬念；钥匙段早出 = 提前泄底 |
| 点亮节奏 | 疏→密（9f→3f，`stagger(.., EASE.out)`）→ 屏息 14f → 三拍 7f/6f | 匀速等间隔没有张力；屏息 <8f 感觉不到，>20f 读作卡住 |
| 不可读期 | 前 13 段（约 60% 时长）读不出字 | QA 抽中段帧自问"能猜出来吗"，能猜出就重排 |
| 半亮 → 满亮 | 悬念期 0.58，揭晓 1.0 + 涌起 1.25 | 悬念期太亮（>0.8）揭晓就没有"通电"的对比 |
| 落位脉冲 | scale 1.02 + 光的涌起 | 霓虹是挂在墙上的物件，大幅缩放会假；冲击交给光 |
| 墙面受光 | 环境光 = 0.12 + 0.5×已亮段占比 + 揭晓/涌起 | 灯越多墙越亮，物理上可信；常量墙光会让点亮失去分量 |
| 地面倒影 | 沿地面交线镜像、blur 5px、opacity 0.42、离地越远越淡 | 遮罩写在镜像前的本地坐标里，交线以上必须全透明 |
| 未亮段 | 条件不渲染（非 opacity 0） | 收尾真静止与"不泄底"的前提 |
## 已知坑
- demo 是霓虹灯牌版（aurora 暗场）；换别的材质（LED 段码、发光描边）时起辉曲线与半亮值要重调
- 暗底上的辅助文字用亮灰——demo 首版顶部标题深灰压深底不可见（P1 自检抓到）
- 揭晓泛光别另画一团径向光斑——会在字中间形成一个脏亮点；让灯牌自己的宽泛光（形状就是字）涌起一次
- 倒影是整块灯牌渲染两遍（每遍两层 SVG 高斯模糊），单镜头渲染成本翻倍；性能吃紧时先砍倒影
- 字数上限：4–6 字母词最佳；长词不可读期难控制，段数爆炸
- 本卡吃"识别瞬间"，标题必须是观众认识的词（产品名/SHIP/LIVE 类），
  生造词没有"认出"可言
- 声音：逐段点亮配霓虹起辉的短促电流 tick（稀疏、音量阶梯递减），屏息段只留低频嗡声，落位帧一声 impact + 可接 riser 铺底
