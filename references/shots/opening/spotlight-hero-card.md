一句话: 关灯的剧场里一束钨丝聚光（带体积光柱）扫过页面锁定一张卡，斜侧推进后卡片弹起悬浮、香槟色光束沿轮廓两圈、连同 3D 注记一起贴回原位
适用: "单一主角"式产品开场；把一个核心对象（卡片/条目/模块）立成全片主角
时长: 172f（约 5.7s；锁定 f34 → 触地 f142 → 30f 真静止 hold）
能量: 中（质感最高的一镜，节奏慢而稳）
标签: effects、camera

## 意图
开场只讲一件事：这一张卡就是产品的原子单位。聚光灯替观众做视线引导，弹起悬浮给它体积和重量，轮廓光束是"扫描/检视"的隐喻，最后贴回原位表示它属于这个页面。

## 动效核心
- **关灯**：真实页面截图（Q1）整页 multiply 压到 ~6–14% 亮度（暖黑 rgba(14,12,10)，保色相），只有光池里是页面本色；
  开灯是"推闸"：f1–6 亮 → 回闪到 62% → 稳住
- **光池**：近高斯衰减的多段 stop（中心透明 → 边缘全暗，不是一圈硬边）+ 低强度钨丝暖白 soft-light；
  游走 3 个中间站（站间 2–3f 停顿，smooth in-out）后锁定卡心，光池收拢 + 锁定瞬间 6% 脉冲，光池外再压暗一档；
  锁定后（f38–58，随推进）屏幕空间的圆光池交叉过渡成**页面空间的卡形光**：同一台相机下一层整页暗场
  （translateZ 1px，0.94 暖黑）在卡位挖一个卡形软孔（紧孔 σ22 + 一圈 15% 的宽溢光 σ60），卡在 z 上高于
  这层暗场，所以从边到边全亮、保持原生文字对比，衰减只发生在卡外；soft-light 暖光同步退掉（卡上不叠泛光）；
  卡边一圈暖白发丝轮廓光 + 极淡外溢让轮廓在暗页上读清；hold 段暗场 ±1.2% 极缓呼吸
- **体积光柱**：光源在画面上方偏右远处，梯形光柱打到光池（外层 blur 28px、内层 clip-path，边缘软），
  柱内一层确定性浮尘；推进后光柱减淡 45%
- 相机从全页正视推进到斜侧特写（左侧机位主导），焦点左移让卡落在画面偏右、左侧留给注记；推进后完全锁死
- 卡片 rise（带过冲）→ 悬停 sin bob → reseat（落地微压 + 一圈香槟色落地光）；悬浮投影落向左下（光从右上来）
- SVG rounded-rect 轮廓光束跑两圈：第一圈快而亮、第二圈慢而弱（香槟金 + 白芯）
- 卡起飞后原位铺页面底色补丁 + 香槟色描边，落地瞬间增亮消失
- 3D 悬空注记（hover-3d-annotation 手法，C3）：卡左侧白色粗黑体两行「One card, / one project.」（34px 页面空间，
  推进后 ≈100px），关键词背后 12f 长出香槟色马克条（字翻成墨色），注记下垫暗色衬底压住邻卡文字；
  注记层用与页面同一套相机数学（camAt）单独画在灯光层之上——它是自发光的字，不被关灯压暗。
  reseat 时注记同步落回页面平面（translateZ 92→4），不提前退场，结尾是一张完整海报
## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 选卡 | cards[3]，中心 x 恰为 960（页面中心） | 主角卡先按"推进后构图"选，不是随便挑一张 |
| 相机 | 静止全页 zoom 0.8（0–40f）→ 18f 推进 zoom 2.6；rotY 34° 主导 + rotX 仅 8°，persp 1200；焦点取卡心左移 105px、上移 10px；推进后锁死到尾 | 侧向水平机位读感优于俯拍（"从左侧拍摄而不是从下方"，Q6）；收尾禁用 zoom 2.6→2.58 一类尾漂，呼吸交给光而不是相机（R1） |
| 关灯 | 光池外 multiply 0.90→0.94（≈6–10% 亮度） | <0.8 读作"调暗的页面"不是剧场；>0.96 邻卡完全消失、失去"在页面里"的上下文 |
| 聚光灯 | 3 个中间站（4→28f），光池半径 400→300，锁定 +6% 脉冲；soft-light 暖白 0.24；锁定后换成卡形光 | 圆光池罩卡会两头落暗、中间打爆（"手电筒照页面"）——主角卡要用卡形软孔从边到边打亮；中间站让"随机照射"可信 |
| 体积光柱 | 光源 (pool.x+420, −720)，柱宽 0.6×光池；screen 0.34→0.06 纵向渐变 | 光源太近读作手电筒；柱太宽会和光池糊成一团 |
| 动作弧 | rise 10f（bezier(0.2,1.25,0.3,1) 过冲）→ 悬停 58f（sin bob 振幅 4px 周期 40f，z=110px·lift）→ reseat 18f，落地 press 0.997 | 锁定→落地 ≈108f≈3.6s——质感镜头要"放慢到 3 秒"（R3），初版几乎总是偏快 |
| 轮廓光束 | lap1 68→82f（strokeWidth 5+2.5 双层）、lap2 88→108f（3.5+1.75、整体 opacity 0.62）；strokeDasharray "0.16 1" 走 dashoffset | 两圈快慢有别才读作"持续扫描"，一圈是眨眼；光束只给主角一次（Q4） |
| 双层影 | 偏左下 `-10·lift, 10·lift …, -36·lift 48·lift 90·lift` 随高度生长 | 影子不随高度长，悬浮就不成立；方向要和光源一致 |
## 声音
开灯推闸钉一记低沉的 light-clunk（f2），弹起钉 whoosh-big（本 demo f56；模板片钉在 f127），光束扫描钉 sparkle（f68），reseat 钉 transition-snap（f142）——弹起/光效/落定各有专属音（S2、S4）。

## 已知坑
- 开场多卡群舞撑不起第一印象（Q5）——开场曾反复推倒多次才收敛到单卡；直接从单主角+完整动作弧起稿
- 推进特写下卡上文字会糊，根因是纹理栅格化分辨率不是 DoF——配套技法展开见审美准则 Q2
- 逐卡 glint 闪烁被两次否决（"不需要每个卡片都闪烁一下"，Q4），光效严格只给主角
- 卡形光的暗场必须在页面空间（PageCam 内、translateZ 介于页面与卡之间），屏幕空间的遮罩跟不上透视与卡的抬升；卡 translateZ 至少 +2px，reseat 后才不会和暗场共面闪烁
- 注记的暗色衬底右缘要止于卡左缘之前，否则会在卡面左侧压出一道暗楔
- 注记若画在 PageCam 内、灯光层之下，会被关灯的 multiply 一起压暗成灰字——注记层要单独套同一台相机画在灯光之上
