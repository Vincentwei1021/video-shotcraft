---
name: vertical-word-roll-blur-cycle
一句话: 句尾词换成竖向 3D 转筒，3 次换词越换越密（outQuint 七成 + outBack 三成，前快后极慢带微过冲），相邻行按距离前缩、垂直 blur 与灰度，中心词落定瞬间从灰染成强调色
适用: "Built for ___" 这类句干 + 受众/对象列举的一句话卖点；品牌片里干净有力的一拍
时长: 165f（5.5s@30fps：滚入首词 → 3 次换词 → 邻行滚走，留结论海报）
能量: 中（稳定三拍，无峰值）
---

## 意图
句尾换词的最优解是滚轮而不是淡入淡出：滚轮自带**方向**（往上翻页），
观众知道"还有下一个"。这卡的两个身份记号是相邻行的**垂直 blur**
（滚轮景深，模拟机械转筒的失焦；本版再把词真贴到圆柱面上做前缩）和落定时的**染色**（灰→强调色，
"这个才是答案"）。句干 `Built for` 全程纹丝不动——眼睛钉在滚轮上，
句干一晃列举感就散。

## 动效核心
- 舞台：lime 石墨暗场，176px / 850 字重一句大字（句干与滚轮同字号同字重、`-0.045em` 字距），
  一条横贯全幅的选取带（两条发丝线 + 极淡黄绿底）钉住中心行，左上眉题、右上 mono 计数 01→04
- 位置量 `p` 由 4 段窗累加（从 -1 起，第 0 段是开场滚入首词）：`STEPS = [[2,20],[36,18],[64,16],[90,24]]`
  （起帧, 时长）——hold 16f → 10f → 10f 越换越密，结论词那段最长最重
- 每段缓动是**混合曲线**：`0.7·outQuint(u) + 0.3·outBack(u)`——
  outQuint 给"前快后极慢"的机械减速，outBack 那三成给落定的微过冲回落
- **3D 转筒**：行高 ROW = 1.12·字号（197px），相邻行圆心角 θ=32°，半径 `R = ROW / (2·tan(θ/2))`；
  第 i 行 `φ = (i-p)·θ`，`translateY(R·sinφ) translateZ(R·cosφ - R) rotateX(-φ)`，父级 perspective 1500
- 距离驱动的三通道，`d = |i - p|`：
  - blur：`min(16, 7d)` px，SVG `feGaussianBlur stdDeviation="0 b"` 只糊纵向；转动时再按转速叠
    `min(14, speed·ROW·0.16)` 纵向运动模糊（静止为 0）
  - opacity：`d<1` 时 `1 - 0.62d`，否则 `max(0, 0.38 - 0.3(d-1))`，d>2.4 不渲染
  - 颜色：`mixHex(#7c8370, accent, clamp01(1 - 2.4d))` —— **d>0.42 就完全是灰色**，
    只有真正落定的那一刻才是荧光黄绿；落定瞬间再起一次 4f 泛光、16f 衰减（结论词留 0.35 余温）
- 句干与转筒行用同一个行盒（`lineHeight = ROW`）——基线严格对齐；句干开场逐词从行盒下沿升起
- 收尾不整组淡出：f112 起邻行淡出、选取带收起，只剩「Built for everyone.」+ 44px 副标题（尾帧是海报）

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 词表 | 4 词（speed→teams→scale→everyone.），3 次换词 | 末词是结论（最宽、带句点），前三个是例子；>5 词观众开始数，<3 词读不出"列举" |
| 拍点 | 换词 36/64/90 起，窗 18/16/24f | 段间 hold ≥10f 给读词；越换越密是节奏，结论那段放长加重 |
| 缓动配方 | `0.7·outQuint + 0.3·outBack` | outQuint 是机械减速的来源；outBack 那三成给落定"咔"一下，纯 outQuint 读作电子屏滑动 |
| 转筒几何 | ROW 197px、θ 32°、R≈343px、perspective 1500 | θ 太小读作平移、>45° 邻行几乎侧立看不出是字 |
| 视窗宽 | 4.45em（按最长词 everyone. 量） | 换词表必须重量；整组居中，短词右侧留白是固定宽的代价 |
| 相邻行 blur | 7px/行，封顶 16px，**仅垂直向** | blur 是"滚筒景深"的身份证，删了退化成词条平移；邻行 >12px 糊成灰条看不出是字 |
| 落定染色 | `1 - 2.4d` 映射灰→强调色 | 系数 2.4 让染色只发生在落定瞬间；<1.5 滚动中途就上色，答案感散掉 |
| 字号字重 | 句干与滚轮同为 176px/850、`-0.045em` | 必须完全一致——滚轮词比句干大就读作两个元素，不是一句话 |
| 收尾 | 末词 ~f108 落定，f112–130 邻行淡出，hold 到 f165 | 末词落定后 ≥1s 静置；不 hold 等于白列举 |

## 已知坑
- demo 在灰阶/占位素材上调校通过——参数是调校起点非实战定稿，
  首次实战须以真实素材回验
- **视窗宽度写死（4.45em）**：换词表时最长词（demo `everyone.`）必须能装进去，
  否则被裁字；反之词都很短则右侧留大片空白，句子重心偏左——换词表必须
  重量一次宽度
- 词长差别不宜过大：mask 宽度是固定的（本卡不做宽度自适应，那是
  pill-chip-slot-cycle-handled 的活），词长差 >2 倍时短词在框里显得孤立
- 句干必须钉死：demo 用 flex 并排是因为视窗宽度恒定不会推挤
  句干——一旦改成宽度自适应的滚轮，就必须换成绝对定位锚左端，
  否则句干随词宽左右甩
- `p` 是各段窗**累加**出来的，所以段窗不能重叠：重叠会让 p 在一帧内
  跨越一整行，滚轮"跳格"
- 句干的入场动画别套带内边距/负外边距的通用揭示组件（如 TextReveal rise 的遮罩框）——
  行盒高度一变，句干与转筒中心词的基线就差出 ~20px；两边必须用同一个 `lineHeight = ROW` 行盒
- 与 pill-chip-slot-cycle-handled 分工：那卡是深色胶囊 + 宽度自适应挤开
  （词是徽章），本卡是裸词滚轮（词是句子成分）——同片只留一个
- 声音：每次落定是一个节奏点，配轻机械/开关音；三连发要交替双样本
  防机枪感，配法纪律见 sound-design.md
