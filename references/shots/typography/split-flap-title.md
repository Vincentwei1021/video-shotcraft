## 意图
文字三式的第三式：压印（paper-title-card）是纸上落墨的"低语"，打字机
（document-typewriter-reveal）是文档被人写出来的"叙述"，翻牌是车站大屏的
"播报"——带机械宣告腔。选翻牌的语境：倒计时/发车感（版本发布、截止日）、
数据播报感（指标揭晓）、或想给标题一层复古机械质感。它天然是等宽深底
格子，在库内纸墨审美里读作"纸面上摆了一块机械显示屏"——异色块本身
就是看点，背景产品画面压暗降饱和给它让位。

## 动效核心
- 版式（demo）：一整块夜间出发大屏（暖黑外壳 + 上沿高光 + 内凹槽 + 落地暖光）：抬头「◆ DEPARTURES」+ 本地时间，
  第 1 行 128×176 大翻牌格的标题（字 132px，整行占画宽 ~75%），第 2 行 60×84 小翻牌格的航班号与状态，
  状态字用强调色——"异色块本身就是看点"由整块屏承担，不再需要背景产品画面
- 每字符一个翻牌格（上下两半 overflow hidden + 中缝铰链线 + 左右转轴销钉），字符序列 = 空白叶片 →
  若干乱码 → 目标字；**每格翻牌次数不同**（大行 3–6 次，种子决定），像真机械"离目标越远翻得越多"
- 单次翻牌两段式：前半旧字上半叶 rotateX 0→-90 掉落（Easing.in 重力感 + brightness 1→0.5），
  后半新字下半叶 90→0 拍下（回亮）；上半叶掉落时下半静态叶随角度压暗 ≤0.45；叶片快速段带轻微竖向模糊
- 级联：大行 14f 起 3f/格、单次 4f；小行 44f 起 2f/格、单次 3f，状态组接在航班号后面翻——两层节奏叠成一道波
- 停定咔哒：整格按格高 3.4% 下沉回弹（大格 6px：下沉 → 过冲 -25% → 归零，7f）
- 状态组全部落定（~101f）后状态格背光一次强调色泛光、状态灯亮起并缓慢呼吸（hold 段不死）
- 机位：全程极缓推近 1→1.045 + 俯角 4°→1.2° 缓收（smooth），角度小到不影响读字（Q6）
- 乱码用 seed 正弦哈希（sin(a·127.3)·43758 取小数），禁 Math.random

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 单次翻牌 | 大格 4f / 小格 3f，p 走 Easing.in(quad) | Easing.in 是重力感来源——越掉越快才像机械叶片；匀速读作电子屏假翻 |
| 翻牌次数 | 大行每格 3–6 次（种子）、小行 3–4 次 | 全部同次数读作整齐的电子动画；少于 2 次读不出"翻找"；多于 7 次拖节奏且乱码抢戏 |
| 级联 | 大行 3f/格、小行 2f/格接力 | 太密整排齐翻没有波，太疏尾部字符等太久 |
| 停定咔哒 | 格高 3.4%（大格 6px），7f | 6px 是可感下限（4px 无感判例）；这一下就是"咔哒"的画面体 |
| 明暗 | 掉落叶 brightness 1→0.5，拍下叶 0.5→1，下半静态叶压暗 ≤0.45 | 明暗差是叶片"转过铰链"的立体感来源，比 rotateX 本身更被肉眼读到 |
| 翻牌格 | 大 128×176 圆角 12 / 小 60×84 圆角 7，perspective = 格高 ×2.6 | 铰链线压住翻转轴穿帮；perspective 太小叶片透视变形夸张 |
| 配色字体 | ember：叶片 `#2f2621→#1a1512` 暖炭、字 `#f6ebdd` 象牙白、状态字强调橙；SF 栈 700 | 深底浅字是翻牌屏的身份证；等宽格子布局，别用比例字体挤格 |
| 节拍 | 0–14f 空白叶片建立 → 级联 → 全停后静止 ≥45f | 建立段让观众先认出"这是块翻牌屏"，直接开翻读作故障闪烁 |

## 已知坑
- demo 在灰阶/占位素材上调校通过——参数是调校起点非实战定稿，
  首次实战须以真实素材回验
- 声音强依赖：每格停定的机械拍打声是效果的一半，实战必须配——级联
  停定天然是一串节奏点，`assets/audio/sfx/ui/switch-click-quick.mp3` 或
  `sfx/mech/gear-lock-metallic.mp3` 起步（更贴机械翻牌），也可用
  `sfx/text/typewriter-hit-single.mp3`；配法纪律见 sound-design.md
  （同类元素同音，拟音与动作等长，连发交替双样本防机枪感）
- 下沉回弹 6px 是可感下限：肉眼看不出就照可感性判例加大幅度，别调
  曲线不调幅度
- 整屏俯角（外层 rotateX）与每格自己的 perspective 是两层 3D：外层角度保持 ≤5°，大了叶片翻转的透视会和整屏透视打架、
  字边也会发软（Q2）
- 一支片翻牌字 ≤1 次：机械宣告腔太抢，重复即贬值（P4 手法去重精神）；
  与压印/打字机同片混用时留给最重的那句标题
