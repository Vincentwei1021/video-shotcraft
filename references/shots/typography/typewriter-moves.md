## 意图
打字是唯一自带时间性的文字入场——字符一个个到来本身就是节奏，
不需要额外动效。A 把打字当**引信**：暖黑终端窗逐字敲出命令、
方块光标方波闪，回车帧引信光烧过命令行、镜头急推进命令行硬切部署结果页，命令行是
场景的导火索，开发者产品标配；B 把打字当**独白**：逐字打出平庸词
（"Kestrel is / a dashboard"）→ 停顿犹豫 → 删除线划掉、退格删掉 → 更快打出卖点词
（"your command center."），犹豫-否定-宣言的三幕剧，戏全在三档
速度差里。与 scramble-decode 的区别：乱码解码是机器在猜，
打字是人在说。

## 两式选型
| 式 | 做法 | 适用 |
|----|------|------|
| A terminal-typewriter | 64px 等宽命令平均 2f/字符敲出（逐字 1–4f 确定性间隔，新词首字前顿一拍，字落下 4f 由橙热到奶白），光标打字中常亮、空闲 f%12<6 方波闪，打字段相机 1→1.035 蓄力缓推；回车帧引信光 4f 烧过命令行，整窗 8f 急推 scale 1→4.8（t^2.3 加速，origin 锁命令行中心）+ 末 4f blur 16px + 暖白曝光闪，硬切结果页 1.12→1 回稳 14f | 开发者工具开场；CLI 卖点产品 |
| B error-retype | 打 2f/字符 → 停顿 20f 光标闪两下 → 删除线 6f 划过 → 退 1.5f/字符（删除线随字缩短）→ 重打 1.5f/字符无犹豫；光标打删常亮、停顿才闪；完稿后宣言词下划朱红底线 | slogan 字卡的"改口"戏；否定式文案 |

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 字符节奏 | substring(0, floor((f-起点)/步长))，帧确定无插值；A 用逐字间隔表（均值不变）模拟真人手速 | 任何缓动打字都读作加载动画 |
| A 光标 | 方块，打字中常亮、空闲 f%12<6 方波 | 淡入淡出的光标不是终端是网页 |
| A 急推 | f58–66 scale 1→4.8，进度 t^2.3 加速，origin 钉命令行文字中心；末 4f blur 0→16px + 曝光闪 0→0.6 | 幅度小于 3x 读作抖了一下，不是"冲进去"；纯 t³ 前 5f 几乎不动，位移全挤在最后 2f |
| A 硬切 | f66 条件挂载切换（终端整棵卸载，blur 随之摘罩），结果页 1.12→1 回稳 14f snappy；曝光闪跨切点 7f 衰减（是爆点的光，不是溶解） | 交叉溶解毁掉引信-爆炸因果 |
| B 三档速度 | 打 2f/字符、删 1.5f、重打 1.5f 且零犹豫 | 三档差必须可感——等速改口读作 bug 不是戏，命门 |
| B 光标三态 | 打删常亮＝果断；停顿 5f 半周期闪两下＝犹豫；完稿闪两下后条件摘除（10px 朱红竖条） | 光标就是演员的脸，全程等速闪就没有"犹豫" |
| B 排版 | 124px 等宽两行（句干 400 字重 / 改口行 700 字重），逐字符固定宽 span（74.4px 槽），左缘锚定 x=216；字模按序号确定性 ±2px 落点、±0.6° 微倾、0.86–1 墨色浓淡 | 变宽字体/整串测宽会逐帧重排抖动；字模偏差按帧变会读成抖动，必须按字符序号固定 |
| 收尾 | A 区域行 f110 落定后 hold 40f（切后不推，靠光呼吸与状态点脉动）/ B 副标题 f156 落定后 hold 29f（全程 1→1.04 极缓推） | 光标残留 0.05 opacity 都毁真静止 |

## 已知坑
- demo 在灰阶/占位素材上调校通过——参数是调校起点非实战定稿，
  首次实战须以真实素材回验
- 声音强依赖：键击声逐字符对齐、B 退格音调更低（sound-design
  §4.5）——无声打字机只剩字幕机
- A 回车急推是与 crash-zoom 的交棒衔接：急推末帧动势最猛处硬切，
  切后新场景不得再推（一棒只交一次）
- B 全片 ≤1 次——改口是一次性的戏剧转折，改两次口是口吃
- 等宽字体或逐字符 span 二选一必须占一个，否则字符到来时
  整行重排，打字变成抽搐
