---
name: pill-slot-cycle
一句话: 句中词槽轮换——固定句干钉死不动，槽位里的 pill 徽章老虎机式绕滚筒翻一格（旧的上飞加速淡出、新的从下带模糊翻入），越换越快，连换 N 个功能词后落成完整句子、填空线点亮收束
适用: "功能列举"类文案的最优雅解法（比逐条列表快、比乱码解码有语义）；一句话卖点 + 多个动词短语的段落
时长: 入场 16f + 6 拍递减（28→16f，共 125f）+ 收束 16f + hold 48f；demo 205f ≈ 6.8s
能量: 中（渐快的节拍器，收束一拍是唯一峰值）
---

## 意图
罗列六个功能，列表要六行、逐条淡入要六拍还占满屏。词槽轮换把它们
塞进**一句话的一个槽位**里：句干 "One AI tool to ___" 是承诺，槽里
滚过的每个 pill 是证据，最后 pill 飞走、"do it all." 落位——证据
列举完毕，结论盖章。结构自带三幕：承诺→列举→收束。命门是句干
**纹丝不动**：观众的眼睛全程钉在槽位上，句干一晃列举感就散。

## 动效核心
- 版式（demo）：两行左对齐大字海报——第 1 行句干 "One AI tool to" 176px/800，第 2 行是"填空槽"：
  开场先由左向右画出一条横贯画面的发丝下划线（空格待填），pill 在线上方轮换；线右端是 ⌘K 键帽
  （命令面板入口）。两行版式让 pill 宽度变化完全不碰句干
- 句干绝对定位左端锚死——**不能用 flex 居中**，pill 宽度变化会带着句干重排（首轮踩过的坑，已是判例）；
  同一行版式时同理
- 拍长递减 `[28,24,21,19,17,16]f`：老虎机停下前越转越快；每拍前 9f 完成换位，剩余时间读词（最短拍 16f 仍读得完）
- 入场：translateY 150→0 snappy + rotateX -48°→0（绕顶边翻下）+ 0.93→1；离场：0→-170 exit 加速 + rotateX 0→42°
  ——新来的减速落定、旧的加速逃走，方向感是"向上翻页"；竖向运动模糊按真实速度计算（入 ≤16 / 出 ≤14px，静止为 0）
- pill 材质：深色玻璃（带蓝色相的半透明渐变 + 发丝描边 + 顶部内高光 + 随离槽高度变大的落地影），
  108px 圆角方块图标底用强调色渐变——强调色只在图标块和结论句上
- 收束拍：末 pill 上飞（7f ease-in，画在结论句之上），"do it all." 与句干**同字号同字重**从下 110px 带
  `Easing.back(1.5)` 过冲落位（全片唯一一次过冲，留给结论），字面电光蓝→青渐变；+6f 起下划线由左到右点亮成
  强调色渐变、键帽同步点亮；+13f 槽位后方一次泛光（Q4：只给主角一次）。全程极缓推近 1→1.03

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 拍长 | 28→16f 递减，5–7 词 | <16f 读不完短语；均匀 21f 是节拍器、没有"要停了"的预感；8+ 词观众开始数数 |
| 换位窗 | 拍内前 9f | 拉长到 12f+ 新旧同屏太久，读作两个 pill 打架 |
| 飞行距离 | 入 +150 / 出 -170px（pill 高 156） | <0.6 倍 pill 高读作原地闪换；入出不对称（出略远）让离场更决绝 |
| 运动模糊 | 入 ≤16 / 出 ≤14px 竖向 blur，按真实速度；入 rotateX -48°→0、出 0→42° | 去掉 blur 换位读作硬弹；>20px 中间帧糊成色块 |
| 收束过冲 | `Easing.back(1.5)`，16f，起点晚 2f 让末 pill 先走 | >2 结论落位像卡通；无过冲结论与列举没有档次差 |
| 字号 | 句干与结论 176px/800、pill 字 90px/650、眉题 28px 全大写 | pill 字比句干小一档是徽章层级；结论句必须与句干完全一致 |
| 收尾 hold | 完整句静置 48f | 这句话是全段目的，不 hold 等于白列举 |

## 已知坑
- demo 在灰阶/占位素材上调校通过——参数是调校起点非实战定稿，
  首次实战须以真实素材回验
- 与 odometer-digit-roll / split-flap-title 分工：那两卡是字符/数位级
  机械滚动（无语义），本卡是整词级 pill 轮换且嵌在活句子里——文案是
  "句干+动词短语"结构才用本卡，纯数字/纯标题词别硬套
- 与 typewriter-moves 分工：打字机是"一个字一个字造句"，本卡是
  "句子造好了换零件"——同片可共存但别在同一句文案上连用
- 与 type-rhythm-sync 分工：那是既有文字随音轨变属性（不换内容），
  本卡换内容——绑音轨时本卡拍点对鼓点即可，别再叠字重脉冲
- pill 短语长度要接近（demo 14–16 字符）——长短差 >2 倍
  槽宽跳变太猛，句子重心左右甩
- 收束句与句干字号字重必须完全一致（demo 都是 176px/800）——
  "do it all." 若比句干大，读作新标题而非句子补完
- 收束帧的层序：离场 pill 要画在结论句之上，否则结论句的模糊残影会盖在 pill 字面上（读作两层字叠印）
- 文案只用虚构产品与通用动作（demo：Relay），别把真实产品名（网盘/IM 工具）写进 pill
