---
name: ui-to-brand-morph
一句话: UI 变品牌两式——icon-flip-bloom 图标 3D 翻身侧成一条竖线、从竖线绽放成花形 mark + wordmark 逐字落定，与 input-morph-assemble 输入框收缩成竖胶囊、三粒圆形图元落进构造槽位拼成字母 mark
适用: 品牌收尾/outro 前最后一拍；"你每天用的那个 UI 就是这个品牌"的视觉论证
时长: A ~5.0s（150f）/ B ~5.6s（168f）
能量: 中高（收尾点睛，一次完整变形讲完）
---

## 意图
品牌收尾库里已有三条路：brand-ink-open 是开场描画压印、
morph-from-primitive 是图元→UI 容器（方向相反）、
outro-group-photo-launch 是元素围拢合影（聚而不变）。本卡补第四条：
**产品 UI 元素自己变形成品牌符号**——A 式是图标翻一个身变成 logo
（同位实体交换），B 式是全片反复出现的输入框在最后一次发送后集结成
字母 mark（多元素落位拼装）。观众看到的不是"logo 出现了"，而是
"刚才用的东西原来就是它"，因果链本身就是品牌论证。

## 两式选型
| 式 | 做法 | 适用 |
|----|------|------|
| A icon-flip-bloom | 图标 anticipation 晃三下→perspective 下 rotateY 0→90° 侧成竖线（双层残影 + 竖线光芒）→最薄处实体交换、spring 绽放成内外两层 5 瓣花形 mark→mark 左移让位、wordmark 逐字落定 | 单图标产品；图标与 logo 形态差异大、需要"翻过去变身"的魔术感 |
| B input-morph-assemble | 光标点发送→文字飞走、强调色从发送键漫开灌满输入框→x/y/w/h/r 五量 spring 收成竖胶囊→三粒圆形图元错峰从画外落进虚线构造槽位拼成字母 P→让位出字标 | 输入框/卡片等矩形 UI 是全片主角的片子；logo 可拆解为几何图元组合 |

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| A anticipation | 12–36f 倾斜 -8°/+12°/-16°→0°，inOut(sin)，transformOrigin 钉底部 92%；接触影随倾斜偏移 | 幅度递增才读作"蓄力"；只晃一下读不出预备动作 |
| A 翻身 | 36–46f perspective 1300 下 rotateY 0→90°（t³ 加速）+ 微放大 1→1.06；两层残影滞后 14°/28°、blur 5px | 加速入是"甩"的关键；匀速翻读作 flip 卡片。90° 侧面即竖线，实体交换在这帧做 |
| A 竖线光芒 | 图标侧过 ~66° 才亮起的 6px 象牙色竖线 + 纵向光芒 + 横向细光，46f 最亮、8–11f 衰减 | 竖线早出现会压在图标正面上；光芒是全片唯一光效 |
| A 绽放 | 外层 spring(damping 12, stiffness 120)、内层晚 4f（damping 13）错开 36°；瓣初始角上下交替（闭合 = 竖线），张到 72° 均分，瓣宽 4→46 同步生长 | 花瓣从闭合竖线张开才接得住"翻过最薄处"；直接 scale 整朵会断因果 |
| A wordmark | mark 66f 起 20f 左移让位（位置先到，缩到 0.84 晚 3f）；逐字 2.6f 错峰、每字 13f：scale 1.9→1 + blur 14→0（snappy），原点钉基线 | 各字母由大变小落位，大的时候模糊、落位时清晰，不是横向扫出；错峰 <2.4f 每字的"由大变小"读不清 |
| B 发送反馈 | 光标 20f 移入按下 scale 0.84 + 按钮闪白 6f；文字 11f ease-in 加速右上飞出（+760,-420）+ rotate -9° + 拖影 | 飞走必须加速——匀速飞读作平移不读作"发出去了" |
| B 灌色 | 28–40f 强调色从发送键位置圆形 clip-path 漫开灌满输入框（全程实色） | 用 opacity 渐变填色会经过一段发灰/发粉的半透明态；文字要先飞离再灌色，否则深字压在蓝上 |
| B morph | 30f 起 spring(damping 15, stiffness 95)，1040×132 r34 → 108×330 r54（横条直接挤成竖条）五量同步，按 spring 速度加 ≤3px 拖影 | 五量必须同一个 spring 驱动，分开插值会中途散架 |
| B 三粒落下 | 58/72/86f 错峰 14f，各自 spring(damping 13) 从画外 -760px 落到槽位；落前 10f 槽位先画虚线构造圆，落定 14f 后淡出；按速度拉伸 / 回弹压扁（原点钉底部） | 错峰是"集结"的节奏感；齐落读作下雨；没有槽位预示，落点读作随机 |
| B 落定 | 108f 起 mark 20f 左移让位、构造网格退场，字标逐字从基线升起、口号逐词；124f 起整组极缓推近 2% | 落定后整段不动即死帧；逐拍 scale 呼吸容易读作抖动 |

## 已知坑
- demo 用虚构品牌调校（A：AI 问答 Pollen，深绿温室 + 珊瑚花；B：团队聊天 Parley，瑞士网格亮场 + 钴蓝 / 琥珀）——
  参数是调校起点非实战定稿，首次实战须以真实素材回验
- A 式实体交换必须发生在 rotateY = 90° 的最薄帧——提前换观众看见两个图形叠影，魔术穿帮；t³ 加速使 45→46f 一帧跨过 ~25°，这一帧的"甩"靠残影和竖线光芒接住
- A 式 wordmark 已改为逐字 scale+blur 落定，错峰 2.2→2.6f；换更长的字标时按可感性判例正常速度看片再定间隔
- B 式拼的是几何构造的字母 P（竖胶囊 + 碗 + 字怀 + 消息点），不是任何真实 logo——实战换成自家 logo 的图元分解，图元数 3–4 粒为宜，多了读作粒子不读作拼装
- 变形中途别叠其他动画（morph-from-primitive 同判例）：morph 本身是全部信息
- 与 outro-group-photo-launch 分工：那是全片元素飞来围住字标合影（聚），本卡是 UI 元素自己变成品牌符号（变）；同片收尾二选一
- 声音：A 翻扁一声"唰"、绽放落定"嗒"；B 发送一声 send、每粒落位一声 pop、字标段静
