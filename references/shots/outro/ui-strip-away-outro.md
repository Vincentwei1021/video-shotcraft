一句话: 减法式收尾——点击 Publish 后整个编辑器 UI 从外围到中心逐行错峰蒸发、画布底逐块瓦解成暗场，只剩那颗按钮滑到屏心放大、变成「✓ Live」，再化开交棒字标定版
适用: "发布/完成"语义的 outro；想讲"一键之后一切复杂性消失"的产品收尾
时长: ~5.9s（176f：光标就位 30f → 蒸发 ~40f → 按钮独占 + Live ~28f → 字标接棒 → 海报 hold ≥0.5s）
能量: 中（前段安静操作，中段持续退场，无瞬时冲击）

## 意图
库内收尾全是"加法"：outro-group-photo-launch 元素飞来合影，logo
sting 是定住再彩蛋。本卡是唯一的"减法"路线——点击引爆全 UI 退场，
黑场只留语义焦点（那颗被点的按钮），把"发布 = 复杂性归零"翻译成
动效叙事。命门有二：**蒸发要有秩序**——从外围到中心逐行/逐块错峰、
每个单元带方向性位移（各自往画外散），连画布底也按距离逐块瓦解，
乱序或同帧齐灭读作断电故障；**按钮是唯一幸存者且必须迁移**——蒸发
期间从工具条角落滑到屏心放大 2.5 倍、光晕随暗场增强、标签变成「✓ Live」，
完成从"UI 控件"到"仪式主角"的升格，最后化开把暗场交给字标。

## 动效核心
- 亮场编辑器为镜头设计：左图层栏 12 行、右属性面板 6 块、顶工具条、画布里一张正在编辑的
  落地页（标题被选中带控制柄），UI 字 16–24px 只当纹理，画布标题 92px、按钮 23px 起
- 开场 0–32f 相机朝 Publish 缓推 4%（原点钉右上），30f 点击：按钮压缩脉冲 + 一圈强调色涟漪，
  光标点击后 10f 内淡出——主角换人，光标必须退场；点击后相机 36f 平滑回到 1.0
- 蒸发单元 = 每一行 / 每一块 / 每个图标，不是整块面板：侧栏行 34f 起每 1.3f 一行 → 属性块 37f
  起每 1.7f → 工具条左段 43f → 画布区块 42–56f → 工具条中右 50–55f；每单元 17f，位移/模糊走
  ease-in（bezier .5,0,.8,.45）、透明度近线性，沿离心方向位移 60–160px + 上飘 26px + 0→12px 模糊 + 缩 5%
- 画布底切 8×5 块瓦片，起始帧按到屏心的椭圆距离排（52f 四角 → ~74f 屏心，带 ≤2f 确定性错位），
  每块 11f 收缩到 30%、圆角变大、颜色被吸向虚空色，到后 40% 才淡出——压黑本身有秩序，不经过整屏灰
- 按钮：58f 起 26f 不对称 in-out（bezier .62,0,.18,1）滑到屏心，按速度加方向拖影；尺寸晚 3f
  按布局放大到 2.5×（字边锐利，不用 CSS scale 放大文字）；光晕与地面光斑随虚空加深增强
- 96f 标签上卷 Publish → ✓ Live（9f snappy）+ 一次裁进圆角的扫光；112f 起 12f 上浮 + 放大 + 模糊化开
- 字标接棒：121f 图形标 spring(damping 15, stiffness 140) 上浮落定，字标逐字由虚到实（2.4f 错峰），
  口号逐词升起、网址淡入，海报 hold 到 176f（光晕极缓呼吸）

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 蒸发粒度 | 行 / 块 / 图标级单元，组内 1.1–1.7f 错峰 | 整块面板一起走读作"图层被删"；碎到像素级读作故障 |
| 单元时长 | 17f，位移 ease-in、透明度近线性 | ease-out 离场读作"飘走"；透明度也 ease-in 会留半透明残影、发灰 |
| 蒸发顺序 | 外围 → 中心，按钮所在的工具条最后 | 中心先空读作故障；按钮层先走全卡崩塌 |
| 位移幅度 | 60–160px 离心 + 26px 上飘 | 无位移纯 fade 读作调透明度；同方向读作整屏平移 |
| 暗场转换 | 画布底 8×5 瓦片外→内收缩，每块 11f | 整屏 opacity 淡到黑会经过一段大面积灰；瓦片先淡后缩会出灰块 |
| 按钮迁移 | 26f 滑到屏心 + 2.5× + 晕光增强 | 不迁移则暗场上一颗角落小钮，读作漏删；先迁后灭顺序不可反 |
| 字标接棒 | 按钮化开 ~9f 后进，spring 定版 | 与按钮同屏抢戏；暗场空窗 >20f 像放完了 |

## 已知坑
- demo 用虚构品牌（建站工具 Tessel / 画布里的咖啡品牌 Okra）调校——参数是调校起点非实战定稿，
  首次实战须以真实素材回验；实战编辑器若是截图纹理，按语义区块切图层再蒸发
- 大面积元素（面板底、artboard 底）的蒸发模糊压到 4–5px：大块实时模糊又贵又糊成一片灰
- 与 outro-group-photo-launch 分工：全家福是"加法"峰值终镜（多功能
  产品全员谢幕），本卡是"减法"收尾（单一动作语义、越走越静）——按
  产品气质二选一，不可同片双收尾
- 与 edit-hook-moves B（logo-sting-button）衔接：本卡字标定版后可接
  sting 彩蛋，但 sting 的"突插"会打破减法的静——接不接看全片性格
- 蒸发的每层必须是**语义完整的 UI 区块**（侧栏/面板/工具条），按
  像素区域切层会在错峰时露出结构不合理的残缺态
- 按钮迁移全程 zIndex 压最顶——任何蒸发层从按钮前面飘过都是穿帮
- 触发动作必须是"终结性"语义（Publish/Ship/Done）；拿 Save 或普通
  确认触发全 UI 蒸发，语义配不上排场
- 实战按钮用品牌高亮色（原片是 Framer 蓝），demo 用群青 #3b4bff，暗场是带群青色相的近黑
  ——暗场上按钮与晕光的对比是主角光环，颜色弱则升格失败
