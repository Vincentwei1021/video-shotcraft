一句话: 整行字爆裂成沸腾颗粒噪点并浮现斜纹选区框，噪点云急速凝聚成更大号发光短字标，位移衰减归零定格
适用: 收尾"XX. Now Live"式上线宣告；长句信息压缩成品牌短标的能量聚合拍
时长: 84f（2.8s@30fps；砂化 10–22f · 沸腾 22–34f · 凝聚 36–46f · 凝固 44–58f · 副标与 hold 54–84f）
能量: 中高（短促、一次性的能量脉冲，天然的 outro 卡点）

## 意图
把"一句话浓缩成一个词"拍成物理事件：句子先失稳沸腾成颗粒（信息解体），选区框暗示"正在选中提取"，然后所有颗粒能量向中心坍缩成更大更亮的短字标——观众读到的是"这一切归结为它"。

## 动效核心
- 滤镜链是唯一引擎：`feTurbulence`（fractalNoise，baseFrequency 0.95→1.3，按 1920×1080 原生坐标）+ `feDisplacementMap`（scale 0→96）+ `feGaussianBlur`（0→0.55px），由同一条 `burst` 曲线（10–22f，snappy）驱动——**高频噪声 + 大位移 + 极小模糊**才是"砂"，频率低或模糊大都会糊成雾
- 噪点"沸腾"靠 `seed = floor(f*1.5)` 逐帧换种子——每帧一幅新噪声图，颗粒永不静止
- 38–46f 交叉淡化：整行字（等宽 76px）淡出、短字标（粗黑体 300px，白热→橙竖向渐变）淡入，两者共用同一滤镜——切换发生在最沸腾时，观众看不到换字；字体从"代码体"换成"品牌字"本身就讲了"一句话归结为一个名字"
- 44–58f `lock` 曲线把 displacement 和 blur 拉回 0，颗粒"凝固"成清晰字形；字标同时 1.08→1 被压实
- 暖橙辉光三段式：砂化期 0.35 弱光 → 凝聚冲高 → 48f 后回落，滤镜链内"紧光 + 宽光"两层 bloom（feGaussianBlur → feColorMatrix → feMerge，半径约 4–44px）同步呼吸；凝聚冲高那一下给一道横向光痕（只一次）
- 180 颗余烬火星：burst 时被"热气"吹出、上飘为主，36f 起 ease-in 加速吸回字标字面，按每帧位移拉成短线（运动模糊），凝固时熄灭
- 斜纹选区框（45° 线阵 + 四角像素棋盘手柄 + 等宽角标 SELECT · 21 CHARS）12f 起 overshoot 横向弹开、32–40f **横向挤压收拢**撤场——挤压动作预告了"压缩"，且早于凝聚完成

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| displacement scale | 峰值 96（原生 1080 坐标） | <50 只是"轻微毛边"；>140 颗粒散到认不出轮廓，"隐约可辨"是砂化质感的底线 |
| baseFrequency | 0.95 → +0.35 | 越高颗粒越细；低于 0.6 变成大块扭曲 + 雾，不是"砂" |
| 模糊 | 峰值 0.55px | >1.5px 颗粒糊成一团烟 |
| seed 换帧率 | floor(f*1.5)，每帧必换 | 降低会看出噪声图重复；保持 ≥20 次/秒的换图率 |
| 砂化窗口 | 10–22f（snappy） | 前 10f 的干净字停留是"失稳前的常态"，砍掉则没有对比 |
| 凝聚交叉 | 38–46f（smooth） | 必须落在最沸腾段内完成换字；提前会穿帮看到两行字叠影 |
| 辉光包络 | burst·0.35 + cond·0.85 − settle·0.55 | 凝聚冲高是卡点位，压 BGM 重音；回落别到 0，留柔光"余温" |

## 已知坑
- 换字标文案（demo 为 Kova → 项目短标）时两行 `<text>` 都要改：整行句式 `{ XX 3 — now live }` 与短标 XX 必须指同一对象，否则叙事断裂；选区角标的字符数也跟着改
- 短标变长（>6 字符）需同步缩 300px 字号，否则凝聚后超出取景括角、视觉重心偏移；整行字变长同步加宽选区框 BOX.w
- `feDisplacementMap` 在 Safari 上性能较差，这张卡是 2s 短拍可接受；拉长时长需实测帧率
- 选区框撤场（32–40f）必须早于凝聚完成（46f）——框留到凝固后会读作"还没选完"，语义反了
