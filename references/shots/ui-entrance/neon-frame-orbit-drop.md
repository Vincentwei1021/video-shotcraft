适用: 单页 UI 的一次性隆重登场（与巡礼/逐区亮相相对）；暗场霓虹调性段落的主视觉揭幕；neon-frame-forerun 的姊妹镜

能量: 中高（一次性的大动作，落定即静）
标签: effects、camera

## 意图
neon-frame-forerun 的孪生变体：同样框先行、内容后落，但镜头
不是固定的——从页面左侧视角连续弧线旋转到右侧视角，旋转进行
的同时全部组件从空中贴落。命门是**同时贴合**：所有组件和文字
同帧起落、同帧贴合、软影同步消失——这是"整体登场"的语法
（判例：错峰版被裁"应该是所有组件和文字同时从空中往下贴合"）。
错峰贴落属于巡礼镜（graze-face-tour/runway），一页一次性亮相
必须齐落，节奏语义不能混用。

## 动效核心
- 霓虹描框：蓝→青渐变霓虹框 14f 奔画成型（同 neon-frame-forerun 的四层描边灯管 + 两颗亮头）
- 视角弧线：rotateY +36° → −24° 连续弧线（0–124f，不对称 in-out bezier(0.45,0.05,0.3,1)），
  中段略推近；按 rotateY 反向做屏幕空间横移补偿，面板全程居中构图
- **真 3D 世界**：面板、悬空组件、地面网格、背景竖直光柱都在同一个 preserve-3d 里，
  镜头一转三层视差同时出现（远光柱 / 中面板 / 近悬空件），环绕不再只是"一块板在转"
- 同时贴落：组件开场就悬在 150–210px（translateZ），环绕前半程看清分层；
  52f 全体同帧起落、24f 加速下落 + 软着陆、76f 同帧贴合，同形软影全体同步收敛；
  贴合帧整圈灯管过曝闪一次 + 面板辉光脉冲（全片唯一的"咔"）
- 背景竖直光柱衬场，96–128f 由中间向两边熄灭让位；面积图在悬空段描出，落定后终点光点呼吸

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 贴落同时性 | 全元素同帧起落（零错峰） | **命门**；任何错峰都会读成巡礼语法（判例裁决原话见上） |
| 视角弧线 | rotateY +36°→−24°、屏幕横移补偿 5px/° | 弧度小读作抖动；只转不落=空转；不补偿时落定面板偏向近侧 |
| 旋转×贴落耦合 | 贴落 52–76f，居中于 0–124f 旋转行程 | 旋转完才落=两段戏；落完还在转=收不了尾 |
| 悬浮高度/软影 | 150–210px、影随高度变大变虚变淡 | 影不可感=没做（累计判例）；暗色面板上影子要压到 ~0.7 不透明度 |
| 描框 | 14f 奔画 | 同 neon-frame-forerun |

## 已知坑
- 参数经占位素材两轮调校通过，非实战定稿，首次实战须以真实素材回验
- **贴落节奏语义判例**（本卡与 graze-face-tour 互为反例）：
  巡礼镜=错开起点+重叠并行下落；整体登场镜=全体同帧。选错语法
  两边都会被裁
- 与 neon-frame-forerun 分工：那张镜头固定、错峰贴落+页面点亮
  三层咬合；本卡镜头旋转+同帧齐落。同段落二选一，别连用（同框
  语言重复）
- 环绕是 CSS 3D 里转整个世界（rotateY 转 rig）而非真相机，>45° 时面板文字压缩明显（Q6）；
  preserve-3d 链上任何 filter / opacity<1 都会把 3D 压平，亮度/淡入只加在叶子节点
