时长: 约 5.6s（168f@30fps）
能量: 中（长镜慢速推进，靠数据包滑行维持活性；吞并瞬间是唯一小高点）

## 意图
"我们把四个来源统一了"是一句抽象话。这个动效把它变成可看的物理过程：先建立四条独立
的通路（draw-on 是"连上了"），再让四个来源真的顺着通路走进同一个点并被吸进去（缩小
到 0 是"被吞并"），最后擦掉通路只留徽标（"现在只有一个"）。三段叙事各自有明确的
起止，观众不需要旁白就能读出因果。

## 动效核心
- 路径几何：每条 `d = "M -22,y L 74,y C 186,y 214,120 332,120"`——起点在画框外 -22，
  74 处是来源节点的驻留位，之后一段三次贝塞尔弯向汇聚点 (332,120)。四条只差起始 y
  （36/92/148/204），所以它们的曲率天然不同，汇入角度也不同
- draw-on 用 `stroke-dasharray = len` + `dashoffset = len*(1-draw)`，`seg(t, 0.04+i*0.045,
  +0.17, E.outQuad)`——0.045 的错峰让四条线像被依次接通而不是一起亮
- 节点定位用 `getPointAtLength`：先在 prime 阶段以 40 步扫描求出 x≈74 对应的路径比例
  `f0`，运行时 `frac = f0 + (1-f0)*conv`，`conv = seg(t, 0.34, 0.74, E.inOutCubic)`——
  节点是**沿真实曲线**走的，不是两点间插值
- 三段式缩小：`conv < 0.75` 时 44→15px（缓慢瘦身），`conv ≥ 0.75` 时 15→0px（最后
  1/4 行程掉光）——后段的尺寸变化率是前段的 4 倍多，这就是"被吸进去"的加速感；
  字号跟着 `size*0.26` 同步缩，标签不会脱离节点
- 数据包：`pkCycle = (seg(t, 0.1, 0.74, E.linear)*2) % 1` 走两个整数周期，各路加
  `i*0.13` 相位偏移；透明度用 `1 - |cycle-0.5|*0.6` 让包在路径中段最亮、两端淡——
  避免看到包在起点凭空出现
- 擦除：`erase = seg(t, 0.78, 0.9, E.outQuad)` 把 dashoffset 推成负值（`-erase*len`），
  于是虚线从**起点**方向退走，方向与 draw-on 相反，读作"通路收回"
- 徽标：`seg(t, 0.16, 0.26)` 淡入并从 0.7 放到 1，吞并时刻（0.7→0.78 outBack 加 12%，
  0.78→0.86 outQuad 减回）做一次接收脉冲；末尾 `endCap` 字幕在 0.84 后淡入

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 来源数 | 4 条（y=36/92/148/204，间距 56） | 4 条是曲率差异明显又不打结的甜点；>6 条中间几条的贝塞尔几乎重合，汇入角读不出区别 |
| draw-on | 起点 `0.04+i*0.045`，窗 0.17，outQuad | 0.045 的错峰约 7f；归零会读作四条线一起刷出，失去"逐路接通"的语义 |
| 汇聚窗 | 0.34→0.74（inOutCubic） | 占全片 40%，是主段落；inOut 的缓起是"启动"、缓收是"到位"，换 linear 立刻变成匀速传送带 |
| 三段缩小 | 44→15px（前 75%）→ 0（后 25%） | 拐点 0.75 越靠后吸入越突然；把它挪到 0.5 会变成"一路缩小"，吞并的那一下就没了 |
| 数据包周期 | 2 个整数周期（0.1→0.74 线性） | 必须是整数周期，否则末帧包停在半路；周期加密到 4 会读作数据流很急，也更容易和节点重叠 |
| 包相位偏移 | `i*0.13` | 错开四路的包，避免它们排成一行同时汇入；0 会看到四个包整齐并进，像一次发车 |
| 擦除 | 0.78→0.9，dashoffset 取负 | 12f 完成；擦除必须在节点全部消失（conv=0.74 结束、节点 0.92 前淡完）之后，否则线先没了节点悬在空中 |
| 徽标脉冲 | outBack +12%（0.7→0.78）→ 回落（0.78→0.86） | 12% 是"接收到了"的量级；>25% 会抢过汇聚本身的注意力 |

## 已知坑
- `getTotalLength` / `getPointAtLength` 必须在 SVG 已挂到文档且完成布局之后才有效，
  代码用 `ready` 标志在首帧 `prime()` 里做——移植到 Remotion 时首帧渲染可能拿不到
  长度（fallback 写了 `|| 380`）。稳妥做法是在 `useEffect`/layout 后再算，或预先算好
  常量表，否则首帧会出现一次错位跳变
- `f0` 是用 40 步线性扫描找出的"x 首次 ≥74"的比例，精度只有 1/40。曲线形状改动大时
  节点驻留位会偏离 74，看起来"没停在该停的地方"——改路径后要提高扫描步数或直接标定
- 节点 opacity 在 `conv > 0.92` 后才开始淡出，而 conv 在 t=0.74 就到 1，所以节点是在
  尺寸缩到 0 时消失而不是淡出消失。这是有意的（被吸进去不该淡出），但如果把三段式
  拐点改晚，会看到节点在有尺寸时突然消失
- 节点是 `S1`–`S4` 的中性灰阶占位圆（灰度分层仅用于区分四路），落地要换成真实来源
  logo；强调色只留给数据包与徽标，不要给节点上色，否则汇聚点的视觉主体被夺走
- 汇聚点 (332,120) 与 SVG 视口 440×240、`overflow:visible` 是绑定的一组坐标。改画布
  比例要整套重标，路径起点 -22 依赖 `overflow:visible` 才能露出画框外的一截
- 字幕 "Four sources unified" 是占位文案，出现在 0.84 之后——如果要配旁白，这句的
  出现点应对齐旁白落词而非动画节点
