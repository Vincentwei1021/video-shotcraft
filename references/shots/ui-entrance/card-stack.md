---
name: card-stack
一句话: 8 张卡从屏幕下方逐张 spring 弹入叠成一摞，全员落位后整摞一次性展成 3D 扇面——每张按序号偏转 8°、横移 34px、向后退一层 z
适用: 需要交代"我们有一组东西"的产品段落；卡片墙/模板库/方案列表的建立镜头，也能当 logo 前的一拍蓄势
时长: 约 4.2s（126f@30fps）
能量: 中高（入场是连续小爆发，展开段收成一次平滑的整体动作）
---

## 意图
一摞卡先聚成一个物体，再摊开成一组物体——顺序很关键：先给"整体"再给"个体"。
观众第一眼记住的是有分量的一摞（数量感），第二眼才看清每张不一样（多样性）。
展开动作留到最后一次性完成，是为了不和入场的节拍打架。

## 动效核心
- 两层运动分离叠加：入场（每张自己的 spring）与扇形（全员共享的一条展开进度），
  最终 transform 是 `translate3d(tx, y, tz) rotate(rot)` 里两层各自算出的分量合成
- 入场：`seg(t, 0.02+i*0.033, +0.3)` 后过 `E.spring(inT, 0.3)`，`y` 从 300px 抬到 0——
  起点在画框外，stagger 0.033（约 4f）让 8 张连成一串而不是一起飞
- 扇形：`seg(t, 0.55, 0.8, E.inOutCubic)` 是唯一的展开时钟，扇形终态是静态偏移量
  （`k = i-3.5`，`rot = k*8°`、`tx = k*34px`、`tz = -10*|k|`）乘上这条进度
- `transform-origin: 50% 130%` 把旋转轴放到卡片下缘之外——扇柄在手里，卡片是绕手腕
  转开的，不是绕自己中心转
- 透明度用 `min(1, inT*4)` 提前吃满：卡在飞行前 1/4 段就已经全实，观众看到的是实体
  运动而不是淡入
- `zIndex = 20 - |k*2|`：中间的卡压在最上层，扇面向两侧递退，配合 `tz` 一起给深度

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 卡数 | N=8（hue 222→334，每张 +16°） | 8 张是扇面 56° 总张角的舒适上限；>10 张要把每张角度降到 5–6°，否则两端卡飞出画框 |
| 入场 stagger | 0.033/张（≈4f） | 4f 是"一串"的手感；≥8f 读作逐张点名，≤2f 读作一团一起冒 |
| 入场行程 | 窗 0.3（≈38f），y 300→0 | 300px 保证起点在画框外；行程缩到 0.15 以内 spring 的回弹会被截断，落位变硬 |
| spring 阻尼 | `E.spring(inT, 0.3)` | 0.3 是可见但不夸张的一次回弹；调小回弹次数增多，卡会"抖两下"，成组时抖动会互相干扰 |
| 展开窗 | 0.55→0.8（inOutCubic） | inOut 让展开缓起缓收像一只手在摊牌；换 outBack 会过冲成"甩开"，与前段的 spring 撞手感 |
| 扇形张角 | `k*8°`，横移 `k*34px` | 角度与横移要同比调：只加角度不加横移，卡会互相穿插；34/8 的比值决定扇面是"疏"还是"叠" |
| 深度递退 | `tz = -10*|k|`，perspective 900px | 只有 10px/张，深度是暗示级别；调到 40 以上必须同时加大 perspective，否则边缘卡透视畸变 |
| 旋转轴 | `transform-origin: 50% 130%` | 130% 决定"扇柄"离卡多远；改成 50% 50% 立刻退化成风车式散开，失去手持感 |

## 已知坑
- 两段时间窗刚好首尾相接：末张入场结束于 `0.02+7*0.033+0.3 = 0.551`，展开始于 0.55。
  加卡数或加大 stagger 会让入场吃进展开段，出现"还在飞就开始转"的浑浊——加卡必须
  同步把展开起点往后推
- 卡数为偶数时 `k` 取半整数（±0.5, ±1.5…），`zIndex = 20-|k*2|` 让中间两张同层，
  它们的叠压次序由 DOM 顺序决定；奇数张时中心卡独占顶层，观感更稳
- 卡片尺寸 110×150 与 `margin:-85px 0 0 -55px` 是绑定的居中量，改尺寸要一起改 margin
- 卡面内容是灰阶骨架条 + 单个几何字符的占位，落地必须换成真实页面切片；hue 色环是
  演示用的区分手段，真实素材里应改为同色系或直接取素材主色
- 展开后没有收尾动作，末帧停在扇面终态。要接下一镜就在 0.8 之后切，别让扇面白停太久
