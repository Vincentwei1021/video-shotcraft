---
name: card-stack
一句话: 一组模板卡（demo 9 张）从屏幕下方逐张 spring 弹入、越落越快叠成一摞，全员落位后整摞一次性展成扇面——每张按序号偏转 6.5°、横移 138px，最后中心卡被抽出
适用: 需要交代"我们有一组东西"的产品段落；卡片墙/模板库/方案列表的建立镜头，也能当 logo 前的一拍蓄势
时长: 约 5.0s（150f@30fps）
能量: 中高（入场是连续小爆发，展开段收成一次平滑的整体动作）
---

## 意图
一摞卡先聚成一个物体，再摊开成一组物体——顺序很关键：先给"整体"再给"个体"。
观众第一眼记住的是有分量的一摞（数量感），第二眼才看清每张不一样（多样性）。
展开动作留到最后一次性完成，是为了不和入场的节拍打架。

## 动效核心
（demo 版本：瓷白模板库发布——video-shotcraft 镜头配方库，9 张 320×440 镜头 / 模板卡，1920×1080 原生坐标）
- 两层运动分离叠加：入场（每张自己的弹簧）与扇形（全员共享的一条展开进度），
  最终 transform 是 `translate3d(tx, y, tz) rotate(rot)` 里两层各自算出的分量合成
- 入场：起跳帧 `2 + stagger(i, 9, 40, EASE.out)`——EASE.out 映射让间隔先大后小（砰——砰—砰-砰砰，越来越快）；
  每张 `springAt(f, start, {damping:13, stiffness:150})`，`y` 从 820px 抬到 0（起点在画框外），≈20f 落座；
  飞行中带 ±9° 交替倾角并随落座收敛，按竖向速度加运动模糊（≤10px）
- 重量：每张落座（起跳后约 6f 越过终点）时整摞被压低 5px（sin 包络 9f）；成摞时确定性 ±3.2° / ±11px 错位，
  像随手码齐的一摞；展开前 62–72f 整摞收紧 2%（预备）
- 扇形：`springAt(f, 68, {damping:20, stiffness:95})` 是唯一的展开时钟（带一次轻微过冲 = 手腕甩开的惯性），
  终态 `k = i-4`，`rot = k*6.5°`、`tx = k*138px`；`transform-origin: 50% 130%` 把旋转轴放到卡片下缘之外——
  扇柄在手里，卡片是绕手腕转开的
- 叠压次序 = 序号（`zIndex = i`，左压右，像手里摊开的一手牌），全程不换——成摞时顶牌就是最后一张，
  展开时不会出现顶牌跳变
- 相机：成摞段 1→1.06 极缓推近给"一摞"分量，展开同段（64→106f）拉远到 0.88 让扇面完整入画；
  地面接触影随扇面从 220 变宽到 760
- 结尾：中心卡（钴蓝实色封面：镜刻标志反白版 +「Launch」，卡名 Launch film）沿自身轴抽出 72px（overshoot）+ 3px 钴蓝描边 + 一次扫光（Q4），
  标题 "Start from a shot recipe."（88px）逐词升起、副句跟随，hold 28f

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 卡数 | N=9（奇数，中心卡独占中位） | 9 张 × 6.5° = 52° 总张角是舒适上限；>11 张要把每张角度降到 4–5°，否则两端卡飞出画框 |
| 入场 stagger | 40f 跨度，EASE.out 分布 | 越来越快是"一串"的手感；等差分布读作逐张点名，<20f 读作一团一起冒 |
| 入场行程 | y 820→0，spring damping 13 | 起点必须在画框外；damping <10 回弹两次以上，成组时抖动互相干扰 |
| 落座下压 | 5px，sin 9f | 这是"有分量"的来源；>10px 整摞像弹簧床 |
| 展开弹簧 | damping 20 / stiffness 95 | 一次轻微过冲像手腕甩开；damping >26 无过冲读作机械展开，<16 扇面来回晃 |
| 扇形张角 | `k*6.5°`，横移 `k*138px` | 角度与横移要同比调：只加角度不加横移，卡会互相穿插 |
| 深度 | `tz = i*2`，perspective 1800px | 只做叠压的暗示；深度主要靠叠压次序 + 两层软阴影 |
| 旋转轴 | `transform-origin: 50% 130%` | 130% 决定"扇柄"离卡多远；改成 50% 50% 立刻退化成风车式散开 |
| 抽卡 | 72px overshoot + 描边 + 扫光 | 只给中心卡一次；抽出量 <40px 看不出"被选中"，>120px 卡与标题打架 |

## 已知坑
- 两段时间窗刚好首尾相接：末张 42f 起跳、≈62f 落座，62f 预备、68f 展开。
  加卡数或加大 stagger 会让入场吃进展开段，出现"还在飞就开始转"的浑浊——加卡必须
  同步把预备与展开起点往后推
- 卡数为偶数时 `k` 取半整数（±0.5, ±1.5…），没有中心卡，结尾"抽出主角"会偏在一侧；
  demo 用 9 张。若改用"中间压两边"的 zIndex，要注意成摞→扇面时顶牌会跳变
- 卡片 320×440 以 `left = CX-CW/2, top = CY-CH/2` 居中，扇柄位置随 CH 变；改尺寸要同步检查
  两端卡是否出安全边距（相机 0.88 时最外卡角距画边约 100px）
- 卡面是手搓的模板封面占位（生成式封面图 + 标题 + mono 元信息），落地应换成真实页面切片；
  封面只用钴蓝 / 青绿 / 墨三色的浅色调，只有中心卡用钴蓝实色——真实素材里也要留一张「主角」
- 展开同段（64→106f）相机拉远到 0.88，保证两端卡不出画；要接下一镜可在抽卡落定（≈120f）后切，别让扇面白停太久
