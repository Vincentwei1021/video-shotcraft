name: research-card-stack-scroll
一句话: 深色论文卡以越来越快的发牌节拍（均值 12 帧一张）沿右下轴线飞入中心叠压，落位带 1 帧压缩，只有最上一张全清晰渲染标题+作者+摘要，下方卡按堆积深度递增模糊变暗只露标题条，背景横向 grid 同步下移做速度参照
适用: "读了大量资料/处理了海量文档"的量级交代；研究类、检索类、批处理类产品的能力镜头
时长: 约 4.8s（144f@30fps）
能量: 中高（匀速高频，无爆发但持续压迫）
---

## 意图
要说的是"数量"，但一次给 11 张卡会读成一堵墙。改成流水线：卡一张一张进，每张都被
读过（最上一张永远是全文渲染的那张），读完就沉进堆里变模糊。观众感受到的是持续不断
的吞吐量，而不是一个静态的堆。背景 grid 同速下移是速度参照——没有它，堆积会读作
"卡在原地缩小"。

## 动效核心
- 时间轴用真实帧号而非归一化 t：内部 `F=144`，落位时间表 `LAND[i]` 首张 f=6，此后间隔
  14→9.5 帧线性递减（越来越快的发牌，均值仍≈12f），末张 f≈123.5 落定，留 ~20f 静止
- 入场是 6 帧短促动作：`seg(f, LAND-6, LAND, E.outCubic)`，`translateY(-40→0)` +
  `scale(0.94→1)`；飞行段按速度加纵向高斯运动模糊（落定为 0），1.5f 内即不透明
- 落位 squash：落定后 2.4 帧内 y 轴按正弦包络压 3% 再弹回——短到读不出是
  变形，只读作"砸实了"
- 堆积推移：每落一张新卡，下面整叠被推一格（向下 30px、向右 `XOFF=9`px，落位前 0.5f 起
  6f ease-out 走完），不再是匀速漂移；形成微微向右下的轴线，让卡不是同心叠放而是有厚度的一叠
- 深度衰减：`depth = min(1, drift/(30*3))`——三格内衰减到底，`blur(depth*4)` +
  `brightness(1-depth*0.25)` + opacity×(1−0.3·depth)、阴影随深度减弱（亮底上不糊成黑块）；再往下 `(drift-30*3.2)/(30*1.6)` 把 opacity 拉到 0 回收
- 焦点唯一：只有最上一张显示 body（分类 chip + 作者 + 两行摘要 + 编号/引用/页数），飞行后半程
  淡入、被下一张盖住时淡出，其余卡只留标题——"正在读的那一张"永远只有一张
- 背景 grid：`translateY((已推格数*30*S) % 24)`，位移量与卡的推移用同一个累计量
  推导，所以 grid 与卡堆严格同步（一推一停）；对 24px 取模让它无缝循环，上下羽化

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 节拍 | 间隔 14→9.5 帧递减（均值≈12），11 张 | 12f 是"紧但看得清"的均值；<8f 标题来不及读，>20f 量级感垮掉变成逐张展示 |
| 入场行程 | 6 帧（outCubic），提前量 -6 帧 | 行程只有节拍的一半 → 每张在下一张来之前已经落定；行程 ≥ PER 时会有两张同时在飞 |
| 入场位移/缩放 | `translateY(-40→0)`、`scale 0.94→1` | 40px 相对 96px 卡高是小幅——卡是"落进去"不是"飞进来"；缩放差只有 0.06，再大就读作弹窗 |
| 落位压缩 | 2.4 帧正弦包络，y 轴最低 ×0.97 | 3% 是刚好能感知的量；>6% 或时长 >3f 会看出橡皮变形 |
| 堆积轴线 | 每被压一张 y+30px、x+9px | 9/30 的比值决定轴线斜度；x 归零会变成正下方同心叠压，厚度感消失 |
| 深度衰减 | `depth = drift/90`，blur 0→4px、brightness 1→0.75 | 90px（3 个节拍）内衰减完 → 画面里始终只有约 3 张是"半清晰"的；衰减距离拉长会让下方糊卡堆太厚，画面变脏 |
| 回收窗 | `drift > 96px` 起淡出，48px 内到 0 | 回收太早会看到卡在画面中央消失；太晚 13 张全在场，DOM 与 blur 开销都上去 |
| 内容坐标系 | 逻辑 420×250，整体 `scale(min(W/420, H/250))` | 所有像素值写在逻辑坐标系里，改画布尺寸不用重排；卡 296×96、字号 9.5px 都是逻辑值 |

## 已知坑
- 卡数与节拍是绑定的：11 张按递减间隔排完在 f≈123.5，尾段 ~20f 静止定格。加卡或拉长间隔前
  先算末张落位帧，必须留出 ≥15f 的静止尾巴，否则末帧又会停在入场途中
- 正文淡出窗绑定在下一张的 `LAND` 上，最后一张没有下一张所以常亮；改时间表时保持这对耦合，
  否则出现"没有任何一张是清晰的"
- 全部时间常量都写死在 144 帧的假设上（`F=144`, `fr=f/F`）。改时长必须同时改 F，
  否则节拍会随时长伸缩，12 帧的紧凑感丢失
- 标题/作者/摘要是 11 条虚构的论文条目、`arXiv:24xx` 编号由索引生成，落地要换成项目
  真实文档；摘要固定两行 clamp，换长文案不会撑破卡高
- 深色卡（`INK` 底 + `#2A2A2A` 描边）压在 `#FAFAFA` 浅底上是这套对比度的前提；卡色
  改浅后 `brightness(0.75)` 的深度衰减几乎看不出来，需要改用 opacity 或灰度衰减
