## 意图
把界面拍成跑道：低角度透视里 UI 卡片悬空在不同高度，随后按界面
位置顺序（行优先左→右）一阵急雨式贴落——掉落感=干脆利落。
三个命门：**重叠并行**（起点只错 1.6f、下落 10f ⇒ 空中恒有 4–5 张
同时在落，"几乎一起但有涟漪感"；串行等待两轮被裁）、**零回弹**
（着地即停，弹起被裁）、**快**（下落 9f，15f 版被裁"快一点"）。
落齐后页面从躺倒立起（rotateX 66°→0°）、镜头拉远居中，观众从
"看戏"回到"看界面"。第二轮把地面做成为镜头设计的暗色 KPI 仪表盘（lime look，虚构产品
Tidewell「Launch week」，3×2 张 84px 大数字卡，只有主角卡是荧光黄绿实底），终帧就是一张可读的海报。

## 动效核心
- 美术：lime（石墨 + 荧光黄绿）暗场；地面 = 1760×960 暗色仪表盘（图标栏 + 72px 标题 + 3×2 KPI 卡），
  外面是一片朝地平线延伸的黄绿网格跑道 + 地平线光带；立起时跑道与地平线光淡出
- 机位：低角度强透视（rotateX 66° 起），开场 0–32f 同时向前滑行（页面在平面内由远滑近、镜头 z 前推、减速到停），
  网格同步流动 = 掠地速度感
- 悬空：卡片初始悬浮 170–310px（×1.5 布局，高度错落），空中被追光提亮 ×1.3（离地 <120px 平滑收回，着地不硬切）
- 贴落：起点 = 8 + i×1.6f + 微差(≤0.9f)（保序），下落 10f 重力加速（距离∝t²），着地即停零回弹；
  下落末段按速度加纵向运动模糊；地面投影随高度收紧变实
- 立起：f34 起 60f，rotateX 66°→0° + 镜头拉远归中（bezier(.5,0,.18,1)，后半程很软），
  终态正视、仪表盘 0.95 倍居中（四周 ≥120px 安全边）
- hold：Revenue 折线 80–110f 描出、主角卡数字 96f 再跳一档（48,210 → 48,396），极缓推近 1.5%
- 清晰度：场景按 1.5 倍布局（CSS zoom），终态 z≈−810 缩回 0.95 倍，正视时字形按高于显示尺寸栅格化（Q2）
- 地面槽位画极淡黄绿虚线框，卡片落进真实格位（Q9），落齐后虚线框淡出

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 起点差 | 1.6f/张（微差 ≤0.9f 不乱序） | 3f 版被裁"不需要一个落下了再启动第二个"；0 差读作开关（那是 orbit 的同帧语法） |
| 下落时长 | 10f 重力加速 | 15f 被裁慢；<6f 读不出下落方向 |
| 回弹 | 零（着地即停） | 压弹 4.5% 版被裁"去掉弹起"——掉落感=干脆利落 |
| 悬浮高度 | 170–310px 错落（×1.5 布局） | 同高读作阅兵；太高时低机位下卡片飘到地平线以上、和槽位脱离对应 |
| 空中提亮 | ~1.3x 追光 | 不提亮悬空不可感（返工判例） |
| 立起段 | rotateX 66→0 + 拉远，60f | 只落不立起=没有收束；立起太快读作弹板 |
| 掠地滑行 | 0–32f，页面平面内 −420→−60、z −1000→−760 | 不滑行时低机位读作静止俯拍，"掠地"感消失 |

## 已知坑
- demo 用的是为镜头设计的虚构仪表盘——参数是调校起点非实战定稿，
  首次实战须以真实素材回验；低机位下透视会把文字压斜，立起前不指望读字
- 贴落节奏语义（三卡判例族）：本卡=急雨式重叠错峰；
  graze-face-tour=巡礼错峰；neon-frame-orbit-drop=同帧齐落。
  按镜头语义选，错用即被裁
- 与 deck-deal-flyin 分工：那张是卡片飞入列队（水平方向运动）；
  本卡是垂直贴落+页面立起的两段式，掉落感是本体
- 立起段原片无对应参考（用户口述新增），终态版式对齐 clickup11
  正视图
