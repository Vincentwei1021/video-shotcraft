## 意图
入场库全是"从外面进来"——飞入、砸落、翻面，主体都预先存在于画外；
本卡是**就地长出来**：画面中心一个发光正圆先鼓一口气（scale
1→1.14，再压到 0.94 预备），随即轮廓连续变形为圆角矩形卡片，光褪成卡面、内容再进来。原型
停留加呼吸这一拍就是预备动作——迪士尼 anticipation 的图形学翻译：
圆先"吸气"，观众就知道它要变，变形本身因此不需要任何解释。
仅适用图形/图标/卡轮廓类主体——位图截图不能 morph。

## 动效核心
- **圆与圆角矩形写成同构 path**：M + 8 段 cubic（4 直边段三等分点
  做退化 cubic + 4 圆角段 kappa 公式 k=4/3·tan(Δθ/4)），逐命令
  数值 lerp 生成 d 字符串，帧驱动全确定性
- 圆锚点取矩形锚点同方位角，保证 t=0 是标准正圆、中途无自交
- **两轴分开计时**：所有 x 坐标用 tx、所有 y 坐标用 ty 插值，横向 31f 起、纵向晚 3f，
  像先被拉宽再撑开，生长有重量；两轴都用 bezier(0.6,0,0.25,1.07)，尾段 ~2% 过冲收住
- 呼吸拍：吸气 14f bezier(0.33,0,0.2,1) 缓鼓到 1.14 → 呼气 7f bezier(0.55,0,0.35,1)
  干脆压到 0.94（预备下蹲）→ 变形开始后 13f 回正到 1；进度全部钳位
- demo 的原型是一颗发光光球（graphite 暗场）：填充用**固定圆心的 userSpace 径向光**，
  变形时光保持圆形向外晕开变暗、深色卡面从光的边缘长出来（用 objectBoundingBox 会把光压扁成一块米色）；
  亮边 3px → 发丝线、外发光 → 两层软阴影在 54–70f 实体化时完成，扫光只走一次（Q4）
- 内容是 HTML 层叠在 SVG 上，实体化后才进：眉题 60f → 80px 标题逐词升起 64f →
  三条决议 78/84/90f → 声波条 86–110f 从左长出；光球缩成卡片左上的小图标前后呼应
- 时间轴 150f：0–10 静置｜10–31 呼吸｜31–58 变形｜54–70 实体化｜60–110 内容｜110–150 hold（极缓推近 2.5%）

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 呼吸幅度 | 1→1.14→0.94→1（吸 14f / 呼 7f / 回正 13f） | <1.1 读不出"吸气"；>1.2 像要爆炸不是要变形；呼气压到 <1 是预备下蹲 |
| 原型停留 | 静置 10f + 呼吸 21f，合计 31f 才起变形 | 停留 <15f 读不出"预备"，变形显得突兀 |
| 变形时长 | 每轴 24f，纵向晚 3f（合计 27f） | 太快像切换、太慢像融化；两轴错开 >6f 读作两段动作 |
| 目标形态 | 1120×640、圆角 48 的卡（画宽 58%）；原型圆 R=165 | 圆角越大与圆同构性越好、中段越顺 |
| 光的半径 | R·1.06·(1+1.6·shape)，变形中光衰减到 ~40% | 光跟着形状拉伸 = 米色色块；光不衰减 = 卡面一直发白 |
| 内容进场 | 实体化开始后 6f 起，逐词/逐行错峰 | 变形没完就进内容 = 内容跟着轮廓扭 |

## 已知坑
- demo 在灰阶/占位素材上调校通过——参数是调校起点非实战定稿，
  首次实战须以真实素材回验
- **变形中途别叠其他动画**——morph 本身就是全部信息，同时飞入/
  变色/晃动会把"长出来"稀释成"乱动"
- 位图截图不能 morph：本卡只对矢量轮廓成立，页面截图请回
  入场库常规手法
- path 插值两端命令数必须严格同构（同为 M+8C），命令数不齐
  中途会闪跳；改目标形状时先对齐锚点数再调参
- 变形中段呈"桶形"过渡是正常形态（QA 判例），不是穿帮；
  出现自交/尖刺才是锚点方位角没对齐
