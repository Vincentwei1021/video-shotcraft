一句话: "Your ___ teammates." 填空排版，朱红四角对焦框钉在句中不动，头像队列在框内垂直 spring 轮换三次，入框放大清晰、出框按距离缩小淡化模糊，角色标签同步更换，切换瞬间对焦框呼吸 7%
适用: "一个位置，多种角色"的能力枚举；团队/身份/预设/人格类产品的核心一句话镜头
时长: 约 5.2s（156f@30fps）
能量: 中（三次等距切换构成稳定节拍器，对焦框脉冲是唯一装饰性动作）

## 意图
"我们有设计师、客服、分析师、写手"列成四行就是一张清单。塞进一句话的一个槽位里，
它变成一个承诺加四次证明：句子不动，只有槽里的人在换。四角对焦框是这个手法的关键
——它不参与轮换，但它把观众的眼睛钉死在那个方框里，所以四次更换才读作
"同一个位置"而不是"四张头像飘过"。

## 动效核心
（demo 版本：暖纸瑞士海报，句子 150px/800 粗黑体，槽位 260px，1920×1080 原生坐标）
- 位置量 `pos` 是三段物理弹簧的累加：`[40, 74, 108].reduce((p, s) => p + springAt(f, s,
  {damping:15, stiffness:150}))`——不是索引跳变，而是连续量，所以任意时刻都能算出每个头像离槽位有多远；
  damping 15 给一次可见过冲（≈7%），每次 ~22f 落定
- 距离驱动一切：`d = |k - pos|`，然后 `scale = max(0.5, 1-d*0.4)`、`opacity = max(0, 1-d*0.62)`、
  `blur = min(8, d*6) + |vel|*10`、`translateY = (k-pos)*236`、落影随 d 变浅——同源于一个距离量，
  入框/出框天然同步；`vel = pos(f+.5)-pos(f-.5)` 额外给移动中的头像竖向拉伸 ≤8% + 运动模糊
- 队列是绝对定位在槽中心 0×0 锚点上叠放的（`left/top = -AV_SIZE/2` 自居中），框外的头像照样渲染，
  只是被 opacity 和 blur 藏掉；邻位露出半张、缩到 0.6，暗示"后面还有人"
- 入场是叠在轮换之上的另一层：头像 `ramp(f, 8+k*4, 18)` 从下方 60px 浮入，句子两词 rise 从基线下升起，
  对焦框四角从外侧 70px overshoot 收拢锁定（6→24f）；之后入场项恒为 1，轮换全权接管
- 角色标签：槽下一枚纸面名牌 chip（实底压住下方队列虚影），里面「编号 · 52px 角色名 · 名字」随 `pos`
  同向滚动（步距 70px），`opacity = max(0, 1-|k-pos|*2.4)`——0.42 格外完全消失，永远不会两个标签同屏
- 对焦框呼吸：`breath = min(1, Σ sin(clamp((f-s)/14)·π))`，四角各向外推 `breath·SLOT·3.5%`
  （总尺寸 +7%）；正弦包络让脉冲在切换动作的正中达峰，走完归零
- 画框骨架：12 栏发丝网格 + 基线、左上 mono 眉题、右上 `0N / 04` 计数、右下进度胶囊（当前位拉长成朱红）、
  左下 32px 说明句；相机全程 1→1.03 smooth 极缓推进

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 切换点 | 40 / 74 / 108f，间隔 34f（1.13s） | 间隔就是"读得完一个角色"的时长；<20f 观众来不及看标签，>45f 节拍器感散掉 |
| 弹簧 | damping 15 / stiffness 150，~22f 落定 | 落定后静置约 12f；damping <12 抖两下会和相邻切换互相干扰，>22 无回弹读作滑轨 |
| 步距 | STEP=236px（框 260、头像 212） | 步距必须大于头像直径否则相邻两张会咬边；邻位仍露出一角，队列的存在被暗示 |
| 缩放衰减 | `1 - d*0.4`，下限 0.5 | 一格距离缩到 0.6；斜率调大出框更决绝，但下限会更早触顶，队列变成"两档尺寸" |
| 透明度衰减 | `1 - d*0.62` | 1.6 格外完全消失 → 画面里始终约 3 张可见；斜率降到 0.3 整列四张都在，"锁定"语义被削弱 |
| 模糊衰减 | `d*6`，上限 8px（+ 速度项） | 景深暗示；>12px 邻位糊成色块，读不出是人像 |
| 标签衰减 | `1 - d*2.4` | 斜率必须显著大于头像的 0.62——标签是文字，两句同时半透明叠着最难读 |
| 框脉冲 | 14f，`sin(·π)` × 7% | 7% 是"咬合了一下"的量；>15% 框自己变成主角，抢过头像更换 |
| 字号配色 | 句子 150px/800、标签 52px、paper 暖纸 + 墨黑 + 朱红四角 | 朱红只给对焦框（及编号、进度胶囊）；头像底色用低饱和土色，别抢框 |

## 已知坑
- 四张头像对三次切换：`pos` 最终停在 3，正好是末位。加第五张必须加第四次切换（且
  末次切换要在片尾前 ≥25f 落定才有静置时间），否则队列末尾永远进不了框
- 切换点是同一个 `SWITCHES` 数组，`pos` 累加与 `breath` 累加共用；改节拍只改这一处，
  别为了单独调脉冲另抄一份数组，否则会出现"框脉冲和头像换位错开"
- 入场 stagger 与首次切换的间隔只有约 10f（末张入场 ~38f 落定 → 切换 40f）。加头像数会推后
  入场结束点（`8+k*4` 起、18f），5 张以上就要把首次切换往后挪
- 头像是为镜头画的插画人像（低饱和土色底 + 肩 + 头 + 四种发型 / 眼镜），强调色只用在对焦框的
  四个 SVG 角标上（及标签编号、进度胶囊）——落地换成真实头像后仍应保持这个分工，头像本身别抢色
- 对焦框 SVG 的四条 path 与 260×260 viewBox 是写死的坐标（`M4 62 L4 4 L62 4` 等）。改
  框尺寸要整套重标，只改容器宽高会让角标缩放失真
- 句子 "Your ___ teammates." 用 flex + gap:44px 居中，槽宽固定 260px 所以句干不会因
  头像更换而重排——但换成中文句子时要确认槽两侧的字宽变化不会让槽偏离画面中心
