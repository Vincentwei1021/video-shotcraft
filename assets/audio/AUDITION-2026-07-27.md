# 新增 SFX 试听清单（2026-07-27，Mixkit）

**筛选已完成。** 下载 165 个 → md5 去重删 3 个 → 试听筛选删 38 个 → **最终留用 124 个**，全部在 `assets/audio/sfx/<类别>/`。

本文件保留为留用音效的速查表（时长 / 峰值 / 建议钉点 / Mixkit 原名），已删掉的行不再列出。
库内全量清单（含首批 25 个）见 `ATTRIBUTION.md`；类别索引见 `references/sound-design.md` 3.0。

授权：全部 Mixkit Sound Effects Free License（免费商用、免署名）。逐条 URL 已登记在 `assets/audio/ATTRIBUTION.md`。

## 怎么用

```bash
# 按类别连播（类别目录见下面各节标题）
for f in assets/audio/sfx/paper/*.mp3; do echo "$f"; afplay "$f"; done

# 单个
afplay assets/audio/sfx/paper/paper-page-turn.mp3

# 再删音效时的自检：ATTRIBUTION 的 sfx 记录与磁盘是否一致（无输出 = 一致）
comm -3 <(grep -oE '^\| `[a-z0-9-]+\.mp3` \| `sfx/' assets/audio/ATTRIBUTION.md \
           | sed 's/| `//;s/`.*//' | sort) \
        <(find assets/audio/sfx -name '*.mp3' -exec basename {} \; | sort)
```

峰值列是 ffmpeg volumedetect 实测峰值（0dB = 满刻度）。全库无削顶（最响 -0.0dB 若干）。

**轻音素材统一以 -12dB 为界**（全库 7 个，含首批的音）：`data-load-os` -24.6、`pencil-write-short` -22.7、`write-fast` -20.0、`wing-flutter` -17.9、`ui-zoom-in` -14.3、`clock-knob-spin` -14.0、`clock-tick-single` -13.9。这些不是坏文件，但 **`volume` 是乘法系数不是目标音量**——给到 1.0 也只是原样播放，仍会被 BGM（0.34 铺底约 -9.4dB）盖住。处理办法（换素材／预归一化／给 >1 增益并验峰）见 `references/sound-design.md` 4.1，以那一节为准。

选音判据：**闭眼只听**，像不像产品发布会预告，而不是好不好听（S1）。长于 5s 的样本按 `references/sound-design.md` 4.1 靠 Sequence 截断使用。
