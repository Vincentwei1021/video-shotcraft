---
name: value-stagger-gradient
一句话: 16 根柱入场时 delay 是时间错峰，同时高度/色相/位移/模糊四个属性各自铺成从首到末的数值梯度；第二拍把错峰原点换成中心，脉冲幅度以中心为最大重新铺开
适用: 技法演示与参数化能力的展示镜头；也可直接当数据/频谱/均衡器类界面的入场
时长: 约 5.5s（165f@30fps）
能量: 中高（第一拍是连续铺开，第二拍中心脉冲是明确的一次峰值）
---

## 意图
stagger 通常只被用来错开时间。这张卡要说的是它还能错开**值**——同一个索引既决定
"什么时候动"，也决定"动到多少"。两拍是一组对照实验：第一拍原点在首位（梯度从左到
右单调铺开），第二拍原点换到中心（梯度以中轴对称铺开）。观众看到的不是两个动画，
而是同一个配方换了一个参数。屏幕上的代码字幕同步换成对应的 stagger 调用，明说这件事。

## 动效核心
- 核心工具是一个 8 行的 `staggerVal(i, n, a, b, ease)`：把索引归一化成 `k = i/(n-1)`
  再 `lerp(k, a, b)`——等价 anime.js 的 `stagger([a, b])` 值模式，可选 ease 让梯度非线性
- 静态梯度（setup 里一次算完）：色相 `staggerVal(i,N,80,30)`（荧光黄绿 → 琥珀 → 橙的热度色带，
  不经过刺眼的纯绿）、最大高度 `staggerVal(i,N,560,195)`px（设计值 92 → 32）——16 根柱天生是一道斜坡
- 动态梯度（每帧用）：行程 `staggerVal(i,N,184,56)`px、模糊 `staggerVal(i,N,30,8)`px
  ——首位柱要走 184px、糊 30px，末位只走 56px、糊 8px。**同一次入场里每根柱的行程都不同**
- 让值看得见：每根柱头一枚 32px 等宽数值标签就是 stagger 给它的值——拍一显示高度 92…32（随柱升起计数），
  换拍时标签按 distC 从中心向两端逐个滚换成脉冲幅度 +06…+42…+06。观众读到的数字本身就是梯度
- 第一拍时间错峰：首柱 8f 起，`i*2.2f`（总 33f），单柱 26f expo-out；`opacity`、`blur((1-e)*b0)`、
  `translateY((1-e)*y0)` + 高度 `hMax*e` 由同一个 e 驱动；柱群裹在基线以上的裁切层里，行程读作"从地板槽升起"
- 第二拍换原点：`distC = |i - 7.5| / 7.5`，脉冲窗 `86 + distC*12` 起、26f——中心柱先动，波向两端扩，
  这就是 `from:'center'`；中心脚下亮起原点三角 + 「FROM CENTER」，地板基线上一道光从中心向两端跑，
  前沿与脉冲波前用同一个 distC 时间函数
- 第二拍的幅度也是梯度：`amp = lerp(1-distC, 0.06, 0.42)`，中心柱脉冲 42%、末端只有 6%；
  `pulse = sin(w*π)` 是纯脉冲，叠进高度 `hMax*e*(1+pulse*amp)` 与柱身外发光（顶部只微提亮，不洗白）
- 代码字幕升格为画面主标题：44px 语法着色等宽代码 + 22px 眉题拍号（01 TIME + VALUE · FROM FIRST /
  02 SAME RECIPE · FROM CENTER）；80f 旧句 10f 上卷退出、新句逐 token 自下滚入
- 舞台：lime look（石墨底），镜面地板倒影 + 地平线光带 + 柱群背后跟随色带的底光；全程相机 1.000→1.025 极缓推进

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 柱数 / 版式 | N=16，步距 100px、柱宽 62px，柱群 1600px 居中（x 160–1760），基线 y=868 | 16 根让梯度有足够分档；<8 根读作"每根都不一样"而非一道斜坡；改柱数按步距重算 X0 |
| 时间错峰 | `i*2.2f`（总 33f） | 2–3f 是连绵的铺开；>5f 变成逐根点名，梯度的"整体感"丢失 |
| 单柱行程 | 26f expo-out | 行程略小于错峰总量 → 大部分时间七八根同时在动；行程远小于错峰时变成一根接一根 |
| 高度梯度 | `stagger([92, 32])`（560→195px） | 首末 2.9 倍差是明确斜坡；比值 <1.5 读不出梯度，>4 末端柱矮到看不见 |
| 色相梯度 | `stagger([80, 30])` | 50° 跨度的热度色带；跨过 100–140°（纯绿）会刺眼发廉，跨度 >200° 绕回读作环形 |
| 位移/模糊梯度 | `stagger([184,56])`px / `stagger([30,8])`px | 本卡的"值 stagger"主证据——改成常量，动效立刻退化成普通的 stagger 入场 |
| 数值标签 | 32px mono，柱头上方 58px；换拍滚换 10f，按 distC 错峰 12f | 标签是把"值梯度"翻译成可读证据的关键；小于 28px 只剩纹理 |
| 第二拍原点 | `from:'center'`，传播 `distC*12f` | 归零则整排同时脉冲，`from` 参数就没有意义了 |
| 脉冲幅度梯度 | `lerp(1-distC, 0.06, 0.42)` | 中心 42% / 端点 6% 是 7 倍差，波形明显；两端也给大幅度会读作整排一起鼓 |
| 节拍 | 拍一 8–67f → hold 至 80f → 换拍 80–92f → 拍二 86–124f → 静止 hold 41f（共 165f） | 两拍之间 ≥13f 的 hold 让观众先读完终态斜坡再换参数 |

## 已知坑
- 第一拍与第二拍首尾相接：末柱入场结束于 `8+15*2.2+26 = 67f`，脉冲 86f 起。加柱数或加大时间错峰会让
  入场吃进换拍段，两拍糊成一件事——加柱必须把 SWITCH / B2 后推
- `distC` 的分母 `C=(N-1)/2` 在 N=1 时会除零；`staggerVal` 里已用 `n<=1 ? 0` 兜住，
  但 `distC` 没有——柱数改成 1 会 NaN
- 字幕是 anime.js 的 API 调用字符串，本质是**技法说明**而不是内容。用在真实成片里
  要么换成有语义的标题（标签改成真实数据单位），要么去掉——否则观众读到的是代码
- 脉冲时别把柱顶提到接近白色：暖色带一提亮就洗成奶油色，梯度看不见；脉冲靠外发光 + 高度表达
- 暗底 + 高饱和柱 + 外发光是一套；浅色主题下发光失效，需要改用 saturate 或阴影表达脉冲
