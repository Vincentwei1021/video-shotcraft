一句话: 标题文字入场两式——scramble-decode 乱码解码（噪声里长出答案）与 letter-drop-physics 字符坠落（重力砸落弹跳归位），按调性二选一
适用: 大标题/章节字卡的入场；与 split-flap-title（机械翻牌）、document-typewriter-reveal（打字机）同品类互斥选用
时长: 单式 4.5–5.5s（A ScrambleDecode 140f / B LetterDropPhysics 160f，含 hold 与静止收尾；动作段 A ~86f / B ~116f）
能量: 中高（A 偏理性推进，B 偏物理趣味）
---

## 意图
标题入场库内已有打字机（沉稳文档感）和翻牌屏（机械仪式感），这两式补
另外两种性格：A 是解密感——字符先是一片高速噪声，从左到右逐个
"解码"锁定，观众看着答案从乱码里长出来，适合技术产品的自信亮相或"揭秘/发布"
时刻（demo 做成亮场机密档案的涂黑揭封；终端暗场版见 scramble 卡，同片别两种都用）；
B 是物理喜剧感——字符从天而降、砸地弹跳、歪歪扭扭站定，最后一拍
集体立正归位，适合轻松调性的开场破冰。四种标题入场同片 ≤2 种（P4）。

## 两式选型
| 式 | 做法 | 适用 |
|----|------|------|
| A scramble-decode 乱码解码 | 全员字符高速跳乱码（demo 做成机密档案：标题整行盖着涂黑条，乱码在条上跳），一道解码波前（竖向读头细线 + 光带）从左到右扫过、逐个锁定真字符并越扫越快，锁定瞬间反色闪 2f、涂黑块收拢消失；副标题随后瀑布解码，急停是一枚「DECLASSIFIED」橡皮章砸下 | 技术/开发者产品；"答案浮出"的理性推进感 |
| B letter-drop-physics 字符坠落 | 字符错峰从画外砸落，重力加速+两次衰减弹跳+落地歪斜站定，地平线随落点弹性下陷；句号作为最弹的小球最后落定，全体一拍齐整回正 | 轻松调性开场；"活物感"的标题破冰 |

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| A 乱码期 | 0–14f 全员每 2f 跳一个随机字符（字符集去掉 O/0、I/l/1 等易混字形）；demo 为 porcelain 亮场档案：乱码是纸白衬线字形画在墨色涂黑块里（被块裁切），离波前 3 槽内变亮、带钴蓝泛光、改 1f/次跳动 | 槽宽不能跟着乱码变：等宽字体用固定 1ch 槽；比例 / 衬线字体每槽先放隐形真字撑出自然字宽，乱码绝对定位居中叠上并裁进槽内，否则每跳一下整行抖动 |
| A 解码节拍 | 第 k 个真字符在帧 14+58·(1−(1−k/14)^1.45) 锁定（15 字，间隔 8.3f→3.4f 越来越快 = 解码提速）；锁定后前 2f 涂黑块闪成强调色 + 白字，随后块从中线 scaleY 收拢 6f、真字 1.12→1 收回 8f；标题锁完斜体副标题 0.6f/字瀑布解码；98–103f 橡皮章加速落下（scale 1.5→1），触地墨色一次到位作急停 | 起步间隔 ≥8f 让观众看清"逐个锁定"的规则，之后可加速到 ~3.5f；全程 <4f 读作一闪而过、>10f 读作卡住 |
| A 伪随机 | `CHARSET[floor(h(i*101+tick*7+13)*len)]`，tick = floor(f/2)（波前附近 tick = f），h = sin hash | 严禁 Math.random——跳动必须随帧确定，否则渲染不可复现 |
| B 坠落 | 第 i 字符帧 6+30·(1−(1−i/6)^1.6) 起跳（间隔 6.9→2.6f 越来越密）；从画外 DROP=980px 落下，y = −DROP + DROP·(t/20)²（重力，下落中按速度竖向拉伸 + 运动模糊）→ 4u(1−u) 抛物线弹跳 22% → 二跳 6%，每跳时长 = 2·20·√h（同一重力下的真实比例）；句号小球 34%/11%/3% 三跳、44f 起跳 | 字母两跳是"有弹性但不闹"的甜点，三跳以上读作果冻——只把多跳留给句号这类"球" |
| B 歪斜 | 落地 6f 内 rotate 到 seed hash ±5° 并保持，按歪角把字抬起 sin(abs θ)·半字宽（底角贴线）；句号不歪 | 歪角是"物理感"的一半；全体笔直落地读作普通位移入场 |
| B 归位一拍 | 句号停稳后（帧 110）3f 吸气撑到 1.05 → 9f ease-out 集体 rotate→0（overshoot 一次）+ scale 回 1，副标题随后逐词升起 | 集体归位是句号——错峰归位会把"立正"的仪式感拆散 |
| B 弹性地平线 | 6px 墨线是一根 polyline，每次触地在落点按高斯包络（宽 ≈ 0.55 字宽 + 60px）做比挤压慢一拍的阻尼振荡下陷（exp(−d/5)·sin），字符始终踩在线上；首次触地两侧扬起 5 团纸灰 | 下陷振幅 ≈ 字宽相关的 16–26px；再大读作蹦床、喧宾夺主 |
| 收尾 | 两式动作完毕真静止 ≥20f | R1：静止期所有属性锁死（含 B 的歪角归零后） |

## 已知坑
- demo 在灰阶/占位素材上调校通过——参数是调校起点非实战定稿，
  首次实战须以真实素材回验
- A 式是声音强依赖候选位：锁定的"嗒"声逐字钉帧（sound-design §4.5）
  会让解码感翻倍；B 式落地砸声同理，无声版两式都还成立但少一半劲
- A 式字符集别混入与真字符太像的字形（如 O/0 连跳）——观众会误判已锁定
- B 式字符间不做真实碰撞（demo 为各字符独立轨迹）——字距排开即可；
  想要"互相撞歪"需预烘焙轨迹，成本高收益薄
- B 式地平线下陷 / 接触影 / 纸灰按写死的字心坐标定位（SF Pro Black 290px 实测）；换字、换字号、换字体
  要重量一次字心，否则下陷中心会偏到字缝里
- 标题入场品类已四式（本卡两式 + split-flap-title + document-typewriter-reveal），
  同片 ≤2 种，且都自带高注意力——别和其他高能量入场同帧抢戏
