## 意图
Wes Anderson 手账美术与立体书纸艺的 UI 翻译。A：卡片像纸一样从画外滑翔落到板前，
悬着微晃（未固定的纸），两条撕边半透明胶带"啪、啪"先后拍在对角——第一条把钉点锁死、
卡片改绕钉点摆，第二条拍下**同帧**卡片停晃、投影由远虚收成贴板实影、整卡贴板——
"按死"的定妆一瞬是主角，两声"啪"是天然音效点。B：摊开的书页平躺（俯视），页上印着的
卡片是模切纸片，沿各自底边由远到近错峰立起成墙，立到 ~95° 回弹 90°（纸的韧性），
最近的一条标题横幅最后立起收尾；根部投影随立起收窄。

## 两式选型
| 式 | 做法 | 适用 |
|----|------|------|
| A masking-tape-slap | 卡片 1040×640 位置弹簧落入（damping 15）+ 仰角 34°→0 / 倾角 -9°→0 晚 3f 收敛；悬浮晃动 = 幅度包络 × 正弦（rot ±1.3° / bob ±6px / 3D 微倾 ±2°），离板 30px 时整卡放大 1.2%；胶带"从镜头方向"拍下 5f：scale 1.7→1 的 ease-in 加速 + 失焦，落帧压扁 0.84 一帧再 1.015 回弹；撕边 20 点 clipPath 锯齿 | 单卡/徽章/印刷品的定妆入场；文案重音对齐 |
| B popup-book-rise | 双层 3D：书页 rotateX 55°→70°（相机降臂，0–96f in-out，persp 2400），每片 rotateX 0→-90° spring（damping 11 过冲到 ~-95°），origin 底边，preserve-3d 贯通；后排 3 张高卡间隔 6f、前排 3 张矮卡间隔 5f（越来越密）、标题横幅最后 | 整版 dashboard 开场；"系统被搭建起来"、年度/季度报告 |

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| A 钉点锁定 | 胶带①落下后 3f 内把卡片平移改成由旋转反推（钉点世界坐标固定），晃幅衰到 0.4 | 不锁钉点，卡片在胶带下面滑，读作"胶带没粘住" |
| A 按死三件套 | 同帧：晃动 2f 归零 + 离板高度 30→2（投影偏移 elev×(0.75,1.25)、blur 4+elev×1.7）+ 全卡下沉 2px | 三件拆帧就没有"按死"感 |
| A 胶带拍击曲线 | ease-in（a²·(0.4+0.6a)）加速砸下 + 落帧压扁一帧 | 用 ease-out 读作"轻轻放上去"，拍击感消失 |
| A 胶带质感 | 香槟金半透明 + 纵向纤维 + 上下缘透光 + 撕边锯齿，落点故意歪 2–3° | 歪斜是设计的手工感；直挺挺读作 UI 元素 |
| B 立起方向 | rotateX 0→**-90°**（向观众立起） | demo 判例：方向写反卡片往画面里倒被底板裁切 |
| B 行距与遮挡 | 三排铰链线 620/1040/1460（页面坐标），后排高 480–540、前排 240、横幅 200 | 行距太小前排会挡掉后排大半；卡片关键信息放上半部 |
| B 根部投影 | blur 矩形不随卡立起，高 136→26px、透明度 0.24→0.1 随角度插值 | 无投影纸片浮空；投影跟着立起来穿帮 |
| B 相机 | 55°（开场看清整页印刷）→ 70°（立起的纸墙接近正对镜头） | 角度不变时躺平态与立起态差别太小，"立起来"读不出 |

## 已知坑
- A 的晃动是"未固定"的叙事铺垫不是手持抖动（Q3 边界）：
  振幅包络必须最终归零，全片只在被按死前存在
- A 暗场里投影难读：卡片背后要有一圈暖色聚光把板面提亮，悬浮/贴板的投影差才看得出
- A 胶带落点会压住卡角内容：卡内文字离右下角留 ≥ 160px，别让胶带盖住正文
- B 与 tilt-reveal 分工：tilt 是**机位**抬头看静止页面，
  本卡相机只陪着降臂，主角是**构件自己**站起来
- B 开场相机俯角大时，后排高卡立起中段顶边会短暂出画；起始俯角别低于 55°
- B 卡片立起后约 -15°~-20° 正对镜头，字可读；书页本身的印刷（页眉/行线）在 70° 下只是纹理
- 声音：A 两声"啪"（纸拍击拟音）；B 每排立起一声轻纸响，
  错峰对齐（S2/S4 同源）
