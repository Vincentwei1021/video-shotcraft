## 意图
让观众"跟着做一遍"：看清输入了什么、页面怎么响应、点了哪里。这是全片唯一模拟真人操作的镜头，节奏必须像人手，不能像脚本。

## 动效核心
- 页面（真实截图纹理）装进暖纸色浏览器窗，浮在石墨暗场上（暖色主光 + 窗下地面光），地址栏随操作换路由
- 相机贴近搜索框（zoom 2.5，输入字有效字高 ≈44px）逐字符打字、随光标微移，光标常亮→闪烁；打完的呼吸位拉开到整窗（zoom 1.0）看网格收敛
- 打完留一口气，然后非目标卡按阅读序错峰淡出下沉，网格收敛；计数 "显示 10/10 → 1/10"、分组标题换成目标卡所属分组、下方空分组淡出
- 目标卡从视口下方升到首行槽位，途中浮起 + 阴影变宽 + 纵向速度拖影
- 指针在全景里带弧线滑到目标卡（屏幕尺寸恒定），双圈琥珀 ripple + 描边点击确认，卡片做容器变形（shared element）展开成详情页，相机同时推近详情标题（zoom 1.75）落定

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 打字速度 | 3f 基准、人手不等间隔（demo 10/13/16/19/24/27/30/33："-" 前犹豫一拍） | 初版嫌快返工后的定稿值（"unhurried"）；交互演示按真人操作速度走（R3）；完全等间隔读作脚本 |
| 呼吸位 | 打完（33f）到过滤（46f）留 ~13f，期间相机开始拉开 | 打完立刻过滤读作机器自动，观众跟不上因果 |
| 光标 | 打字时常亮，之后 8f 周期闪烁；展开详情时消失 | 打字中闪烁会读作卡顿；常亮→闪烁的切换本身就是"打完了"的信号 |
| 过滤退场 | 非目标卡按阅读序 0.9f 间隔错峰，各 7f ease-in 淡出 + 下沉 10px + 缩 3% | 同时消失读作页面崩溃；错峰哪怕只差 0.4f 也够 |
| 页面细节 | 计数 / 分组标题换字分两拍（先盖旧字 3f、再淡入新字） | 同一拍交叉淡化会新旧字叠影 |
| 目标卡滑位 | 16f 升到首行槽位，EASE.swift，途中 sin 浮起、scale +0.03、阴影随浮起变宽 | 终点必须是布局真实槽位（Q9），滑到画面中央悬停就假了 |
| 点击确认 | 两圈同心琥珀 ripple（起点差 3f、各 12f、半径 10→46/70 页面 px）+ 3px 描边 + 辉光 | 单圈 ripple 太轻看不见 |
| 穿透 | 容器变形 26f（EASE.smooth）：矩形卡片 → 整视口、圆角 16→0，详情页固定在最终位置、容器只当遮罩，卡片纹理 10f 淡出；相机 30f 推到 zoom 1.75 | 详情页跟着容器缩放会读作"图片放大"；模板片里也可以改为推进交棒给 flash-cut（assets/lib/FlashCut.tsx，from = 切点 − 5） |
| 搜索框 | 页面底色补丁盖掉纹理里的 placeholder（保留放大镜图标），文字层叠上去打 | 直接在截图纹理上叠字会和烤入的 placeholder 重影 |

## 声音
打字段钉 keyboard.mp3 并按 Sequence 截 24f 与动作严格等长（S4）；点击钉 click-camera（全片最响 vol 0.6，S2 响度分层）；网格飞走钉 whoosh-fast。

## 已知坑
- 初版打字+过滤"太快了"被返工（R3）——交互镜头的第一版几乎总是偏快，起稿就按 3f/字符
- 过滤后目标卡若不归位到真实槽位、悬浮在网格上方，读作假（Q9，曾因此近乎整文件重写）
