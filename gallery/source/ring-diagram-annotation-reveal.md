## 意图
直接出现一张环形图，观众只会把它当作静态信息图。本卡先让主体占满全画面，再用
收缩的圆形窗口把“内容”压成一个可分析对象；细环、分段环与向心箭头依次补齐机制，
最后整组退到左侧，右栏才给出名称和解释。视觉顺序因此是**先经历对象，再理解结构，
最后阅读定义**，适合科技、工程、数据和概念科普。

## 动效核心
（demo：虚构紧凑型聚变试验堆「Ardent-1」的磁约束图解，1920×1080 原生坐标，midnight 暗场）
- f0–10：主体全屏——等离子体（白热核心 + 环形等离子带 + 两层反向旋转的 feTurbulence 湍流丝缕）
  放大 3.6× 铺满画面，四角也不露边；这是后续圆窗收束的连续来源，不能空场开局
- f10–50：`clip-path: circle()` 半径 1150→230px（snappy `cubic-bezier(.16,1,.3,1)`）；等离子体同时 3.6→1
  （ease-out，晚 2f 起、晚 6f 收）——圆窗与内容两层速度不同，收束有纵深；落定后圆窗边缘亮起一圈青色轮廓光
- f18–42：r290 细环 + 72 道刻度从 3.8× 收到 1×；f30–52：24 块线圈（r400、厚 30px）顺时针逐块从外侧 34px
  "咔"入位（每块 8f、间隔 0.6f），内沿一道被等离子体照亮的青色轮廓光；f29 起外环匀速慢转（0.29°/f，至片尾 ~50°），
  细环与箭头不跟转
- f36–58：12 支箭头从线圈内沿 r378 向 r306 顺时针错峰长出（每支 10f、间隔 0.9f），箭头头部随线端同一进度推进，
  全部指向核心；f58 等离子体被"挤"一下（1→0.95→1，12f 阻尼脉冲）
- f90–134：整组中心 x 960→600、scale 1→0.8（swift 不对称 in-out）；等离子体、圆窗、三层几何共用同一 transform
- f112 起右栏：四个词块「Twelve / coils. / One / star.」各自从遮罩下升起（每块 16f、错峰 3f，两行间隔 6f）；
  f126–152 青色注释条「ARDENT-1 | COMPACT FUSION PILOT」自左 clip 揭出（不压扁文字）；f140–156 二级说明两行落入
- f156–199：只保留外环慢转与等离子体的极缓呼吸

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 圆窗收束 | f10–50，半径 1150→230px | 终点半径必须刚好包住内容圈；过大会失去"聚焦"，过小会切主体 |
| 内容拉远 | 3.6→1，f12–56 | 起始倍率要让内容外缘出四角；与圆窗同速会粘成一层 |
| 细环收缩 | f18–42，scale 3.8→1 | 比圆窗晚起，形成两层深度；细线宽按 1/scale 补偿，缩放时不变粗 |
| 分段环 | 24 块，r400，弧长占 64%，逐块入位 8f | 块数要稀疏可数；太密会读作普通虚线描边 |
| 外环旋转 | f29 起 0.29°/f（~50°） | **命门**：仅外环旋转；箭头跟转会把"向心关系"变成装饰转盘 |
| 向心箭头 | 12 支，f36–58，r378→306 | 线端和箭头头必须一起推进；头先到、线后长会穿帮 |
| 布局让位 | f90–134，x -360px，scale 1→.8 | 移动和缩放必须共享一条进度，否则同心结构会漂 |
| 标题错峰 | f112 起，每块间隔 3f，单块 16f | 间隔 >6f 会像逐字点名；0f 同时出现则失去"命名被拼出"的节奏 |
| 最终 hold | f156–199 | 可继续保留外环慢转，但文字和箭头必须完全静止 |

## 已知坑
- 圆窗半径大于画幅时 CSS `circle()` 仍要以同一中心计算；改分辨率时不要用宽度百分比近似，否则开头边角会提前露白
- 分段外环、细环和箭头是三层独立几何；合并成一张旋转 PNG 会让箭头也跟着转，破坏机制语义
- 布局左移后再单独定位右栏，不能把右栏放进同一 transform 容器，否则标签会跟着缩小漂走
- 四块标题是四个独立运动单元，不代表必须使用四个汉字；落地时可换四段短词（demo 用四个词）、四个图标或四枚状态块
- 终段只允许外环的低速持续运动；标题 glow、箭头呼吸或多点闪光会把解释镜头做成廉价 HUD
- 湍流纹理用 feTurbulence 生成 data-URI 小图，只栅格化一次、逐帧只做 rotate；别用逐帧变化的全屏 blur 模拟等离子体（贵且发糊）
- demo 为原创 DOM/SVG 重构（虚构装置与文案），不包含研究参考中的品牌、装置图片或文字资产
