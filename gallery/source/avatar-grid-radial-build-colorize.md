## 意图
两幕结构：第一幕"群体成形"——卡片从中心一环环长出，像镜头下的菌落生长；第二幕"异常浮现"——铺满后个别卡片陆续变红，观众的眼睛被迫扫描全场找红点。它把"我们帮你盯着所有项"这句话拍成了体验。

## 动效核心
- 分环 stagger：每格按 `ring = round(hypot((c-3.5), (r-3)/0.85))` 算环号，延迟 `10 + ring*4 + rand*3` 帧——同环内再加 0–3 帧随机抖动，生长波有机不机械
- 卡片入场只做 opacity（6f，ease-out）+ scale 0.86→1（10f，overshoot 小幅落座）+ 6px→0 收焦，**无位移**——"长出来"而不是"飞进来"
- 卡片内容三种混合（`rand(i*9.1)` 决定）：首字母头像、抽象人像、公司 logo（矢量 SVG，不用字体回退不可控的 Unicode 符号）——实际使用换项目素材（头像/logo/缩略图均可）
- demo 的配色策略：整面墙去色（graphite 暗场，健康点压成低饱和灰绿），画面里唯一饱和的颜色是风险红——红点一亮观众被迫扫全场找下一个
- 中央 3×6 区域 `visibility:hidden` 占位不销毁——网格完整性保留，给标题和汇总腾出舞台
- 染色幕：6 张（38 张的 ~15%，按固定种子挑、彼此曼哈顿距离 ≥3 保证分散）在 52/61/69/80/90/101f 陆续染色——底 / 描边 / 状态点同一条 7f 曲线 mix 到红，卡片顿一下（1→1.05→1）+ 一圈裁在卡内的红色涟漪，ARR 行换成流失原因；其余健康卡同时整体退暗 1→0.5
- 标题 112px 逐词从线下升起最先入（0–14f），汇总行「n accounts · $Xk ARR at risk」与三色图例 36f 跟进、随每次染红滚动计数；全部浮现后图例让位给红色行动胶囊「Bring them back in →」

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 生长速度 | 每 4 帧一环 + 3 帧抖动，~1s 铺满 | 快于 3 帧/环读作"闪现"；抖动砍掉后波前整齐得像机器 |
| 异常比例 | 15% | <8% 观众可能漏看；>25% "异常"变"普遍"，叙事反转 |
| 染色窗口 | 每张 7f，6 张散布在 52–101f、间隔不等（9/8/11/10/11f） | 全部同拍染色是警报不是浮现；散布区间越长"陆续发现"感越强 |
| 状态色 | 健康灰绿 #7FAE92 → 风险红 #FF4A3D（点 + 描边 + 外辉），暗底染成 #2A1414 | 暗场里健康色必须低饱和，否则红点不再是唯一的颜色；亮场版底色染红别深过 #F8D8D8 |
| 网格规模 | 8×7 − 中央 18 格 = 38 张可见（原生 1920：200×118 卡、gap 18、边距 96/72） | 更大网格需同步缩 gap 和字号；中央留空区随标题长度调；卡内名字 ≤ 9 字符，否则 22px 会被卡边截断 |
| 内容混合比 | 首字母/人像/logo 各 1/3（rand 均分） | 全换成同类（如全头像）也成立；混合版本更像"多类型资产"场景 |
| 其余退暗 | 健康卡 brightness 1→0.5（50–110f，EASE.smooth） | 不退暗时 6 个红点在 38 张卡里不够跳；退到 0.3 以下读作"其余卡被禁用" |

## 已知坑
- 中央留空用 `visibility:hidden` 而不是不渲染——删格子会让分环计算的环心偏移，生长波变形
- 染色的三个通道（底/描边/点）必须同一条 cT 曲线驱动，分开会出现"点红了底还白"的中间态
- 图片占位是 CSS 渐变色块，换真实图片时保留 `overflow:hidden` 和 border-radius 继承，注意深色图上状态点要加白描边
- 标题/汇总 z-index 在卡片之上但无底板，若换更密的网格需给中央区加半透明底垫保证可读
