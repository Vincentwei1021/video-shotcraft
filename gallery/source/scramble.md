---
name: scramble
一句话: 等宽大标题字符先每 2 帧高速跳乱码，再从左到右逐个锁定为真字，锁定瞬间字底亮起一块强调色反色块再退去——种子驱动可复现的解密感
适用: 技术型开场标题；版本号/代号揭晓；"系统就绪""数据解锁"这类带机器口吻的一拍
时长: 约 4.3s（130f@30fps：启动 + 噪声 hold 26f → 锁定扫过 ~58f → 落定 hold ~44f）
能量: 中高（持续高频跳字的视觉噪声，无单点冲击）
---

## 意图
同一句标题的三种"造字"手法里，打字机是人在写、翻牌是机器在播报，
乱码锁定是**机器在算**——先满屏噪声表示"还没解出来"，再左→右一个个
咬定真字符。它天然带黑客/解密腔，适合技术产品的开场；但也最挑文案：
字符是被逐个点名的，字数就是节拍数。

## 动效核心
- 版式（demo）：终端技术海报——两行 168px 等宽粗体 `AUTOPILOT / NOW ONLINE` 左对齐占画宽 ~55%；
  上方 HUD 抬头（系统名 / 构建号 / 节点 / T+ 计时，26px 纹理字），下方解算进度条 + 34px 状态行与百分比；
  右侧一列暗淡虚化的十六进制流（纹理，解完后减速停住），全屏叠极淡扫描线
- 起手 0–4f 标题位是暗色占位点 `·`（第 1 帧就有画面）；4f 起乱码按 0.5f/字从左到右依次启动，
  **每 2 帧重掷一次**（`bucket = floor(frame/2)`），全员乱码 hold 到 26f 才开始锁
- 锁定点：`lockAt = 26 + stagger(k, n, 54, bezier(0.36,0,0.6,1)) + round(rand(k·7.3)·3)`
  ——in-out 铺开（起步慢 → 中段快 → 收尾慢）+ ≤3f 种子抖动，末字 ~84f 定
- 锁定瞬间：字底亮起一块强调色反色块（字变 onAccent 深色），**满格 2f**、再 4f 线性退去，同时块外一圈泛光；
  字形 -0.04em 微落定。线性退去而非 ease-out：ease-out 第 1 帧就掉到一半，块读不出来
- 锁定前沿（解算头）：前沿字是强调色乱码 + 泛光 + 字底光标条，下一字半透明强调色，其余乱码按重掷在 0.38–0.78 闪烁
- 结论词 ONLINE 锁定后保持强调色 + 轻泛光；全部锁完 +2f：进度条满格、状态灯一次泛光、状态行由 "Decrypting…" 换成 "Link established"
- 乱码字符、闪烁与抖动全走种子哈希 `rand(seed)`，**禁 Math.random**，同一帧号永远同一画面
- 全程极缓推近 1→1.04（smooth）

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 占位文案 | `AUTOPILOT / NOW ONLINE`，19 个非空格字符，两行 | 字符数直接决定 stagger 密度：<10 字锁定太快读不出"逐个"，>30 字末字等到片尾 |
| 锁定窗 | 26f → ~84f，in-out 铺开 + ≤3f 抖动 | 噪声 hold 短于 ~12f 没建立"在算"；等差铺开读作进度条 |
| 跳字频率 | 每 2 帧（15 次/秒） | 1 帧一换糊成灰带；4 帧以上读作"慢慢翻"不是高速运算 |
| 锁定反色块 | 满格 2f + 4f 线性退去，块泛光 ≤40px | 这一下是"咬定"的画面体；块 <2f 肉眼看不到，>8f 整行像被选中高亮 |
| 字体字距 | SF Mono/Menlo 700 168px、槽宽 `0.62em` 居中 | 等宽 + 固定槽宽是刚需，比例字体会随乱码字符宽度整行抖动 |
| 配色 | lime：石墨黑底、乱码暗灰闪烁、锁定白、结论词与反色块荧光黄绿 | 亮度差本身就是进度条；强调色只给前沿、反色块与结论词 |
| 收尾 hold | 末字定后 ~44f | 状态行与进度条落定后要留够读整句的时间 |

## 已知坑
- demo 在灰阶/占位素材上调校通过——参数是调校起点非实战定稿，
  首次实战须以真实素材回验
- **换成项目文案时字符数要贴近 20**：lockAt 是按 `k/n` 归一化铺开的，
  字数变了锁定间隔跟着缩放——8 字标题会在半秒内全锁完（读不出解密过程），
  40 字标题每字间隔压到 1.4f（逐个咬定读成一抹）
- 必须等宽字体：槽宽写死 `0.62em`，比例字体下 `#`/`W`/`I` 宽度不一，
  整行会随每次重掷左右抽动
- 反色块放在字的下层（父容器 `isolation: isolate` + 块 `z-index:-1`），否则会盖住字形
- 右侧十六进制流是纹理：必须虚化 + 压暗（demo blur 2.2px、透明度 0.1–0.2），读得清就会和标题抢戏
- 空格字符被显式跳过（永不参与乱码），所以词间隙全程保持——文案里
  空格位置就是节奏的呼吸点，把长标题拆成 3–4 词比一整串更好读
- 与 split-flap-title / 打字机类分工：那两个是**机械/人工**造字，本卡是
  **算法**解字；一支片里同类"造字"手法只留一次，重复即贬值
