## 意图
库内节奏卡各管一段：beat-cut 管切点排布、montage-rhythm 管段落呼吸、
rhythm-interrupt 管打断。本卡管**预告片的结构性时刻**——不是某个
镜头怎么动，是整片的三个关节怎么接：A 是开场钩——正片前 0.9 秒塞
三个最抓眼镜头速剪 + 黑场静默一拍再开场，预告片的"预告"；B 是中段
对话——UI 镜头与黑底短语卡互相接拍交替硬切，画面与文字都踩拍点，
第三幕结构；C 是高潮句号——满屏动势轰鸣最高潮一帧硬切成整齐静止
全景死寂，喧闹→死寂。三式合用即一支预告片的骨架。

## 三式选型
| 式 | 做法 | 适用 |
|----|------|------|
| A trailer-bumper | 三镜头各 9f 等长硬切（0/9/18：微距命令行 / 全景大数字 / 特写按钮按下），每镜内部 scale 1→1.04 微推保活；27–33f 纯黑静默，33f 起舞台由黑亮起、标题逐字由虚到实从中间绽开 + 字距 0.42→0.16em 缓收、一道宽银幕光条横扫一次 | 正片开场前的钩子；cold open |
| B card-footage-cadence | 七段条件挂载分段（16/26/40/50/62/72 切点）：UI 段各讲一件事且带微动（推近 / 拖拽 / 落位弹跳），字卡段满版色块单词 1.05→1 落定微缩 | 中段画面与文字对话；卖点三连 |
| C smash-cut | 轰鸣段全 ease-in：未读计数加速冲高、背景推近 1→1.5 + rotate 2°、12 张通知卡两轮从中心加速冲脸 + 速度门控模糊；42f 一帧硬切到冷静的静止海报（暗红→暖米色、1,284→0） | 全片最高潮的收束句号 |

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| A 速剪 | 三镜等长 9f，零过渡；景别拉开：微距（荷兰角 −7°、上下行景深虚化）/ 全景正视 / 特写（反向荷兰角 +6°） | 节拍感靠等长；三镜构图必须明显不同 |
| A 微推 | 每镜内部 scale 1→1.04 线性 | 静帧三连读作幻灯片——命门 |
| A 黑场 | 27–33f 纯黑 #000 空 div，6f | 黑场里放任何东西都毁掉"静默一拍" |
| B 交替 | UI 段 12–16f ↔ 字卡 10f 硬切，条件挂载分段=天然零过渡；UI 裁切 1.7x / 2.2x 走 CSS zoom（字不糊） | 段长可变但要读出"接拍"感；字卡只放一个词 |
| B 字卡 | 满版克莱因蓝 + 米白 300px 单词左对齐（瑞士网格：页码 / 发丝线 / 一行注脚），第三张反白做变奏；落定 1.05→1 5f 内完成，其余全静 | 字卡的静 ↔ UI 段的动，质感对比即节奏 |
| C 切点 | 42f 一帧完成全部反差（内容、色温、明暗同时翻转）；切前 3f 动势仍在加速 | 绝不减速迎接切点——命门 |
| C 模糊 | 飞卡沿各自飞行方向做方向性模糊，量按瞬时速度算（>20px/f 起、屏上封顶 ≈18px） | 速度门控：快才糊，不是全程糊 |
| 收尾 | A hold 70f（3% 极缓推近 + 浮尘）/ B 真静止 45f / C 真静止 93f（≥40f） | C 死寂段直接 return 无动画子树（无颗粒），帧函数级真静止 |

## 已知坑
- demo 用为镜头手搓的虚构产品画面调校——参数是调校起点非实战定稿，
  首次实战须以真实素材回验
- A 黑场必须纯黑无物（drop-blackout 判例同族）——黑场是喘息，
  不是又一张字卡
- B 与 cel-flash-stomp/beat-cut 字卡段的分工：那些是字在表演
  （字自己是主角），这是字与画对话（互相接拍）——别混用
- C 死寂段绝对真静止、音乐同帧骤停——声音强依赖，无声版的 smash cut
  只剩一半（sound-design §4.5）；A 三连切每切一声打点、黑场全消音
- C 与 drop-blackout-slam 的区别：那是黑场蓄力再爆（静→爆），
  这是爆完瞬间入定（爆→静）——方向相反，别接错位置
