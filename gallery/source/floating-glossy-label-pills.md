## 意图
四个功能挨个全屏展示会切四刀，观众每次都要重新定位。走廊式 carousel 只有一个视觉
中心：居中的那块是主角，左右各露一截邻居的边缘告诉观众"还有更多、这是同一条队列"。
末段的光标是刻意的：它把叙事从"系统在自动播放"交回"这是一个人在操作"，为下一拍的
交互镜头做交接。

## 动效核心
- 这是**手法模板**：demo 面板是为镜头设计的虚构产品 UI（Halo：Compose 写作 / Insights 营收曲线 /
  Automate 三节点工作流 / Publish 分享发布），每屏只留一个主信息、要读的字 ≥30px；落地时整块换成
  真实页面截图即可（Q1）
- 轨道三拍写在 `BEATS`（帧）：24f 起 26f / 66f 起 20f / 98f 起 18f，每拍走一个中心距 SP。
  归一化进度用 `inOutCubic`（缓起→中段冲→缓收），**不是**常见的"快进慢出"；拍越来越短、
  拍间 hold 越来越短（16f → 12f），整段是"先从容、后加速"
- 首拍带长尾，两条曲线加权混合：`0.85*ramp(f, 24, 26, inOutCubic) + 0.15*ramp(f, 24, 42, outCubic)`
  ——主体 26f 完成，剩 15% 拖到 66f 才收住，首拍读起来明显比后两拍软
- 开场有上一拍的收尾余量：`trackX = -36 * (1 - outQuart(ramp(f, 0, 22)))`——一进画就"正在收尾"
- 环形轨道：`wx = ((trackX - i*SP) % RING + RING*1.5) % RING - RING/2`（SP=800，RING=4*SP），
  任一拍都保证左右各有一个邻居露在画面边缘，走廊不断；|wx| > 1.7·SP 的不画
- 一切属性由离心距离 `d = min(1, |wx|/SP)` 驱动：`scale = mix(1, 0.62, d)`、
  `rotateY = -sign(wx)·16°·d`（perspective 2200，邻位朝外侧转出纵深）、压暗 `0.5·d`、`blur = 2.2·d`px
- 面板与胶囊下沉曲线**不同**：面板 `translateY(d*120)`，胶囊 `translateY(d*150)`——胶囊沉得更多，
  离心时贴近面板顶边；胶囊混入 3f 前的轨道位置（权重 0.3），比面板晚约 2f 落定（跟随）；
  胶囊另有极缓的漂浮 `sin(f/20 + i·1.7)·4px`
- 换位时整条轨道按速度加横向运动模糊（`SpeedBlur` amount 0.065、封顶 3px），静止为 0
- 胶囊的"糖果玻璃"是四层叠出来的：180° 四段紫渐变（#ddd0ff→#a78bfa→#7c4dff→#5b21b6）+ 底部粉色
  反光椭圆 + 内描边/下沿内阴影 + 上 44% 的白色椭圆高光（左右内缩 18px），`overflow:hidden` 裁进圆角（Q4）；
  居中者外加一圈紫色泛光，并在面板顶沿洒一抹紫（溢光）
- 每块面板居中时自己的主元素做一个小动作（`FOCUS_AT` 起算）：Compose 逐字打出 AI 续写、Insights 数字
  数上来 + 曲线描出、Automate 光点沿连线跑过、Publish 开关打开——hold 段不是死帧
- 光标：118f **硬现**（2f），outQuart 20f 从 (1480,70) 斜滑到末位胶囊右端 (1086,220)；140f 点按：
  胶囊下压 5%（3f）后弹簧弹回（damping 14），随后一道单次扫光（18f，screen 混合，裁进圆角）
- 舞台：aurora 暗场（顶部主光 + 右下粉色余光 + 地平线光带）+ 面板脚下紫色地面反光 + 浮尘；
  全程整体极缓推近 1→1.025

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 拍点 | 24 / 66 / 98f，时长 26 / 20 / 18f | 拍越来越短 = 越巡越快；改成等长等距会读作机械播片 |
| 首拍长尾 | 0.85×主曲线 + 0.15×`outCubic(42f)` | 15% 的权重摊在 1.6 倍时长上；权重调到 0.3 以上尾巴会拖得能看出"还在动" |
| 换位曲线 | `inOutCubic` | 缓起缓收是关键；换 outQuad（快进慢出）立刻读作被甩过去，走廊的从容感消失 |
| 开场余量 | 左偏 36px，22f outQuart 归位 | "上一拍刚结束"的暗示量；归零则开场是死的，>~5% SP 会读作又一次换位 |
| 中心距 | SP=800px（面板 W=1040） | SP < W 时邻居压在居中面板身后露出一截；SP ≥ W 走廊断开成三张独立卡 |
| 邻位缩放 / 转角 | 0.62 / 16° | 缩放 >0.75 主次不分，<0.5 邻居小到读作缩略图；转角 >25° 邻位面板变成细条 |
| 邻位下沉 | 面板 `d*120px` / 胶囊 `d*150px` | 两条曲线的差让胶囊离心时贴住面板顶边；改成同值会看到胶囊悬在面板上方 |
| 邻位压暗/模糊 | 压暗 0.5、blur `d*2.2px` | **邻位必须仍清楚可见**；压暗到 0.75 或 blur >4px 走廊就断了 |
| 速度模糊 | amount 0.065，封顶 3px | 超过 ~4px 中段整屏糊成一片，胶囊字也看不清 |
| 光标 | 118f 硬现（2f），outQuart 20f 到位，140f 点按 + 单次扫光 | 硬现是"指针本来就在那"；给它淡入会读作 UI 元素出现。outQuart 的强减速是鼠标的物理本能 |

## 已知坑
- 整卡色相来源是 `LOOKS.aurora`（舞台/面板/文字/强调色）加胶囊渐变里写死的 4 个紫色 hex 与粉色反光。
  换品牌色要两处一起改，漏掉胶囊 hex 会出现"面板换色了但胶囊还是紫"
- 例外：Automate 状态点的青绿（#5eead4）与头像渐变是**保留的功能/装饰色**，不跟品牌色换肤
- 三拍只走完 4 块中的 3 次换位（0→1→2→3），末位面板在 116f 之后一直居中到底，约 50f 的静置——
  这段是给光标滑到位、点按和扫光用的，不是空白
- 面板按"离心远的先画、居中的最后画"排序决定压盖关系；改成按索引画，换位中段会看到远处面板压住居中面板
- 居中面板 rotateY 为 0 时不写 `perspective()`，保证居中帧走 2D 栅格化、字不糊（Q2）；邻位本来就是虚化的纹理
- 光标终点 (1086,220) 是对着末位胶囊右端标的，且光标在屏幕空间、不随整体推近；胶囊固定宽度
  （`PILL_W=320`），换文案不改宽；改 `PILL_W`、`PILL_Y` 或推近幅度时必须重标光标终点
- 面板主元素的小动作按 `FOCUS_AT` 起算，改拍点时要同步改这张表，否则面板在邻位就已经做完动作
