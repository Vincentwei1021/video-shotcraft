---
name: canvas-materialize-moves
一句话: 内容"物化上画布"两式——panel-to-canvas 行倒卡（面板表格行沿弧线飞出、跨容器变形成画布卡片）与 diagram-cascade 级联生成树（prompt 打字后节点逐层弹出、连线先于节点生长）
适用: AI/协作工具"生成结果落到画布上"的叙事段落；A 式讲"已有内容换了个存在形态"，B 式讲"从一句话长出一棵结构"
时长: A ~5s（150f）/ B ~6s（180f）
能量: 中
标签: ui-entrance
---

## 意图
库内生成叙事只有"窗口内逐字写出"（document-typewriter-reveal 文档自己写出来）
和"图表自己活起来"（chart-live-moves），没有词管**内容离开容器、在
开放画布上物化成新实体**。本卡补这一块：画布是舞台，生成物是登台的
演员。A 式的命门是跨容器形态迁移——同一条内容从"行"变成"卡"，位置
/宽高/圆角/内容布局在一条 spring 上同步插值，观众读到"是它飞过去
变的"而不是"删一个加一个"；B 式的命门是级联时序——线牵出节点、层
喂出层，结构感来自先后而非同时。

## 两式选型
| 式 | 做法 | 适用 |
|----|------|------|
| A panel-to-canvas 行倒卡 | 光标逐个点复选框打勾→按钮按下→三行先拔起再沿上抛弧线错峰飞出，途中行形态与卡形态交叉淡化，落位带倾角与落地压扁；面板行槽塌陷成虚线留白 | 批量导入/一键上板：内容从列表态迁移为空间态 |
| B diagram-cascade 级联生成树 | prompt 逐字敲出（敲完描边确认、提交后描边流光=生成中）→prompt 底部滴线接根（渐变描边主角）→2 子→4 孙逐层从顶端口拉出，折角连线带彗星头先行 10f，相机从 prompt 特写拉远揭示全树，成树后整棵呼吸一拍 | AI 生成结构图/脑图/ER 图：一句话长出一棵树 |

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| A 打勾 | 14/24/34f 逐个（光标 swift 弧线逐个点中），spring(damping 11, stiffness 300) pop + 勾线 7f 描出 | 打勾是"预告"，全删观众不知道要飞谁；同帧齐勾读作静态已选 |
| A 起飞错峰 | 按钮 52f 按下，三行 56/62/68f 拔起（4f：放大 2% + 阴影加深）后起飞（错峰 6f） | 同帧齐飞读作复制粘贴；错峰 >12f 尾行像掉队；不拔起直接飞读作被删除 |
| A 飞行插值 | spring(damping 17, stiffness 95, mass 0.9)；位置走二次贝塞尔，中点上抬 220px；宽高晚 3f 收敛 | 直线飞读作平移不读作"倒出来"；中点抬 <100px 弧线感消失；尺寸与位置同步则少了"父先子后"的重量 |
| A 形态迁移 | 行 626×104 → 卡 486×300，圆角 18→24，rowOp 在 us 0.08→0.4 灭、cardOp 在 0.5→0.8 亮 | 两套内容交叉淡化必须错开——中段两态同显即穿帮 |
| A 落位倾角 | −2.5 / 1.8 / −1.2°，落地 6f scaleY 0.97 压扁回弹 | 全正读作网格排版；>4° 读作散落故障 |
| A 速度模糊 | SpeedBlur amount 0.32、max 14（按弧线速度方向） | 只在飞行段；落定后归零 |
| B 打字 | 每字 0.95–1.2f 不均匀、空格停 1.7f；敲完 prompt 条描边转紫确认，+4f 按下提交键 | 匀速打字读作机器；无确认态则"敲完"与"开始生成"之间没有因果扣 |
| B 相机 | 开场 1.3× 推近 prompt 居中；提交后 72f smooth 拉远到 1.0 | 不推近则前 2s 画面下半空着；拉远要与级联同时进行，树长在镜头"退"出来的空间里 |
| B 级联时序 | 根 = 提交 +14f，层间隔 22f、同层兄弟错峰 5f；节点 spring(damping 14, stiffness 190)，缩放原点 = 顶边中点（从端口拉出） | 层间隔 <12f 读作一次性全出；兄弟同帧读作复制；中心缩放读作弹窗 |
| B 连线先行 | SVG 圆弧折角 path（父底端口→中线→子顶端口）描线 16f ease-out，比子节点早 10f；线头一颗彗星光点 | "线牵出节点"是因果感来源；线晚于节点就成了补笔 |
| B 收尾呼吸 | 末节点 +22f 起，以树心为原点 scale 1→1.03→1（smooth，28f），背后极光同步亮一档 | 呼吸是"成树"的句号；>1.06 读作缩放故障 |

## 已知坑
- demo 在灰阶/占位素材上调校通过——参数是调校起点非实战定稿，
  首次实战须以真实素材回验
- 与 chart-live-moves 分工：那卡是数据图表自身的活性（流线/点阵/爆轴），
  B 式是结构图的**诞生过程**——图活着≠图正在被生成，别拿 B 式去演已有图表
- A 式行槽必须塌陷成虚线留白——行飞走后原位完好如初，"迁移"就退化成
  "复制"，语义全失
- A 式交叉淡化窗口（rowOp 灭于 u≈0.45 前、cardOp 亮于其后）是防穿帮的
  命门；spring 有过冲，u 可能短暂 >1，内容 opacity 都要 clamp
- B 式呼吸原点必须是树的视觉重心（demo 960,620）而非画面中心，
  不然读作整屏 zoom
- B 式彗星头靠路径弧长取点：折角用 SVG 圆弧（A 命令）而非二次贝塞尔，长度才能解析算准，
  线头与描线端点不脱节
