---
name: edit-hook-moves
一句话: logo-sting-button 片尾钩子——片尾 logo 定住后突插 12f 彩蛋再收，预告片 button ending
适用: 片尾收束（全片 ≤1 次）
时长: 150f（5s）
能量: 低→瞬时中→低
---

## 意图
库内声画卡管的都是"画面上的事"；这一式管**时间线本身的修辞**——
终点的反悔：收黑→logo 淡入定住（观众以为结束）→突然 12f UI 特写
彩蛋硬切插入→切回 logo 收尾，预告片 button ending，留最后一个钩子。
拿观众的"已经结束了"的预期开玩笑。

## 单式选型
| 式 | 做法 | 适用 |
|----|------|------|
| B logo-sting-button | 上一镜尾巴压暗 + 2.39:1 遮幅合拢→黑场 6f→logo 对焦入场 12f（blur 10→0 + scale 0.97→1，字标逐字字距收拢晚 3f）→定住 34f→彩蛋 12f 硬切（遮幅消失、整屏强调色）→切回 logo 定格 64f | 片尾；正片收束后再给一记 |

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 彩蛋时长 | 12f 级：f0–2 光标进场、f3–4 按下（0.965 压缩）、f5 起按钮翻黑 + 勾弹出（弹簧 damping 14） | 长于 20f 就不是"眨眼"是一个镜头 |
| 彩蛋构图 | 整屏强调色满画幅（demo 绯红 #e8202f）+ 按 1920×1080 目标尺寸直接布局的巨型胶囊按钮（字 104px 即最终像素），右侧被画框裁掉的失焦次按钮 + 前景光斑做浅景深，12f 内前推 4%（ease-out） | 彩蛋里露出旧构图残边读作切错了；色调与 logo 段反差越大，"眨眼"越清楚 |
| 遮幅 | logo 段全程 2.39:1 黑边（上下各 138px），彩蛋段无遮幅 | 遮幅在彩蛋里消失 = "打破第四面墙"，是手法识别度的一半 |
| 像素级一致 | logo 段 interpolate 全 clamp 到终值，彩蛋前后 logo 共用同一分支渲染；只有贯穿全段的极缓推镜（1.0→1.02）继续走 | 硬切回来 logo 跳 1px 都读作抖动；推镜 12f 只走 ~0.002，看不出 |
| 切回后的眼神 | 图形标上的晚星从暗环变成强调色点亮——彩蛋"按下"把它点亮 | 只许这一处变化；改动多了读作换了一张卡 |
| 剪辑方式 | 全程硬切分支渲染（frame 区间 return 不同子树），无交叉溶解 | 节奏靠剪不靠淡；任何溶解都泄劲 |

## 已知坑
- demo 在灰阶/占位素材上调校通过——参数是调校起点非实战定稿，
  首次实战须以真实素材回验
- 全片 ≤1 次且只在片尾——中段用 button ending 变成故障，
  观众以为片子坏了
- 彩蛋内容必须是全片未见的新特写——复用旧镜头读作剪辑失误
  不是钩子，命门
