## 意图
Linear changelog 视频语法：一整年的更新日志作为长卷高速掠过
（糊成色带），指数减速精准急刹停在本次发布那条上，该条抬升离面
高亮、其余退暗——密度感讲"一直在发货"，急停讲"今天这条最大"。
B 是组合变异：急刹帧**同帧**四个 L 角标从画外飞入咬合锁定停点
条目——急刹的"哐"与咬合的"咔"叠在同一帧共振（组合命门：
角标起跳帧=列表首停帧，错开退化成两招并置）。

## 两式选型
| 式 | 做法 | 适用 |
|----|------|------|
| A changelog-scroll-brake | 深蓝暗场瑞士网格：左栏固定读数区（字标 + 96px「Changelog」+ 随读线翻动的 120px 日期读数），右侧 1136px 长卷；先向下回拉 26px 预备（10f），再 translateY 扫 ~5000px（cubic-bezier(.45,0,.06,1)：~6f 拉满速再长尾指数式减速，共 54f），纵向方向性 blur 由速度差分驱动（×0.1 封顶 26px，停稳自动清零）；急刹帧目标行弹簧抬升（scale 1.04、damping 15 一次回弹）+ 2px 强调色描边 + 背后泛光 + 一次裁进圆角的扫光，其余行 opacity 退 0.38 + 1.6px 景深虚化，读数落成强调色「Today」 | changelog 段落基本款 |
| B brake-reticle-lock | 暖沙亮场奶白卡长卷：滚动三段 sin-in 加速（12–48f）→ cubic-out 猛减速冲过头 +34px（48–58f）→ 6f 回弹落定；纵向方向性 blur=v×0.13 封顶 32px；急刹帧四个 10px 粗赤陶 L 角从 ±620/±320 画外 back(2.4) 飞入咬合（超调越过咬合位只往里咬 12%，不压进卡片）+ 同帧 1.6% 冲击推；被锁卡 6f 内奶白翻墨色，右侧「Today」原地换成 back(2.6) 弹出的 NOW SHIPPING 页签 | 停点需要更强打击感的高光段 |

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 减速曲线 | A 回拉预备 26px + 快起步长尾减速（bezier .45,0,.06,1，54f）；B 加"冲过头 34px 回弹" | 匀速滚读作跑马灯；B 的过头回弹是"哐"的来源 |
| blur 驱动 | 帧间位移差分 `|p(f+½)-p(f-½)|`×系数（A 0.1 / B 0.13） | 手排模糊关键帧必然对不上速度；差分法帧确定（模式已沉为 assets/lib/helpers/motion.ts velocityAt） |
| 行高节奏 | A 96/118/140 三档错落 + 主角行 212；B 等高 132（间距 32） | 等高行高速掠过时色带无节奏（B 靠咬合打击，不靠色带） |
| 停位 | 目标行停画面纵向正中（A 有固定读线标记） | 停偏读作事故 |
| 选中表达 | A 抬升 + 描边 + 泛光；B 卡片反白（奶白→墨色） | 亮场里反白比描边更像"被锁定" |
| B 共振帧 | 角标挂载起跳帧 = 列表首次停住帧 = 冲击推帧（严格同帧，f58） | 组合命门，错 2f 以上就散 |

## 已知坑
- demo 用虚构品牌（Quarry / Wren）的手搓 changelog 调校——参数是调校起点非实战定稿，
  首次实战须以真实素材回验
- 与 timeline-travel 分工：本卡纵向列表急刹停"最新"，
  那卡横向时间轴旅行看"历史"——同片双用时先后错开且各 ≤1 次
- 高速段条目糊成色带，但急刹后邻行仍在画面里（退暗不退零），所以全卷都要写成真实感条目；
  停点条目必须出版级真内容（Q10）
- B 的 back(2.4) 超调幅度 ≈15%×620px，原样会让角标冲进卡片里 90px；超调段按 12% 收缩，只"咬"一小口
- 停点后其余行退暗 0.38 是构图动作：别退到 0（上下文消失）
- 声音：高速段低频 riser 铺垫，急刹一声 impact；B 咬合帧
  再叠一声"咔"（与 impact 同帧不同声部）
