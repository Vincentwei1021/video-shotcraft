## 意图
第一拍先给品牌记忆点：观众在任何产品画面出现之前，先看清并记住名字。安静、纸墨质感、有一个完整的静止时刻。

## 动效核心
- SVG 十字准星笔画描画（pathLength dashoffset），先竖后横再画环，对位后缩小淡出；demo 里准星绝对定位在字标中心，不占版面，lockup 真正居中
- demo 舞台是一张活版打样稿（sand 米色棉纸 · 墨 · 赤陶）：四角裁切线与左右小套准标和中心准星同在第 0 帧起描画，左下色标条 + 打样编号是 22px 级压暗"纹理"，只为让画面像一张设计过的海报
- 字标逐字 letterpress：280px 粗衬线，每字 scale 1.45→1 + blur 5.5px→0（ease-in 加速砸向纸面），离地投影随高度从远而虚收到贴实；落地 0.97 微压回弹 + 一圈墨晕；末尾强调色句点最后落、压得最重（0.94）
- 字下一条强调色细线逐字段拉开（每字落地时它下方那段从左展开，线头一点亮）——**唯一一道**跟着压印前沿走的光（Q4），描完即 lockup 的分隔线
- kicker 副标 mono 34px 宽字距打字机逐字符出现，强调色块光标周期闪烁
- lockup 完整静止满 1 秒（hold 段极缓推近 1.2%），然后整体上浮 + 缩小 + 失焦淡出，打样框留在纸上交棒 dashboard

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 准星描画 | 竖线 0→9f、横线 8→18f，24→34f 淡出（demo：竖 2→12、横 7→17、环 4→20，14→25 缩小淡出） | 描画完必须淡出，残留准星会和字标抢焦点 |
| 字标逐字 | 第 i 字 delay=10+i·3、12f（demo：18+i·3.6、10f，末字句点 ~53f 落定）；scale 1.6→1（demo 1.45，origin 下部）+ blur 6px→0（demo 5.5） | "opacity+位移/scale+blur→0"是全片入场三件套定式，缺 blur 会显得硬 |
| kicker 打字机 | 0.7f/字符（demo：0.75f/字符，54 起 ~74 完），光标 4f 周期闪、88f 停闪 | 0.7f/字符只适用于装饰性小字；正文交互打字要 3f/字符（对照 type-and-filter，用户嫌快返工过） |
| 品牌 hold | 46→76 帧整整 1 秒（demo：53→104，kicker 就位后仍有 ~30f） | 硬底线：用户两轮点名"出现后延长停留1秒"（R1）；短于 1s 必返工 |
| 退场 | 7f 上浮 40px + 缩 12% + 淡出（demo：104→114 上浮 52px + 缩 8% + 失焦，ease-in；114–120 留空打样纸） | 退场快于入场——观众已读完，拖长反而泄气 |

## 声音
品牌落定钉 transition-soft（模板片钉在 f12），brand→dashboard 运镜钉 whoosh-fast（f78）。SFX 逐拍钉帧、声明式表管理（S2）；音色走电影系词汇，不用游戏 UI tap（S1）。

## 已知坑
- hold 要给的是 wordmark 落定时刻，不是普通字卡/内容卡（R1）——曾把 hold 错加给普通内容卡后很快回滚；指代含糊的"停留"反馈先确认对象再动手（P3）
- 开场能量必须低起步：全片能量曲线低开→中段推进→outro 峰值，开场炫技会压死后面的爬升（对照 Q8 的能量曲线要求）
