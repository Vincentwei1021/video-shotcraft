## 意图
把"报数值"做成仪表的身体动作：A 是汽车点火自检——座舱三表（中央大表 +
左右小表内倾环抱）指针先"唰"地甩满全弧（270°）、在满量程挂一下，再回落
定格真实值，多表错峰成波浪，盘心读数全程跟随指针、落定才转亮，先亮量程
再报数，开场宣誓感；B 是飞机空速带语法——读数窗 + 指针钉死画面中线，
贯穿全画高的刻度带整体从窗后滚过，先顶着旧上限慢爬、升级后冲刺
（峰值 ~100px/f）、末尾 spring 刹车带回摆过冲，"世界动、针不动"，
数值大小变成看得见的位移距离。
与 odometer-digit-roll 分工：那是数字在窗里滚，B 是连刻度格线全在平移。

## 两式选型
| 式 | 做法 | 适用 |
|----|------|------|
| A needle-sweep-selftest | 外圈描边点火 → 指针去程 14f 快起急停甩满弧、满量程挂 3f → 弹簧回程 ~7° 过冲回摆落真值；三表错峰 4f；盘心读数跟随指针，落定转亮白弹出 | dashboard 开场/系统就绪仪式 |
| B tape-scroll-fixed-pointer | 全画高刻度带 translate：慢爬顶住旧上限线→上限线断开→预备回拉 5→冲刺 22f（峰值 ~100px/f，纵向运动模糊）→spring 刹车过冲回摆停位，新上限 bug 停进指针；窗内读数同步刷新 | 单指标大跳变（性能翻倍/配额提升） |

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| A 甩弧幅度 | 满量程 270°，挂 3f | 只甩到真值=没有自检仪式感；满弧挂一下再回落才是"先亮量程"；红区在满弧时闪亮 |
| A 过冲 | 回落带 ~7° 回摆（按行程反算弹簧阻尼） | 无过冲读作电子表；过冲=机械指针的质量 |
| A 错峰 | 4f/表（左→中→右） | 齐甩读作复制粘贴；错峰成波浪 |
| B 冲刺速度 | 5px/单位、峰值 ~100px/f（大跳变段） | 慢了读作匀速爬升，"世界动"不成立；带子越长越大，越要配纵向运动模糊 |
| B 刹车 | spring 过冲（冲过头再弹回停位） | 词汇原案的回摆是"哐"的来源，直停可惜 |
| 真静止 | 停位后 ≥30f 全锁死（A 末表落定 ~66f、B 110f 锁常数） | 指针类最忌尾漂 |
