---
name: radial-wave
一句话: 一张铺向地平线的透视点阵地面按到波源的欧氏距离错峰点亮，每点被波峰抬起、scale 过冲到 1.5 再落回常亮，第一道波扫完后第二道粉色脉冲从外圈反向收拢回中心、汇聚时放出光柱与回执环
适用: 产品/品牌开场的"系统上电"一拍；也用作数据网格、节点地图、覆盖范围类叙事的建立镜头
时长: 约 5.2s（156f@30fps）
能量: 中高（起手爆发一次，波前过后转为常亮低能量底子）
---

## 意图
把"很多点同时存在"这件静态事实，改写成"能量从一个源头扩散到全体"的动态事实。观众
看到的不是一张点阵图，而是一次通电：中心先亮，亮度像水波推过去，走完之后整张阵列
留在常亮态——为下一拍要放的内容铺好底。第二道反向波是回执，告诉观众这个系统会回应。

## 动效核心
（demo：aurora look，深紫夜 + 紫光 + 粉色点缀；收尾标题「Every node, online.」）
- 阵列是一张透视 LED 地面：世界网格 X∈[-40,40] × Z∈[0,30]，屏幕坐标 `x = 960 + X·S/(Z+Z0)`、
  `y = HY + C/(Z+Z0)`（S=420、Z0=6、地平线 HY=250），裁掉画外点后约 2,100 枚（与标题里的 2,048 节点同量级）；点径同样乘 `1/(Z+Z0)`（近大远小），
  最远 7 排按纵深渐隐进地平线雾。未通电的点是一枚暗"插座"（深紫 50% 透明度）交代阵列规模
- 波源是地面中央（Z=9）的能量核：f0–8 蓄能（预备），f8 放出第一道波
- 第一道波：单点起点 `8 + d·1.3`（f，d = 到波源的世界距离，格），单点行程 18f——波前是"起点错峰"而不是变速；
  经过时 `f1 = sin(w1·π)`：点被抬起 `0.9·f1` 格（近处 ~60px 的 crest）、scale `1 + 0.5·f1`（峰值 1.5）、
  颜色向近白提亮并挂一层 3.2R 光晕；之后留在常亮紫，常亮亮度按到波源距离衰减（源头附近更亮 = 视觉重心）
- 第二道波：f70 起从半径 34 格处向内收拢，单点起点 `70 + (34 - d)·0.9`、行程 14f，`f2 = sin(w2·π)` 做纯脉冲
  （抬起 0.45 格、scale +0.6、颜色插值到粉、3.4R 粉色光晕），走完不留状态；源头附近 8 格内地面画一圈透视椭圆光环
- 汇聚 f≈107：能量核爆亮、一道软边竖向光柱（径向渐变，底部最亮）+ 一圈外扩回执环（26f）；
  f106 起标题逐词由虚到实，等宽副标 `MESH · 2,048 / 2,048 NODES` 计数到满；f126–156 点阵极缓呼吸定格

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 透视 | S=420 / Z0=6 / HY=250 | Z0 越小透视越强、近处越大；HY 决定天空区留给标题的高度 |
| 波速 | 第一道 1.3 f/格、第二道 0.9 f/格 | 第二道更快 = 越收越急；第一道 >2 f/格时最外圈要等到全片过半才亮 |
| 单点行程 | 18f / 14f | 决定波前的厚度；<10f 波前锐利像扫描线，>30f 全场几乎同时亮，扩散感消失 |
| 过冲幅度 | `1+0.5·f1` → 峰值 1.5，抬起 0.9 格 | 系数 0.5 是"弹一下"的量；抬起 >1.5 格近排点会跳出地面读作喷泉 |
| 第二道波 | f70 起，R=34 格，幅度 0.6 | 起点要晚于第一道波掠过可视区（~f60）；提前会和第一道波尾巴叠在一起读作一团乱闪 |
| 常亮底 | `op = (0.5 + 0.5·e1·focus + 0.2·f2)·fog` | 未点亮点的存在感交代规模；调到 0 则波前之外一片黑 |
| 发光 | 光晕 3.2R / 3.4R，只给波前正在经过的点 | 光晕半径 >4R 时相邻点的光晕连成一片雾，波前形状就看不出来了 |

## 已知坑
- 透视地面上的圆形波前在近处会被拉宽成"梨形"——这是正确的透视，不要为了"看起来圆"去改距离公式
- 波前光环只在源头附近画（≤ 8 格）：大半径的地面椭圆近半边在镜头后方，只剩一条横跨全画面的拱线，很难看
- 第二道波时间表压在 ~f107 汇聚，是为了留出标题揭示 + ≥ 30f 静止（工作台定格尾帧）
- 光柱用径向渐变的软边矩形，硬边矩形读作廉价的"光剑"
- 点数 ~2,100，每帧只给波前经过的点加光晕，渲染 ~20s；把 ROWS/COLS 加大前先看渲染时间
- 暗场背景是发光的前提，白底上这套亮度脉冲基本看不见
