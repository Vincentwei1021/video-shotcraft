---
name: radial-wave
一句话: 17×9 圆点阵列按到波源的欧氏距离错峰点亮，每点 scale 过冲到 1.5 再落回常亮，第一道波扫完后第二道亮蓝脉冲从外圈反向收拢回中心
适用: 产品/品牌开场的"系统上电"一拍；也用作数据网格、节点地图、覆盖范围类叙事的建立镜头
时长: 约 3.8s（114f@30fps）
能量: 中高（起手爆发一次，波前过后转为常亮低能量底子）
---

## 意图
把"很多点同时存在"这件静态事实，改写成"能量从一个源头扩散到全体"的动态事实。观众
看到的不是一张点阵图，而是一次通电：中心先亮，亮度像水波推过去，走完之后整张阵列
留在常亮态——为下一拍要放的内容铺好底。第二道反向波是回执，告诉观众这个系统会回应。

## 动效核心
- 阵列 17×9 共 153 点，按 1920×1080 原生坐标、正方格距 100px 居中排布（行列等距 → 波前是正圆），
  未通电的点先是一枚暗"插座"（r=4，16% 透明度）交代阵列规模；每点预存归一化距离 `dist = hypot(c-cx, r-cy) / maxD`（maxD = hypot(8,4)）
- 第一道波：`seg(t, dist*0.35, dist*0.35+0.18, E.outCubic)`——起点由距离线性推迟（最外
  圈延后 0.35），单点自己的行程恒定 0.18；波前是"起点错峰"而不是变速
- 每点的 scale 不是简单 0→1，而是 `w1*(1+0.5*sin(w1*π))`：中途鼓到约 1.5 再收回 1，
  正弦包络让过冲发生在行程正中而非落位时
- 第一道波前自带亮边：颜色按 `sin(w1*π)` 向 `#b4c4ff` 提亮并挂一层淡蓝径向辉光，行程走完归零
- 第二道波：`seg(t, 0.57+(1-dist)*0.18, +0.12)` 把偏移量反号（外圈先动），取
  `sin(w2*π)` 做纯脉冲，叠加 0.8 的 scale 增量与 0.25 的透明度增量，走完不留状态；
  中心在 t≈0.87 走完，脉冲汇到中心的峰值时放出一圈外扩淡出的细环（回执），之后 ~15f 静止落定
- 脉冲颜色按 `pulse2` 连续插值到 `#c4f2ff`，青色光晕（2.3R 径向渐变）透明度同样跟 `pulse2`
  走——第二道波是青色发光，第一道波只是蓝色提亮，两道波在视觉上不会混成一件事

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 阵列规模 | COLS=17 / ROWS=9（153 点） | 点数决定波前的"分辨率"；<8 列时距离分档太粗，波读作三四圈同心环在跳 |
| 波速系数 | `dist*0.35` | 这个 0.35 就是波速倒数：调大波走得慢、拖尾长；>0.5 时最外圈要等到全片过半才亮 |
| 单点行程 | 0.18（≈21f） | 决定波前的厚度；<0.1 波前锐利像扫描线，>0.3 全场几乎同时亮，扩散感消失 |
| 过冲幅度 | `1+0.5*sin(w1*π)` → 峰值 1.5 | 系数 0.5 是"弹一下"的量；去掉正弦项就是平淡的 0→1 淡入，>0.8 点会互相咬边 |
| 第二道波 | 起点 `0.57+(1-dist)*0.18`，窗 0.12，幅度 0.8 | 外圈 0.57 起步时第一道波（0.53 收尾）刚走完；提前到 0.5 以下会和第一道波尾巴叠在一起读作一团乱闪 |
| 常亮底 | `opacity = 0.25 + w1*0.5 + pulse2*0.25` | 0.25 是未点亮点的存在感；调到 0 则波前之外一片黑，阵列的"规模"交代不出来 |
| 发光 | 颜色/光晕随 `pulse2` 连续插值 | 光晕半径 >3R 时相邻点的光晕连成一片青雾，波前形状就看不出来了 |

## 已知坑
- 波源写死在几何中心（`cx=(COLS-1)/2, cy=(ROWS-1)/2`）。要改成从角落或某个"节点"起波，
  必须同时改 cx/cy 与 maxD，否则归一化距离 >1，最外圈的起点会被推到 t=1 之外永不点亮
- 第二道波时间表压在 t≈0.87 前走完，是为了末帧干净静止（工作台定格尾帧）；再往后挪，
  中心点会在末帧仍处于高亮
- 点用 SVG `circle` 以圆心定位，改点径只改 `R`；但 `R*1.8`（过冲+脉冲峰值）要小于格距的一半，
  否则峰值时相邻点咬边
- 颜色三档（常色 `#6c84ff` / 波前 `#b4c4ff` / 峰值 `#c4f2ff`）加光晕渐变色，换品牌色一起改；
  暗场背景是发光的前提，白底上这套亮度脉冲基本看不见
