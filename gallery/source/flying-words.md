name: flying-words
一句话: 22 个关键词按黄金角铺在扁椭圆截面上，沿 z 轴从 -1750px 飞到相机前 800px 擦身而过，透明度走 [0,1,0.5,0.2,0] 生命曲线，跑满 2 整圈首尾无缝
适用: 关键词云/能力清单的动态背景；片头片尾的"信息量"垫底层；需要纵深穿越感的转场
时长: 约 6.0s（180f@30fps，2 个完整循环，可无缝接续）
能量: 高（全屏持续 3D 位移，画面无一刻静止）

## 意图
关键词列举最土的做法是堆一屏静态词云。词语隧道把同一批词**摊到时间轴上**：
远处生成、由小变大、擦过镜头消失，观众永远只在读三五个词，但主观感受是
"词很多"。它是背景层不是主角层——相机不动、元素动，所以前景压一层标题
或 UI 完全不打架。词表整体替换成项目关键词即可，不改一行运动逻辑。

## 动效核心
- 场景 `perspective:1100px` + `preserve-3d`，词沿 z 从 **-1750 → 800px**
  线性推进（`lerp(u, -1750, 800)`）——正值即穿过相机平面，这才有"擦身"
- 铺位用黄金角：`a = i·2.39996 + rand(i·7+1)·0.8`，半径 `r = 82 + rand·165`，
  y 半径再 ×0.6 压成扁椭圆——避开正中、避免近处几个词堆成一团
- 生命曲线 `OP=[0,1,0.5,0.2,0]` @ `OT=[0,0.25,0.6,0.85,1]`：**前 1/4 猛亮到满，
  中段降到半透，末段拖尾消失**——不是简单淡入淡出，中段压暗才不遮前景
- 向外散开 `drift = 0.5 + u·1.35`：远处收拢在中心、越近越往画外甩，
  和 z 轴推进叠成真透视感
- 近端糊化：`u > 0.86` 时 `blur((u-0.86)·26)`——词冲到眼前会大到失控，
  这一层模糊既是运动模糊也是遮丑
- `CYCLES = 2` 是整数圈，t=0 与 t=1 画面完全一致可无缝 loop；每词相位
  `ph = i/N` 均分、spawn 全确定性；中心 220px 蓝紫光晕
  `opacity = 0.75 + sin(t·4π)·0.12` 呼吸 2 次，钉住"隧道尽头"这个视觉锚

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 词表 | 22 词，字号 `20 + rand·16`px（20–36），800 字重 | 词数与相位 `i/N` 绑定：<12 词画面稀，>30 词近处糊成一片；字号随机是层次感来源，全同号读作贴图 |
| 纵深行程 | z −1750 → +800px，perspective 1100 | 起点更远（−2500+）词太小认不出；终点不过 0 就没有"穿过去"只有"飞到脸前停住" |
| 散开系数 | `drift = 0.5 + u·1.35` | 系数 <1 词全从正中喷出像爆炸；>2 早早飞出画外，隧道变喷泉 |
| 生命曲线 | `[0,1,0.5,0.2,0]` @ `[0,0.25,0.6,0.85,1]` | 中段那个 0.5 是给前景让位的；改成一路满亮就抢主角，改成早早归零隧道变空 |
| 循环圈数 | `CYCLES = 2`（必须整数） | 非整数 → t=1 与 t=0 不接，loop 处一跳；圈数越多单词过镜越快 |
| 近端模糊 | `u>0.86` 起 `(u-0.86)·26`px | 阈值提到 0.95 巨大词硬边扎眼；系数 >40 末段成色斑 |
| 配色 | `hsl(200+rand·130, …)` 蓝→紫，光晕 `rgba(120,150,255,.22)` | 深底浅字发光是身份证，白底套本卡直接失效——要浅底得整套重配 |
| 中心光晕 | 220px、blur 6、呼吸 2 次/片 | 删了隧道尽头没有焦点，词像随机乱飞；呼吸频率跟 CYCLES 对齐才不打拍 |

## 已知坑
- demo 在灰阶/占位素材上调校通过——参数是调校起点非实战定稿，
  首次实战须以真实素材回验
- 词表替换要**保持词数与字长量级**（demo 22 词、单词 4–9 字母）：相位是
  `i/N` 均分的，词数一变密度整体缩放；中文词字宽是英文的两倍以上，
  换中文关键词须同步下调字号否则近处直接占满画面
- `CYCLES` 必须是整数，否则首尾不接——这是本卡"可无缝 loop"的唯一前提，
  想调过镜速度就整数加减，别改小数
- 只做背景层：中段生命曲线压到 0.5 就是为了给前景让位，把它当主角
  （拉满亮度）反而读作杂乱
- 深底专用：`text-shadow` 发光 + 径向暗角是效果的一半，浅底上词会糊成
  脏点；22 个词元素全程挂在 DOM 里（不销毁重建）只改 transform/opacity，
  移植 Remotion 时保持这个结构，别改成按帧增删节点
