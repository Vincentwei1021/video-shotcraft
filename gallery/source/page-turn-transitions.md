name: page-turn-transitions
一句话: 整页体块转场两式——cube-rotate 立方体翻转（两页贴盒子相邻面转 90°）与 barn-door-split 对开门裂幕（旧页裂两半滑出、新页迎上）
适用: 章节级换页：两个并列大段落之间的"翻篇"仪式；与 shot-transitions 系（镜头交棒）分工——那是"航拍机移过去"，这是"页面自己是实体"
时长: 单式 150f（前态建立 30–40f + 转场 24–40f + 跟随与收尾 ≥70f），约 5.0s
能量: 中高
---

## 意图
shot-transitions 六式和 transition-travel/hidden-cut 都把页面当"场景"
——相机在场景间移动。本卡把页面当**实体**：它有厚度、有重量、会翻面
会裂开。体块隐喻的仪式感更强，适合章节级大换页（功能 A 讲完→功能 B）
而非镜头级小交棒。A 立方体是"空间上并列"——两页是盒子的两面，
暗示同级关系；B 对开门是"旧的让位"——旧页从正中撕开滑走、新页
从底下迎上来，暗示取代关系。按语义选：并列翻篇用 A，新旧交替用 B。

## 两式选型
| 式 | 做法 | 适用 |
|----|------|------|
| A cube-rotate | 两页贴立方体相邻面（rotateY 0/90° + translateZ W/2），场景层转 -90°；旧面转出压暗、新面转进变亮，45° 时共享凸棱亮起一条受光细棱；demo 用一明一暗两面（瓷白「01 Plan」/ 深海军蓝「02 Ship」）+ 底部章节指示器同曲线滑动 | 并列章节翻篇；产品两大功能区切换 |
| B barn-door-split | 旧页两个 960px overflow 容器对位拼合，同时向外 ease-in 加速滑出画外（按速度挂横向运动模糊）；裂缝里透出新页的光——门内缘 10px 切面被照亮、门面近缝处被光染暖，新页带一次过曝光束 scale 1.08→1 迎上；demo 为同版式的「Kiln 3」冷灰旧页 → 「Kiln 4」余烬发布页，数据从旧值滚到新值 | 新旧交替：改版前后、方案 A→方案 B、版本发布 |

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| A 结构命门 | 场景层 `translateZ(−W/2) rotateY(θ)` 把正面拉回 z=0 | 少了这层 hold 段页面尺度不对（被 perspective 推远） |
| A 转速 | θ 0→−90° / 40f，bezier(0.6,−0.2,0.2,1.2)：先回拉 ~1.6° 再转、到位过冲 ~1.6° 回落；中段按棱上线速度挂横向运动模糊（≤2.4px）+ 相机后退 14%，落定摘 | <28f 读不出体块感；>50f 读作慢慢挪；相机退得不够凸角会顶出画框 |
| A 亮度对切 | 旧面 1→0.5、新面 0.5→1（按法线夹角 cos 压暗，远离镜头一侧再深一档）+ 共享棱 3px 受光高光 sin(pπ)；两面本身一明一暗时体块感最强 | 无明暗对切两面读作同一张图在转 |
| A 空间 | 地面接触影 + 同一 3D 场景镜像一份做倒影（opacity 0.11，贴地 120px 渐隐） | 倒影太实会和底部文字打架；没有地面盒子像飘在空中 |
| B 预告 | 裂前中缝一条发丝亮线（带泛光）自中点向上下描出（20–30f），30–40f 裂缝 ease-in 撑开 0→16px 成一道光缝 | 直接裂开观众没看到裂点在哪；硬开关闪线读作渲染故障 |
| B 滑出 | 各 translateX ∓1000px / 24f，bezier(0.42,0,0.8,0.25) 加速 | ease-out 滑出是"被推走"，ease-in 才是"让位"；quart-in 太猛会读作"停住→最后一帧消失" |
| B 新页迎上 | scale 1.08→1（snappy 36f，晚门 2f 起跳），过曝光束随门远去 ~30f 衰减；新旧两页同版式同槽位 | 新旧页版式不同就读不出"取代" |
| B 撕裂边 | 内边缘 10px 受光切面（亮→强调色→暗）+ 门面近缝 620px 光染（screen），门不向新页投影 | 无边线两半读作普通左右擦除；门往缝里投影会把光压灰 |
| 收尾 | 新页落定后跟随动作（数据滚动 / 清单打勾）+ hold ≥30f，hold 段相机极缓推近 1.5–2% | R1 |

## 已知坑
- demo 在为镜头手搓的页面上调校（A 式页面 1920 原生排版按 S=0.76 走 CSS zoom 贴面，3D 里文字不糊）——参数是调校起点非实战定稿，
  首次实战须以真实素材回验
- 一缝一式规矩同 shot-transitions；体块转场比镜头交棒更重，
  **全片 ≤2 次**，连续两缝都用体块读作 PPT 翻页
- A 式官方 `@remotion/transitions` cube() 是付费件——本卡是 CSS 自实现，
  backlog 已有"评估官方转场原语"待选项，若引入官方件可对照
- B 式两半必须**对位拼合无缝**（右半内层 translateX(−960px)）——
  静止时看出接缝就穿帮；真实截图注意奇数宽度取整
- 转场前后两页都要有 ≥30f 静止建立/收尾——两端都在动，体块感被
  运动淹没
