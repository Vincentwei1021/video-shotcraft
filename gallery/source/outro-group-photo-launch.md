name: outro-group-photo-launch
一句话: 全片元素从四面八方飞来围住字标合影，crane 落机位+舞台光束+光尘做成发布会收场
适用: outro/品牌收尾；多功能产品的"全家福"式终镜
时长: 约 5s（150f）
能量: 峰值（全片最高点）
---

## 意图
把看过的每个功能各抽一个代表元素叫回来合影，字标压轴登场——观众离场前最后记住的是"这些东西属于同一个产品"。规格必须是发布会级：能量推到全片最高。

## 动效核心
- 舞台关灯：深蓝暗场（midnight）+ 顶部三道缓摆的体积光束 + 地平线光带 + 背后一面羽化压暗的"LED 墙"（真实项目页截图远景）——白色产品卡在暗舞台上一块块发光，合影一眼可读（奶白纸面上铺奶白卡会糊成一片）
- 9 个页面元素（nav/项目卡/论文条/搜索框/字段卡/周报条，纹理保持原截图 Q1）沿"画面中心→落点"方向向外延长 760–980px 处飞入（四面八方），cue 4→25 越来越密，各飞 14f；飞行中旋转 ×3.2→settled、scale 1.16→1，按屏幕速度做方向性运动模糊，过冲落定 + 落地压实（接触影收紧 + 1.8% 轻压，不逐个发光，Q4）
- 三层景深：后排（导航条/论文条）blur 1.8 + 压暗到 0.62；中排；前排三张项目卡最大最实、接触影最浓——合影有前后
- 字标压轴：眉题 INTRODUCING 逐字由虚到实 → 150px 字标逐字从线下升起 → 电光蓝 rule 长出 + 两端延长线射出 → 副标逐词升起；全员"退后排"（压暗 22% + 微虚）
- crane 运镜：合影层 perspective rotateX 9°→0 + 下落 46px + scale 1.1→1，前 44f 落下，之后零速起步缓推 3%
- 发布会氛围三件套：顶部光束、字标背后舞台光（只亮一次后回落成余光）、冷白光尘上飘

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 元素飞入 | 9 元素 cue [4,7,9,12,15,17,19,22,25]，各飞 14f；起点 = 落点沿离心方向外推 760（中后排）/ 980px（前排）；渲染顺序 = 后排→前排 | 每个已展示过的功能都要有代表元素（Q8 自检项），缺谁观众都会察觉 |
| 飞入缓动 | bezier(0.3,1.32,0.42,1) | 落地要弹 y1 必须 >1；旧 bezier(0.25,0.9,0.3,1) "never crossed 1" 没有真过冲 |
| 飞行姿态 | 旋转 rot×3.2→rot（±6° 内）、scale ×1.16→1；方向性运动模糊 0.32×px/帧，封顶 24；落地前 4f 压实 | 落定角度收进 ±6° 内——合影要整齐但不刻板 |
| 景深分层 | 后排 blur 1.8 / 亮度 0.62；中排亮度 0.86；前排 1.0 | 不分层的合影像一张平铺拼贴 |
| 退后排 | 字标登场 40–60f 全员亮度 −22%、blur +0.6–1.2px | 主角登场配角必须让位，白卡不压暗字标压不住 |
| crane 运镜 | `perspective(1600px) translateY(−46→0) rotateX(9°→0) scale(1.1→1)` 前 44f（swift），之后缓推 +3%（40f 起 smooth 零速起步） | 推幅过大边缘卡片被裁出画；>12° 会晕（推测） |
| 氛围三件套 | 光束 3 道（±14° 斜射、±3.2° 缓摆、外层 blur 内层梯形裁切）；舞台光 42→52f 亮起、54–80f 回落到 55%；光尘 34 颗确定性上飘 | 粒子/光效参数必须确定性派生；光束模糊与裁切写在同一层会留硬边 |
| 字标 | 眉题 44f 起逐字 blur 揭示；字标 46f 起逐字 rise（间隔 1.1f、各 16f）；rule 60→72f；延长线 62→70f 射出、70–78f 淡去；副标 68f 起逐词；落定后 hold ≥ 2s | 字标落定 hold 满 1 秒（R1 定案）；投影要走父级 drop-shadow，逐字遮罩会把 text-shadow 裁成方块 |

## 声音
固定三拍句式：riser-cine 铺进组装（模板片钉在 f945）→ impact-deep-whoosh 钉字标 stamp（f980，vol 0.55 全片峰值）→ sparkle 点 rule（f1005）。这是模板片定稿后唯一从未改动的段落句式（S2；详见 sound-design 4.3）。

## 已知坑
- 初版收尾几乎总是偏保守（Q8：安静签名式→合影→发布会三级加码）——起稿就按"像一个产品发布"的规格给足 crane/舞台光/粒子
- 亮色截图卡放在亮色底上会糊成一片：合影要么暗场托白卡，要么亮场给卡片足够的投影与景深分层
- 结构先于特效：先有"四方飞入合影"结构再加码氛围；直接堆特效没有骨架
- outro tagline 与字标下方文案查重（P4 dedupe 判例），同一句话全片只出现一次
