name: print-texture-transitions
一句话: 印刷质感转场——ink-bleed-reveal 墨渗揭示（须状渗边洇开吃掉旧景）
适用: 换景接缝的纸墨审美款；与交棒六式/穿越三式并列的第三族——"介质显影"型转场
时长: 约 5s（152f：墨滴 8–18f + 洇开 24–104f + 跟随与 hold 46f）
能量: 中（渐进显形，无冲击拍）
---

## 意图
转场语言已有交棒（shot-transitions 六式）和穿越（transition-travel）
，都是空间/光学隐喻。本式开第三族：**介质隐喻**——新画面不是"到来"
而是"印染"出来的，直接调用库内纸墨审美的物理想象：像一滴墨落在
宣纸上洇开吃掉旧景，有机、书写感。天然亲和 paper/ink 调性的片子，
是 light-leak-burn（强调色漏光）之外的另一个"介质系"接缝选择。

| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 墨滴 | 8–18f 自由落体（位移 ∝ t²），按速度纵向拉长 ≤3.2×，头圆尾尖 | 匀速落读作滑下来；不落直接洇开观众不知道墨从哪来 |
| 触纸 | 主墨团 0→64px（overshoot 8f）+ 7 粒卫星墨点（距 96–246px，snappy 6f 外飞，各自再洇开 1.6×）| 没有卫星读作普通圆形 iris；卫星太远太大像泼墨 |
| 渗边 | 每层遮罩的墨形（主墨团 + 卫星）挂 `feTurbulence(fractalNoise, seed 11 固定)` + `feDisplacementMap scale 36→110 随帧涨` | filter 只揉遮罩形状、内容始终清晰；seed 必须写死（确定性） |
| 洇开 | 半径 [24,104f]→[64,1564px]，曲线 = 线性与 ease-out(quad) 各半，乘 `1+0.07·sin(0.31f)·env`（env 84–104f 衰减归零） | 纯 ease-out 前 1/4 就吃掉大半屏；匀速圆扩张读作普通 iris——扰动即"墨的脾气" |
| 墨的四层 | 湿晕（领先 +70px、22px 羽化、暖暗 0.08）/ 淡墨须边（+24px、高频噪声 0.05·4 octave、靛灰 0.34）/ 浓墨边（领先新景 8–18px、比墨底更深 0.96）/ 新景 | 无墨边读作 iris 擦除；湿晕太重读作烧纸洞；淡墨须边是"水带着颜料先跑"的关键 |
| 新景 = 墨底 | 新页底色就是墨（#10121f 带靛），纸色衬线字 + 朱红斜体印在墨上 | 新页若是亮色 UI，墨边就成了"黑框"；墨底让墨和新页是同一种物质 |
| 显影 | 新景在遮罩内 scale 1.03→1（24–104f ease-out），摘罩前精确回到 1 | 不收会在摘罩帧跳一下 |

## 已知坑
- demo 在手搓的刊物扉页（纸 → 墨两章）上调校——参数是调校起点非实战定稿，
  首次实战须以真实素材回验
- 一缝一式规矩同 shot-transitions：介质转场不与白闪/震屏叠加；
  本式与 light-leak-burn 介质系同片合计 ≤2 次，多了片子读作印刷厂宣传
- 洇开中段旧景内容会透过噪声孔洞碎片式短暂露出——读作墨渍肌理
  属可接受有机效果，但旧景若是人脸/logo 等高辨识元素会读作故障，避开
- 慢转场（墨滴 + 洇开约 95f 动作段），高节奏连打段落别用——那里去 E 式甩镜
- 落墨点放在新页主标题的对侧，让标题最后被墨染到；落在标题上会先露出半个字，读作故障
