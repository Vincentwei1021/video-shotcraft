一句话: 文档不淡出而是向左滑出只露约 40% 宽并微缩到 0.92，右侧按旁白节奏慢速发牌三张结论药丸（从文档里的依据句飞出、过冲落位），每张落定后其下方说明逐词加深、下一张到来前整句淡出，左侧文档全程极缓慢自动滚动保持"正在被读"
适用: 旁白驱动的"分析结论逐条给出"段落；文档理解、推荐理由、审阅意见类产品的核心说明镜头
时长: 180f（6s@30fps）
能量: 低（慢发牌节奏，全片无峰值；靠自动滚动维持活性）
---

## 意图
结论要一条一条给，观众才记得住。但如果把来源文档淡出，结论就变成了空中楼阁——观众
不知道这些话从哪来。这张卡的解法是**让来源留在画面里**：文档靠左驻留只露一截，还在
缓慢滚动（说明它正在被读），右侧的每条结论都是从这份文档里长出来的。发牌节奏刻意慢，
是为了给旁白留出说完一句的时间。

## 动效核心
- 开场（0–30f）：文档居中，一道强调色扫描光带自上而下扫过整页（裁在纸面圆角内），眉题"ANALYZING · 12 SOURCES"——先交代"在读"
- 驻留（park）不是淡出：18→46f smooth in-out 驱动 `translateX(0→−1010px) scale(1→0.92)`，`transform-origin: 0% 50%`
  让缩放以左边缘为锚，最终右缘落在 x≈370、只露约 40% 宽（露出的是句尾——依据句的荧光笔和连线起点都在可见区）
- 常驻自动滚动：`translateY(−frame × 1.4px)` 连续匀速，内容比窗口长出整段行程；纸面上下 7–10% 渐隐，滚动内容柔和进出。
  旧写法取模（`-(t*3 % 1) * 40`）在非周期内容上每 1/3 片长整页回跳，已弃用
- 慢发牌：三张起点 `T0 = [46, 84, 122]`——间隔 38f（约 1.27s），这是一句短旁白的长度，不是 UI 常规的 stagger
- 每张的因果链：依据句荧光笔 T0−6→T0+6 自左向右划出（先找到依据）→ 药丸 T0→T0+14 从依据句所在位置飞向右栏槽位
  （位移/缩放 overshoot 14f，透明度 out 6f 先到——先看见、再落定；飞行中按速度加模糊）→ 连线 T0+8→T0+20 从句尾 draw-on 到药丸左缘
  → 匹配度 chip 落定后弹出
- 说明句：T0+12 起逐词加深（灰→墨 + 每词 8px 上浮，摊在 22f 上），下一张 T0−8 前整句上移淡出，画面永远只有一句；
  末张不淡出，尾帧 = 三条结论 + 一句理由
- 药丸终态是静态列表（y = 196 / 436 / 676，高 128），三张全部落位后一直留在画面上，读作"结论清单已成形"

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 发牌起点 | `T0 = [46, 84, 122]`，间隔 38f | 间隔就是旁白句长；压到 20f 以下说明句的"逐词加深"来不及走完，读作字幕闪一下就没了 |
| 驻留窗 | 18→46f（smooth in-out 28f） | 必须在首张药丸（46f）之前收住；重叠会出现"文档还在滑、药丸已在发"的浑浊 |
| 驻留幅度 | `translateX −1010px` + `scale 0.92`，露约 40% | 露太少（<25%）文档变成装饰失去"来源"语义；露太多右栏放不下 1000px 宽的药丸 |
| 药丸透明度窗 | 6f（out） | 比位移窗短是有意的——先实后稳；两窗等长会读作普通淡入 |
| 药丸位移窗 | 14f（overshoot），起点 = 依据句屏幕位置左偏 200px、scale 0.72 | 过冲是"发牌落桌"的手感；从依据句起飞是"结论从文档里长出来"的因果 |
| 说明延迟 | T0+12（药丸落定附近） | 提前会出现说明先于结论出现 |
| 说明加深行程 | 22f，逐词窗 = 0.75/n × 1.6 | 末段是全实态的静置阅读时间；太长则刚读完就被淡出 |
| 自动滚动 | 1.4px/f 连续匀速 | "正在读"的暗示级速度；>3px/f 会抢注意力变成滚动展示 |
| 字号 | 文档标题 52 / 正文 30；药丸名称 54；说明 44；眉题 mono 24 | 原生 1920 排版，要读的字都过 Q11（≥32）；文档正文只露句尾，是"来源纹理" |

## 已知坑
- 自动滚动是连续位移而非取模循环；改时长或速度时要保证文档内容比窗口长出整段行程，否则末段会滚出空白
- 依据句必须在驻留后的可见区（句尾要够长、落在文档右侧 40% 里），且发牌时刻没被滚出窗口——改滚动速度要回查三处依据句的屏幕 y
- 药丸位置写死为 `left:600, top: 196/436/676`、宽 1000，与驻留后文档右缘 x≈370 配套；改驻留幅度必须同步改 PX，否则连线过短或两者重叠
- 药丸数写死为 3（`T0` 的长度）。加到 4 条时间与纵向空间都不够；4 条以上应考虑缩短单句而不是硬塞
- 说明句的淡出依赖 `T0[k+1]`，改任一张的起点都会连带改变前一张说明的可见时长——这是有意的联动
- 文案（Northwind Studio / 三条结论 / 百分比）全是虚构占位；换真实文案后按新句长重调加深行程
