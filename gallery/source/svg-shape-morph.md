---
name: svg-shape-morph
一句话: 一条 140 点闭合轮廓平滑变形为另一条再变回，两形状先在极坐标下重采样到相同点数、逐点半径插值（预备收缩 + 过冲回落），内部 5 圈等高线逐圈滞后跟随，变形中段叠 scale 呼吸、缓慢自转与色相从 258° 漂到 322°
适用: 抽象概念的"形态转换/自适应/有机生长"表达；开场 logo 前的氛围一拍，或章节之间的过渡形
时长: 约 5.6s（168f@30fps）
能量: 低（无爆点的连续流动，适合当旁白底或呼吸拍）
---

## 意图
"形态会变"这件事，用两张图交叉淡入是说不清的——观众看到的是两个东西重叠。真正的
morph 要让观众相信这一直是**同一个东西**在改变形状。等点数重采样加逐点插值就是这个
"同一性"的技术保证：没有点的生成或消失，只有半径在变。变回原形是为了闭环——观众
看到往返，才知道这是可逆的能力而不是一次性的变身。

## 动效核心
- 美术：aurora 极光暗场；主体居右（中心 1040,520，基半径 300），左下一组字标（mono 眉题「03 LOBES · 140 PTS · ONE CONTOUR」
  数字随形态翻牌 03 ⇄ 05，64px 标题「Same 140 points. / A new form.」逐词升起）
- 两形状用极坐标函数定义：`rA(θ) = 300*(1 + 0.30*cos(3θ) + 0.05*sin(7θ+0.8))`、
  `rB(θ) = 300*(1 + 0.26*sin(5θ+1.2) + 0.06*cos(2θ))`——三瓣与五瓣，各带一层高频扰动
- 重采样：两形状都在 `i/140 * 2π` 上取样存进 `RAD_A/RAD_B`，天生等点数且一一对应
- 插值只发生在半径上：`r = mix(RAD_A[i], RAD_B[i], m)`，角度恒定 → 中间态是不自交的闭合曲线
- 往返：`m = MORPH((f−18)/40) − MORPH((f−90)/40)`，MORPH = bezier(.55,−.22,.3,1.18)：先反向收缩、再冲过 ~3% 回落——
  形变有重量；58–90f 是 B 的静置段（32f），两端 A 静置
- 等高线：外圈之内再画 5 圈轮廓（缩放 1−0.15j），第 j 圈用 `f − 3j` 的形态系数（逐圈滞后 3f）并在形变中途扭转 `busy·j·2.2°`，
  裁在外圈内；最内圈填柔光——"里面的流体慢半拍"
- 同一性可视化：外圈每 4 个采样点挂一颗白点（35 颗），只沿径向滑动
- 呼吸与自转：`breath = 1 + 0.035·busy + 0.008·sin(f/16)`（busy = 两次形变的钟形进行度），`rot = sin(f/168·2π)·4°`，末帧回零
- 色相跟形态绑定：`hue = mix(258, 322, clamp(m))`，驱动填充、渐变描边、辉光与环境光
- 140 个采样点用闭合 Catmull-Rom 转三次贝塞尔，1920×1080 原生坐标作画

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 采样点数 | N=140 | <60 点能看到多边形棱角，>300 点是纯浪费 |
| 基半径 | BASE=300，中心 (1040,520) | 凸起 0.30 时外沿最高 ~400px，留边给辉光与左下字标 |
| 形状 A / B | 三瓣 / 五瓣 | 瓣数不同才有变形张力；瓣数相同只会看到形状"转了转" |
| 变形曲线 | 40f，bezier(.55,−.22,.3,1.18) | 预备 + 过冲让形变像液体；换 inOutCubic 变回"矢量插值"的机械感 |
| 中段静置 | 58–90f（32f） | 让观众认清 B 形态；砍掉会读作一次来回摆动而不是 A→B→A |
| 等高线滞后 | 每圈 3f、扭转 2.2°/圈 | 滞后 >5f 内圈和外圈形态差太大读作两个东西；0 滞后就是静态同心缩放 |
| 呼吸幅度 | 3.5% × busy | >8% 会读作缩放动画而不是形变 |
| 色相区间 | 258°→322°（冷紫→品红） | 跨度 <40° 时颜色变化读不出 |

## 已知坑
- 极坐标定义天生只能表达"从中心看每个角度一个半径"的形状——星形、花瓣、水滴都行，
  但**任何凹到自遮挡的形状（C 形、环形、有孔洞）都表达不出来**。要 morph 真实 logo
  轮廓必须换成路径重采样，这张卡的技术路线不适用
- 路径已用 Catmull-Rom `C` 段连接；形状高频扰动很强时，切线外推可能在尖角处轻微过冲，
  此时提高 N 比改张力更稳
- 每帧重建 6 条 `d` 字符串（140 点 × 6 圈），单实例无压力；同屏放多个实例或点数上到 500 时要考虑缓存插值结果
- 两条形状函数写死在 setup 里，没有做成参数。要换形状是改函数体而不是传参——移植时
  建议把 `rA/rB` 提成入参，否则每个变体都要复制一份 setup
- 背景是 aurora 深紫舞台 + 随色相的环境柔光，整套辉光依赖深底。白底上光晕失效，
  低透明度体积填充也几乎不可见，浅色主题需要重配饱和度与描边宽度
