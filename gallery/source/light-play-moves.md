name: light-play-moves
一句话: 光效三式——spotlight-sweep 聚光扫字、sheen 单点扫光、halation-bloom 撞停晕染
适用: 把光当第四种笔触（扫/擦/晕）：暗场标题揭示（A）、主角卡加冕（B）、撞停帧冲击（D）
时长: A 170f ~5.7s / B 150f ~5s / D 150f ~5s
能量: A 中 / B 低 / D 高
标签: typography
---

## 意图
库内"光"一直只有 spotlight-hero-card 一个点射手法；这三式把光做成
体系，三种笔触三种职责：A 是**扫**——暗场里几乎不可见的标题被锥形
光摆动扫亮，光到哪哪亮，与 spotlight-hero-card 的区别是那个打卡片、
这个扫文字；B 是**擦**——深墨主角卡上一道 45° 高光带缓扫一次，被
圆角裁住，无声的加冕；D 是**晕**——白字撞停帧一圈柔晕猛涨炸开再
回落成驻留呼吸光，与 B 的区别是 B 移动扫过、D 驻留在高光边缘。
全部深底或深主角——**白底上提亮不可见**（判例）是这整张卡的地基。

## 三式选型
| 式 | 做法 | 适用 |
|----|------|------|
| A spotlight-sweep | 双层同文本：暗版 0.07 常驻，亮版 radial mask 随光斑走，钟摆式追光摆两个半来回阻尼停在正中，iris 张开全亮定格 | 暗场大标题揭示开场 |
| B sheen-sweep | 深墨卡（demo：钛黑金属卡）转向光源的同时，115° 高光带扫一次，overflow hidden 圆角裁剪 | 主角卡静止段的一次加冕 |
| D halation-bloom | 文字复制底层 blur+brightness 当晕层（紧芯 / 主晕 / 外圈 halation 三层 + 横向光条），撞停帧起猛涨一圈回落成稳态柔光 | crash-zoom 撞停帧的冲击加成 |

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| A 反差 | 暗版 0.07 vs 全亮 1.0；demo 为暖白 #f8efe2 衬线字对酒红黑天鹅绒幕布（#1a0a0d→#070203），幕布本身也只在光斑里被照亮 | 反差是本式全部；暗版 >0.15 就没有"点亮"了 |
| A 光斑 | ellipse 360px（硬芯+长软边），钟摆：x = 960+600·sin θ·env，θ 从 −π/2（最左）起、周期 50f、走 2.25 个周期至 f121；y 走下凹弧（中心最低 44px）；env 第一来回后 smooth 收到 0，x 与速度在 f121 同时归零（纯 sin 会在中心最快时急刹）；开灯 4–10f 钨丝预热闪两下 | f121–141 iris 张开 360→1080px 全亮（out-cubic）、光锥线性收成柔和顶光（扩散/消散解耦判例） |
| B 高光带 | 宽 2×卡宽，115° 渐变：宽柔光 0.14 + 窄亮芯 0.5（暖白，screen），58–90f swift 扫一次；同段卡 rotateY 21°→14°（转向光源 = 扫光的物理动机）；光带下拉丝纹与蚀刻字的亮版副本被同一遮罩揭开 | 0.5 芯在钛黑上足够响又不糊；双向 clamp + 条件挂载保证只扫一次 |
| D 晕层 | 主晕 blur 14→30px + brightness 1.8，scale 1→1.18 用 6f out-cubic 猛涨、随消散收回 1.03；opacity 20f 线性回落 0.38 再 18f 缓收 0.24 稳态（±8% 呼吸）；外圈 halation（电光蓝 blur 64）扩到 1.14；撞停帧横向光条 12f 收干 | 扩散 out-cubic/消散线性解耦（判例）；同快涨快消读作闪光灯；晕层停在大 scale 会读成"重影"，必须收回 |
| 摘罩 | 扫光（B）、光条（D）条件挂载，扫完即卸载；A 光锥收成常驻柔和顶光，D 晕层停在稳态柔光 | opacity 0 残留层照样每帧合成——不用的光效层直接卸载 |
| 收尾 | A ~30f / B ~55f / D ~90f hold；hold 段只留极缓运动（A 浮尘与顶光呼吸、B 卡 rotateY 再转 1.5°、D 相机推进 2.5% + 晕呼吸） | 不加手持抖动（Q3） |

## 已知坑
- demo 在灰阶/占位素材上调校通过——参数是调校起点非实战定稿，
  首次实战须以真实素材回验
- **全片光效合计 ≤2 次**——光是最快掉价的手法，每个卡都闪一下
  等于廉价模板
- B 式是高标准重试通过：旧否决（2026-07-13 判例）针对当时实现不好看，
  非路径不可行；四约束 = 单点+主角+圆角裁剪+只扫一次，违反任何
  一条回到否决区
- 深底是地基：三式全部依赖深底/深主角，白底上做光效直接跳过本卡
- D 与 crash-zoom-punch 撞停帧天然联动（撞停即起晕）；A 与
  spotlight-hero-card 同片二选一，都是"聚光"语汇
