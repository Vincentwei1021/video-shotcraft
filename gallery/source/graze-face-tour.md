## 意图
把 UI 拍成地形：大倾角特写让侧栏树、导航、列表行变成掠过的地貌，
浅景深强化"贴面"。戏眼是**文字空中贴落**：文字/组件不是原地淡入，
而是悬浮在界面上空（3D z 轴抬高），在空中时往界面投同形软影，
随镜头行进先后加速贴落、影子随高度收敛消失——观众看见界面在
镜头经过时"完成自己"。影子是可感命门：没有影子，悬浮读作
普通位移入场；有影子，空间关系瞬间成立。

## 动效核心
- 机位：perspective 1150 + 画布 `scale·rotateX(64°→54°)·rotateZ(航向 −10°→−20°)·translate(−焦点)`，
  焦点沿一条三次贝塞尔曲线一镜到底上行（前进方向 = 画布"向上"，文字永远正读）；
  行程曲线缓起 25% → 匀速巡航 → 缓落 30%，无刹停；末段俯角略抬，落在大标题上做尾帧海报
- 悬浮元素：真 3D——文字/图标/徽标作为独立单元 `translateZ(h)` 沿界面法线抬起（父级
  preserve-3d），初始 H≈120–230px（标题最高最重），easeFall 22f 加速下落 + 软着陆、不回弹
- 同形长影：元素在 z≈0.5 处渲一份 `brightness(0) blur` 副本，偏移 = h × 0.75 沿光的方位角
  （低角度光从左侧来，影朝右拖），高处影大而虚而淡、贴近时收紧变实，落地与本体重合消失
- 错峰贴落：每个元素的落地帧 = 相机焦点"前方距离"第一次降到阈值（120px）的那一帧——按
  相机路径预扫出来，所以先经过的先落、下落彼此重叠并行，开场近处元素最早 10f 落
- 景深：远端一条 backdrop-filter 模糊带 + 暖色空气雾、近端底边轻虚化——只一层全屏
  backdrop，不重复渲染整页
- 长镜也可拆段接力：段间用相邻段交叉淡化（判例：透明度窗口不重叠会产生黑闪帧）

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 悬浮高度 | 120–230px（正文 150、标题 230） | <80px 影子和位移都读不出；>250px 落地砸得太重 |
| 影子参数 | 偏移 0.75h、blur 2+0.12h、不透明度 0.24×(1−0.7·h/H) | 影子恒定不随高度变＝贴纸感；落地影必须归零；偏移 >1.1h 且朝镜头方向时读作重影 |
| 贴落错峰 | 焦点前方距离 < 120px 即落地（按相机路径预扫） | 阈值太大（>400）全在远端虚化区里落、看不见；同帧齐落读作开关；**错峰=错开起点但下落过程重叠并行**，串行等待被裁（runway 判例） |
| 下落曲线 | easeFall bezier(0.5,0.05,0.6,1)，22f | ease-out 下落读作气球飘落，重力感靠加速 |
| 相机行程 | 140f 缓起 25% / 巡航 / 缓落 30%，之后 hold 25f | 分段各自 ease 会段段刹停 |
| 段间接力（拆段时） | 相邻段交叉淡化 ≥8f | 透明度窗口不搭接会黑闪（返工判例 f100 纯黑帧） |
| 景深 | 远端 backdrop blur 9px 带 + 空气雾，近端 5px | 全清晰读作平面滚动，浅景深才有"贴面"体感 |

## 已知坑
- demo 在灰阶/占位素材上调校通过——参数是调校起点非实战定稿，
  首次实战须以真实素材回验
- 悬空元素别被环境压黑带吞掉（邻候选 runway 判例）：空中元素
  需追光/提亮 ~1.3x，否则悬浮状态不可感等于没做
- 与 space-camera-moves/tension-camera-moves 分工：那两张是相机
  语言本身；本卡=贴面机位 **+ 元素贴落** 的组合签名，缺一半就
  改用相机卡
- **贴落节奏语义判例**（与 neon-frame-orbit-drop 互为反例）：
  本卡巡礼镜=错峰并行；整体登场镜必须全体同帧齐落（那张卡的
  错峰版被裁）。选错语法两边都会被裁
- 原片（clickup-30）是一条连续上行长镜；demo 已做成真单长镜：画布按"前进 = 画布向上"
  排版（侧栏树在左下、列表在中、标题在右上），焦点走一条曲线即可——难点是画布内容要沿路径
  铺满，否则近处会露出空白界面（起点焦点要压在内容区里）
- 悬浮单元要绝对定位在画布上、父级全程 preserve-3d；中间夹 overflow/filter/opacity 的容器会把
  translateZ 拍平
