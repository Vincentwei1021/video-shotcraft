---
name: scan-bracket-sweep
一句话: 文档弹到中央，四角落下 L 形取景括号，一条扫描光带拖着渐变尾迹在文档上往复扫 5 趟——文档全程静止，只有光在读它
适用: "正在解析/校验这份内容"的过程镜头；文档类产品的能力演示；上传→分析链路的中段
时长: 约6.3s（190f@30fps）
能量: 中低（机械、克制，节奏全在往复扫掠的呼吸上）
---

## 意图
让观众看懂"这份东西正在被机器逐行读过"。取景括号先把目标框住（宣布检查
对象），扫描光带再往复走完全篇（宣布检查过程）。命门是**文档本身完全静止**：
一旦文档也在动，观众就分不清是"被检查"还是"在加载"。

## 动效核心
- demo 画面：暖黑舞台（ember）正中一份 1180×700 的暗色合同条款表（7 条条款、30px 正文），
  琥珀色取景括号 + 琥珀扫描光；文档下方一条 HUD（状态点 / 进度条 / 当前条款）
- 文档 0–18f `snappy` 从 scale 0.94 弹到 1，透明度 `dp*2.5` 提前满亮——先"在了"再"稳了"
- 四角 72px、5px 圆头 L 形括号外扩 26px，10f 起每角错峰 3f，各 14f 从外侧沿对角 40px
  收进来（overshoot，约 8% 一次回弹）
- 扫描窗口 30→146f 严格 linear 切成 5 趟，趟内 `inOutSine` 两端慢中间快，末尾留 12% 完全停顿
  （`local=(raw-pi)/0.88`）；30–36f 淡入、142–150f 淡出
- 光带 = 3px 白热光芯（两端琥珀）+ 44px 对称柔辉 + 拖尾；暗场里全部 `screen` 叠加（光是加上去的）。
  拖尾最长 200px、长度随扫描速度伸缩（趟末停顿处收成 0，换向不跳）；方向随 `dir` 翻转：
  下行挂在光带上方、上行挂在下方，渐变同步反向
- "光在读"做成可见结果：第 1 趟光芯扫过的行由未读（24% 亮度）转为已读；风险条款在光芯经过时
  左缘亮起琥珀竖条 + 右侧页边琥珀点（overshoot 弹出）；之后每趟只做瞬时行提亮（行底 10%，高斯衰减）。
  文档本体一像素不动
- 收束 148f：括号向内收紧 14px（spring damping 16）并转为暖白、HUD 切成「REVIEW READY · 2 CLAUSES FLAGGED」；
  162–190f hold 28f，相机全程 smooth 极缓推进 1.8%
- 整条光带裁在与文档同 22px 圆角的 `overflow:hidden` 层里

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 文档弹入 | scale 0.94→1，0–18f snappy | 起始值低于 0.8 就成了"从远处飞来"，弹入要小幅度才像 UI |
| 取景括号 | 臂长 72px、圆头描边 5px、外扩 26px；错峰 3f / 各 14f，落位位移 40px | 四角同时出现读作静态边框；差 3f 就够读出"依次落下" |
| 扫描趟数 | PASSES=5，窗口 30→146f linear（每趟 ~23f） | 3 趟不够读作"往复"，7 趟以上每趟太快 |
| 趟内缓动 | inOutSine + 末尾 12% 停顿 | 停顿是"看清了这一趟"的换气位；去掉就成了匀速来回摆 |
| 光带 | 3px 光芯 + 44px 柔辉 + ≤200px 拖尾（暗场 screen / 亮场 multiply） | 线太粗（>6px）读作遮罩边缘而不是光；拖尾用黑灰会读成脏污 |
| 拖尾方向 | 下行 top:−tail / 上行 top:0，渐变一并翻转；tail 随速度 | 只翻其一 → 拖尾跑到运动前方，读作"光在往回吸"；定长拖尾换向时会整块跳到另一侧 |
| 已读 / 标记 | 第 1 趟光芯到达行中心的帧（反解 inOutSine）起 8f 转亮；标记 10f 弹出 | 让"读过"留下结果；标记只给 1–2 行，多了就成了报错列表 |
| 收束 | 括号内收 14px spring + 转暖白、HUD 切结论文案 | 扫完不收一拍，结尾读不出"读完了" |
| 裁切层 | 与文档同圆角 overflow:hidden | 漏到文档外就是"扫画面"不是"扫文档" |

## 已知坑
- 光带必须裁在文档 bbox 内，且圆角与文档一致——漏出一点就丢掉"扫描
  这份文档"的语义
- 拖尾的 `top` 和 gradient 方向是两处独立写法，改扫描方向时必须同改，
  漏一处就出现"尾迹在前"的反物理观感
- 括号的 72px 臂长与 26px 外扩是按 1180×700 的文档尺寸配的；换真实截图
  要按新尺寸重算，臂长超过短边 1/6 就压住内容
- 暗场用 `screen`、亮场用 `multiply`——暗场里 multiply 的光几乎看不见，亮场里 screen 会把纸洗白
- 等宽编号/负责人与无衬线正文混排时用 flex + `alignItems: baseline`，分别按行高居中会差 3–4px 基线
- 颜色只有 AMBER（光芯 / 柔辉 / 拖尾 / 括号 / 标记）一个光色，换肤只改它和 look
