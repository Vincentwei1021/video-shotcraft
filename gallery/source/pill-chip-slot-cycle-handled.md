name: pill-chip-slot-cycle-handled
一句话: 暖沙底大字句 "Your `chip` handled" 里浓缩咖啡色胶囊内词竖向滚轮轮换，胶囊宽度按实测词宽连续伸缩、两侧大字被自然挤开收拢，胶囊上下露出半速视差的幽灵项；末词胶囊转强调色实心盖章
适用: "我们替你搞定 ___" 这类句式卖点；SaaS 功能列举的一句话收口；浅底品牌片主视觉一拍
时长: 约 6.0s（180f@30fps：胶囊弹出展开 → 3 次切换（44/74/100f，越换越快）→ 末词转色 + 副标题 → hold）
能量: 中（三拍渐快节拍，宽度伸缩是唯一的连续运动，末拍转色是唯一峰值）
---

## 意图
词槽轮换有两派：让句子躲开变化（宽度固定的滚轮），或者让句子**接受**
变化（胶囊撑宽、两侧文字被挤开）。这卡是后者，代价是必须把宽度算准，
回报是句子读起来活的——"Your" 和 "Handled" 被推着走，观众感到胶囊里
的词有分量。上下露出的灰色幽灵项是第二个记号：它明示"这是个可以滚的
列表"，让观众预期还有下一个词。

## 动效核心
- 版式：句子 150px/800（字距 -0.05em）居中占画宽 ~70%；胶囊高 148、内含 100px 圆形强调色图标块 + 84px/720 词
  （比句子小一档：徽章依附句子）；眉题全大写 28px、左下品牌字标、右下 `01 / 04` 序号随滚轮落定翻页
- 宽度预量：首帧 `useLayoutEffect` 用隐藏 `<span>` 逐词量 `offsetWidth`，胶囊宽 = 24 + 100 + 26 + 词宽 + 54
  （带 `length·0.56em` 兜底）；两侧文字 `flex:none`，胶囊宽变化由 flex 居中自然把它们推开/收拢
- 滚轮位置 `pos` 由 3 段窗累加：起点 `[44, 74, 100]f`、窗 `[20, 18, 20]f`，缓动 `bezier(0.6,-0.12,0.3,1.14)`
  ——两头缓、起步 ~2% 反向回拉、末端 ~5% 过冲卡入（棘轮）；词列竖移 `-pos·148`px，按竖向速度加方向性模糊（≤16px，静止为 0）
- 宽度位置用**不过冲**的 swift 且晚 2f（父先动、子跟随）：宽度跟着词走，不会在过冲时预支下一个词的宽度
- 开场：胶囊先以只露图标块的圆形弹出（spring damping 15），再展开到首词宽（damping 20）——两侧大字第一次被推开就是手法本身的预告
- 幽灵项与胶囊内词左缘对齐，取 `near = round(pos)` 的前后邻居，半速视差 `(pos-near)·148·0.5` + `scaleY(0.82)` 柱面压扁，
  透明度 `0.13·(0.35+0.65·settle)`，滚动中更淡并轻微虚化
- 结论拍：108–122f 胶囊由咖啡色渐变转成赤陶实心、末词图标块反白，落定时胶囊下一次暖色地面泛光；幽灵项随之淡出；126f 副标题逐词升起
- 全程极缓推近 1→1.035（smooth）；切换中胶囊阴影随滚速变大变虚（离地感），落定回落

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 词表 | 4 词（Payroll/Invoices/Taxes/Finances），3 次切换，末词是结论 | 词长差决定挤开幅度：demo 5–8 字母；差 >2 倍胶囊跳变太猛，句子重心左右甩 |
| 切换点 | 44 / 74 / 100f，窗 20/18/20f | 持词时间 24→12→8f 越来越短（渐快），最后一词落定后长 hold；均匀间隔读作节拍器 |
| 缓动 | `bezier(0.6,-0.12,0.3,1.14)`（in-out + 预备 + ~5% 过冲） | 两头缓才像滚轮起停；过冲 >8% 读作弹簧，不再是棘轮 |
| 胶囊 | 高 148、圆角 999、`#3a2c22→#18110c` 竖向渐变、宽 = 词宽 + 204 | 带暖色相的深色，不用纯黑；内边距 <150 词贴边 |
| 幽灵项 | 与词左缘对齐，上 -110 / 下 +170px，基础透明度 0.13 | >0.25 读作三行并列文字；删了列表暗示就没了 |
| 幽灵视差 | `(pos-near)·148·0.5`（半速）+ scaleY 0.82 | 同速则三行像一整块滑动，幽灵失去意义 |
| 句子字号 | 两侧 150px/800、胶囊内 84px/720 | 胶囊内比句子小是正确层级；等大就读作两个标题打架 |
| 配色 | sand：米色舞台、墨色句子、咖啡色胶囊 + 赤陶图标块，末词赤陶实心 | 浅底 + 单一深色块是本卡身份证；强调色只给图标块与结论拍 |

## 已知坑
- demo 在灰阶/占位素材上调校通过——参数是调校起点非实战定稿，
  首次实战须以真实素材回验
- **宽度靠 setup 期 `offsetWidth` 实测**：字体没加载完时量到的是回退字体
  的宽度，胶囊会偏窄或偏宽——移植时须确保 webfont 就绪后再量，或改用
  离屏 canvas `measureText`；`length·0.56em` 那条兜底只保证不崩，不保证准
- 词长差要控制在 2 倍内：宽度自适应是本卡的卖点也是风险，
  `Invoices`→`Taxes`（8→5）这一跳已经接近可接受上限，再大句子两侧甩得晃眼
- 两侧文字必须 `flex:none`：不然 flex 会去压缩它们而不是移动它们，
  "挤开"变成"字被压扁"
- 幽灵项文本取 `round(pos)` 的邻居，所以在切换的正中间（pos=x.5）会
  **跳一次文本**——被 `settle` 压到最淡时发生，肉眼基本不可察；但若把
  透明度调高到 0.25+，这一跳就会露出来
- 胶囊宽度别直接用带过冲的 `pos` 插值：过冲段 frac>0 会把宽度往"下一个词"拉，读作胶囊抽搐；宽度单独用不过冲曲线
- 图标用自绘线性 SVG（不用系统 emoji：不同平台字形宽度不一，会让实测宽度漂移）
- 与 vertical-word-roll-blur-cycle 分工：那卡宽度固定、裸词、带滚筒 blur
  （词是句子成分），本卡宽度自适应、深色胶囊、带幽灵项（词是徽章）——
  同片只留一个；声音上三次落定是三个节奏点，配轻质开关/胶囊贴合音，
  连发交替双样本，配法纪律见 sound-design.md
