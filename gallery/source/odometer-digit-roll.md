## 意图
王牌数字的登场库内有"砸"（score-slam）和"弹"（damage-number），
都是位移系。本卡是**机械系**：数字不是飞进来的，是"算出来的"——
每位一只 0–9 圆柱滚筒高速转动，从左到右逐位减速、过冲小半格、咔哒锁定，
Vercel Ship/Stripe Sessions 指标段的标准语法。滚动过程自带悬念
（它会停在几？），逐位锁定自带节奏（哒、哒、哒、哒），比直接显示
终值多一整拍的期待感。与 VerticalTicker（backlog 待选）的区别：
有终值、逐位停稳，不是无限滚动墙。

## 动效核心
- 每位一只深色玻璃槽（overflow:hidden，内凹渐变 + 上沿反光 + 发丝线框）+ 一只 10 面圆柱滚筒：当前位附近 ±2 格按圆柱投影排布
  （`y = r·sinθ`、`scaleY = cosθ`、亮度 ∝ cos²θ，`θ = (k − pos)·36°`），邻位数字在槽口上下以压扁的暗影露出一线；posAt(f, i) 纯帧函数
- 0–8f 匀加速起步到全速 0.85 格/帧，各位起始相位错开（开场四位不是同一个数）
- 位 i 于 22+i×8f 开始 16f 三次 Hermite 减速（初速 = 满速，无速度折点）冲到目标 **+0.4 格过冲**，再 8f 回落锁定——
  锁定帧（46/54/62/70f）即各位的"哒"；锁定前 3f 由次级蓝灰转白，槽内一次 6f 电光蓝闪亮
- 滚动期按转速给纵向高斯模糊（SVG feGaussianBlur `0 σ`，封顶 14px），停稳自动摘——圆柱上可见的多格数字本身就是"残影"
- 全体锁定（72f）：整排一次快起慢落的顿挫 1→1.025→1（16f）+ 数字背后蓝色泛光 + % 转强调色 + 一条电光细线从中间向两侧拉开
  （全片唯一一次光效）；80f 起标题逐词升起、94f 副标题淡入——"合计确认"的句号
- 小数点与 % 等非数字位全程驻场不滚，与滚筒正面同字号、同基线（% 按基线缩到 0.74）

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 字号/字体 | 340px fw800 + fontVariantNumeric: tabular-nums | 非等宽数字每滚一格整行抖动（同 scramble 等宽判例） |
| 圆柱半径 | r = 格高 / (2·tan18°)（10 面闭合） | r 小了邻位挤成一团；槽高 ≈ 1.4 格只露邻位一线最像机械 |
| 错峰 | 22+i×8f 起减速，从左到右 | 从右往左停读作倒着算；同时停失去"哒哒哒" |
| 过冲 | +0.4 格再 8f 回落 | 无过冲读作滑到即停，机械感减半 |
| 运动模糊 | 纵向 σ = 转速 × 格高 × 0.045，封顶 14px | 不封顶全速时糊成色块，读不出"在转" |
| 终值确认 | 顿挫 1.025 + 泛光 + 细线拉开 | 只变色不顿挫在 340px 大字上不可感；光效只给这一次 |
| 收尾 | 确认后真静止 ≥45f（仅极缓推近） | R1 |

## 已知坑
- demo 在灰阶/占位素材上调校通过——参数是调校起点非实战定稿，
  首次实战须以真实素材回验
- 数位 ≤6（含小数点前后）——每多一位多 8f 错峰，8 位滚完 >2.5s
  观众等不起；大数换缩写（12.4M 不是 12,400,000）
- 与 impact-feedback B（伤害数字）同片可共存但分工要清：全屏主菜
  一次（本卡），卡片配菜多次（B 式）——两处都全屏就是两次主菜
- 滚动的数字必须是**真值的各位**——终值 99.98 就滚 9/9/9/8，
  中途乱数会被暂停党抓到"假滚动"
- 声音强依赖候选位：逐位锁定"哒"×N + 终值确认一声低音
  （sound-design §4.5），无声版成立但少一半爽感
