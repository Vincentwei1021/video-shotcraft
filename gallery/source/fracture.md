name: fracture
一句话: 5×5 瓦片从 3D 碎片态按中心波纹逐圈聚合成整面海报，停一拍亮字，随后全部碎片背离中心加速旋转飞出画面
适用: 开场第一镜"从混沌到成形"的品牌/海报揭示；倒放或只取后半可作硬转场
时长: 约 6s（180f@30fps；聚合 0–2.4s · 点亮+hold 1.6s · 飞散 1.1s · 落版 0.9s）
能量: 高（两头高能、中段静止，适合压 BGM 重音起收）

## 意图
把"产品成形"拍成物理事件：碎片从三维空间各自带着旋转飞回原位，观众看着一面完整画面从无序中长出来；hold 读字后再整体炸出画面，把注意力干净地交给下一镜。进出对称，一支素材可正反两用。

## 动效核心
- 25 块瓦片各自持有确定性伪随机的初始姿态：位移 ±1150/±650px（x/y）+ 景深 z −300~−1800 + 三轴 ±200°/±200°/±110° 旋转，由 `rand(seed)` 生成，渲染可复现
- 瓦片是**有厚度的实体**（16px：正面海报切片 + 背面 + 四条侧边，共处一个 preserve-3d 上下文）：按 CSS 旋转矩阵（Rx·Ry·Rz）算每个面的法线，对左上前方主光做 Lambert 明暗——翻滚时侧边被光扫成暖金、背光面压暗；离镜头越远越暗（景深里的碎片"还没被照到"）
- 入场按曼哈顿距离波纹 stagger：`start = 4 + d·6.5f + ≤3f 抖动`，中心先就位、四角最后，每块 36f 走 `bezier(0.33,0,0.15,1)`（飞得快、入槽前长减速）；落位后 ~16f 一次 ≤2.5° 的 rotateX 阻尼小摆 = 入槽"咔哒"
- 25 块切的是**同一张海报**（每块按格位偏移取自己那一格），拼齐才看见完整画面：石墨底 + 日蚀（暗盘 + 金白细边 + 钻石环亮点与横向光带）+ 衬线字标；**版式按瓦片行排**——字标整个落在一行内，拼缝只切图形不切字的笔画
- 不做透明度淡入：碎片第 1 帧就是实体（暗处的石板），靠受光由暗变亮"浮现"
- 点亮：末块落位时金边由暗转亮、钻石环闪一下，字标逐字从线下升起，hold 段一次扫光（Q4 只给主角一次）
- 退场不淡出：中心先走（每环 +2.2f），每块沿背离中心方向（`atan2` + ±0.35 抖动）飞出 1300–1800px、同时冲向镜头 z +400~+1000、大角度翻滚，`EASE.exit` 加速实体出画；碎片清空后露出底下的落版（小标 + 字标 + 上市日期）
- 飞行段包 CameraMotionBlur（聚合 6 采样、飞散 10 采样），hold 段不包

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 网格 | 5×5，海报 1440×810（每块 288×162），perspective 1800px，拼缝 4px | 瓦片更多波纹更细腻但单块存在感下降；persp <1200 冲向镜头的碎片会夸张变形 |
| 厚度 | 16px，侧边 `#1a1b1e → #b59a68` 按受光² 插值 | 没有厚度的纸片翻起来像卡片；侧边不受光读不出体积 |
| 初始散布 | dx±1150 / dy±650 / dz −300~−1800 | 放大散布开场更混沌，但聚合路径变长需同步加 delay 窗口 |
| 波纹间隔 | 6.5f/环（曼哈顿距离） | >10f 波纹感变"逐圈点名"；<4f 全体近同时到位失去波纹 |
| 入场时长 | 每块 36f | 缩短更"啪"地成形；保证末块 ≤72f 就位 |
| 退场窗口 | 118f + d·2.2f 起飞，26f（EASE.exit） | **窗口必须在落版文字出现前清场**：最晚的角瓦片 ~154f 出画，落版 140f 起从中心升起 |
| 退场距离 | 1300–1800px + z +400~+1000（背离中心 + 随机抖动） | 距离不足会残留在画框边；z 超过 perspective 会穿过镜头翻面 |
| 运动模糊采样 | 聚合 6 / 飞散 10 | 飞散段转速大，6 采样会露出一层层分离的残影 |

## 已知坑
- 退场用位移出画而非 opacity 淡出——淡出会读作"消失"而非"飞走"，物理感尽失；改参数时别给瓦片挂退场透明度
- 所有随机量必须走确定性 `rand(seed)`（等价 Remotion `random()`），真随机会渲染间抖动
- hold 段（~92–118f）是唯一读字窗口，加长文案要同步推迟首块起飞，否则字还没读完瓦片已散
- 海报上的文字别压在拼缝上：居中短句两端恰好落在列缝里会被各吃掉 4px（判例："Every piece, in place." 首尾字母被切），改短到一列之内或让缝穿过字中段
- 用作转场时建议只取飞散段（118f 起）倒放/正放各半，两侧素材分别贴在瓦片面上需另做纹理映射
