标签: ui-entrance

## 意图
观众会读清屏幕上每个字——这一镜的说服力全在"文档是真的"。打字机式写入把静态页面变成"正在被写出来的文档"，侧栏历史条目落入补上"持续产出"的时间纵深。

## 动效核心
- 内容块两两一对按节拍写入：页面底色遮罩右锚左→右收窄，强调色 caret 骑在揭示前沿
- 人名 @-mention 在 wipe 完成后长出强调色底色
- 左右双栏靠底色补丁上→下收走入场，内缘强调色细线随揭示生长后淡去
- 尾段（history-list-stack）：6 条历史条目从上方逐个落入侧栏轨道，每落一条配一声 pop
- 相机从斜侧标题特写拉到全窗（双栏必须都入画），之后微俯上移让出底部给一行标语，只做极缓推近；页面是一扇悬浮在暗场里的应用窗口（圆角、亮边、背光、长投影），不铺满全屏

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 写入节拍 | 20 块两两一对，第 g 对 cue = 8 + g·4.4，每块 wipe 9f，最后一对 ~57f 完成（赶在 64f 全窗 settle 前） | 逐块写会超预算——"块数×节拍要先对预算"是这卡的核心算术，先算再写 |
| 写入手法 | 底色遮罩 width 100%→0，bezier(0.4,0,0.6,1)，遮罩色取纹理纸面实测色、右侧多盖（标题 120px——块测量宽度短于粗体实际字宽，否则尾词漏出）；强调色 caret 3px（深一档的极光紫 + 同色柔光）只跟最新块、只骑在实际文字宽度内，写完 2f 淡出；首块开写前 8f 笔尖在标题起点闪烁待命 | caret 同时出现多个立刻穿帮；永远只有一个"笔尖" |
| li 圆点 | 遮罩向左多盖 28px（::marker 在文本左 ~22px） | 不多盖圆点会提前穿帮——截图纹理里烤入的排版细节都要这样排查 |
| @-mention | wipe 完成后 4f 起、8f 长出强调色底（极光紫 0.4）、`mix-blend-mode: multiply`（底色盖在纹理字上方，normal 混合会把人名洗浅）；跳过非人名标题 | 高亮晚于写入才读作"重点被标出"；同帧出现读作贴图 |
| 双栏入场 | 左栏 cue 54 / 右栏 cue 62，底色补丁上→下 10f 收走 + 内缘 2px 强调色线随揭示生长、24f 淡去 | 双栏与正文错开节拍，同时入场会互相抢视线 |
| 历史条目落入 | 6 条，cue = 66 + i·5（排在侧栏 wipe 完成 64f 后），每条 9f 落下；起点 −48px，bezier(0.2,1.15,0.3,1) 轻弹跳，空中影 `0 12·air px 24·air px` | 条目几何紧贴烤入纹理已有条目的下方、行高对齐——DOM 重绘条目必须和纹理里的活条目严格对齐 |
| 舞台 | aurora 暗场：窗口背后一圈强调色背光（页面空间 translateZ −40，随窗口透视）、四周 0 0 0 1.5px 亮边 + 70px 长投影、顶沿一道高光；收尾标语 84px 两段（第二段强调色）左对齐窗口左缘 | 暖白纸面放进冷暗场里像一盏灯——舞台和窗口要同一套光向，背光别盖过纸面 |
| 相机 | 自写 3D 窗口相机（布局级 CSS zoom，Q2），单调三次 Hermite 样条逐帧展开：f0 zoom 1.42 / rotY −18° / rotX 8°（窗口左上角与舞台光同时入画）→ f26 1.24 → f64 全窗 0.86 → f104 0.74 + rotX 9° + 上移 78px（底部让给标语）→ f150 0.746 | 开场太近（>1.6x）整屏只剩纸面，暗场与窗口边都看不见，读作原版平铺页面；全窗时双栏必须都入画（Q10） |

## 声音
写入段钉 keyboard.mp3 修剪到 ~50f（8→57f）盖住书写段（拟音与动作严格等长，S4）；历史条目 6 连 pop 每 5f 一发、音量 0.40→0.25 阶梯递减做距离衰减（S2）。

## 已知坑
- mock 内容必须出版级：产品原生排版、文字铺满、侧栏完整入镜（Q10）——"贴图+标语"级的敷衍文档会导致整镜头重做
- 数据合规：mock 内容里绝不出现客户/成员真名（Q1）
- 素材页面是活数据源（协作文档类）时，全量重采会刷掉已定稿纹理——用增量脚本只刷单页单键
- 强调色示例（caret/@-mention/内缘线）在模板片中为琥珀色，适配新品牌时统一换成目标品牌强调色
