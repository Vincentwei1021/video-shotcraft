## 意图
文字变实体的常规做法是渐变/morph/展开，原片帧级拆解证明 Bear 反着
来：**实体化是 1 帧硬切**——上一帧还是文字+光标，下一帧就是完整
胶囊，无展开无 cross-fade 无回弹。硬切给的是"啪、成了"的确定感，
任何渐变都会把"实体"软化成"特效"。全段骨架是**两次硬切夹一次
滑动**：硬切实体化 → 平滑缩移归位 → 硬切揭示成品页。唯一的连续
运动（缩移）被两记硬切框住，才显得又快又稳。这个节奏骨架是命门，
三段挪动任何一段的性质（把硬切改渐变、把滑动改硬切）整卡就塌。

## 动效核心
- 打字段：几何无衬线（Futura 气质）180px 居中打 "#word"，**红实心光标
  恒亮不闪**（原片实测，别加 blink）；人手节奏 5–7f/字带确定性抖动。
  demo 把前半段放在暖墨暗场（朱红光标是画面唯一的颜色），第二记硬切时整页翻成纸白——明暗翻转放大了硬切的"啪"
- **实体化 = 1 帧硬切**：文字+光标整层消失，同帧出现无描边奶油色实体
  胶囊（受光上沿内高光 + 上亮下暗体积 + 两层落地影，浮起 16px）+ 图标 + 词（字号不变、原位等大，# 被图标替换）；仅允许
  3f 1.03→1 微落定防死板；舞台顶光同帧硬切提亮一档（不渐变）
- 胶囊 hold ~0.6s → 一段 bezier(0.5,0,0.25,1) 缩小左移（0.3x、
  16f）落到页面标签行的真实槽位（后半程落地、影子收没），位置/缩放同曲线同起止，中途不分段；按速度加方向性运动模糊
- 落位后**再 1 帧硬切**揭示成品页：底色/标题/正文/胶囊配色同帧
  全变（demo：笔记应用 Tern——左栏标签列表 #music 高亮、面包屑、132px 标题、标签行胶囊 + Add tag、46px 正文三行、关联笔记行），
  之后只留 1→1.015 极缓推镜收尾
- 实现要点：胶囊按大字号绘制、整体 transform 缩放，且
  transformOrigin 必须 0 0 + translate 先行，否则落位中心漂移

## 参数表
| 参数 | 典型值 | 调节手感 |
|------|--------|----------|
| 打字节奏 | 5–7f/字（原片 ~6 字/秒），mulberry32 抖动 | 均匀间隔读作机打；光标必须恒亮（**原片实测**不闪烁） |
| 实体化 | **1 帧硬切**（原片帧级实测无任何过渡）+ 3f 1.03→1 微落定 | 加淡入/展开立刻降级成普通 morph；微落定 >4f 读作弹跳 |
| 胶囊几何 | 原片实测 740×236@1920（493×157@720p ×1.5）；demo 放大到 900×300、字 180px，左右留白接近对称 | 胶囊要"宽大过头"才有实体感；加描边读作按钮；右侧留白比左侧多一倍会显得没摆正 |
| hold | ~20f（0.67s；原片实测 18f） | <12f 观众没看清胶囊长啥样就飞了 |
| 缩移 | 0.3x、16f、bezier(0.5,0,0.25,1)（原片实测 ~0.55x/14f，demo hero 更大故缩得更多，落槽后胶囊 270×90、字 54px） | 缩放与位移必须同曲线；分开调会读作两个动画 |
| 揭示 | 落位 +3f 再 1 帧硬切全页 | 揭示若做转场，第二记硬切没了，骨架塌一半 |

## 已知坑
- demo 在手搓画面上调校通过（墨夜打字 → 纸白笔记页）——参数是调校起点非实战定稿，
  首次实战须以真实素材回验（成品页应换产品真实截图，Q1）
- 与 typewriter-moves/ai-stream-response（打字呈现）、
  morph-from-primitive（图元渐变成形）撞领域：本卡命门是**硬切
  实体化非渐变变形**——只要你想加过渡，就该去用那几张卡而不是改这张
- 早期版本曾杜撰"胶囊飞入下方滑入笔记卡"段，原片对照证伪已砍；
  别复活飞行段
- transformOrigin 默认 50% 50% 会让缩放落位中心漂移 (1−s)×半宽，
  必须 origin 0 0 + translate 到目标中心再 scale（demo 内注释）
- 与原片残余差距：音符图标手绘 SVG 曲线、Futura 回退字重、揭示帧
  正文间距 ~10px 级别偏差；节奏与硬切时点已密帧对齐
